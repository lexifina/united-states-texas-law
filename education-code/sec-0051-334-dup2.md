# Sec. 51.334. ASSESSMENT INSTRUMENTS.
(a) The board shall designate one or more instruments for use by institutions of higher education in assessing students under this subchapter.
(b) Each assessment instrument designated by the board for use under this subchapter must be diagnostic in nature and designed to assess a student's readiness to perform freshman-level academic coursework. The board shall prescribe a single standard or set of standards for each assessment instrument to effectively measure student readiness as demonstrated by current research.
(c) For each assessment instrument designated by the board for use under this subchapter, the board shall prescribe a score below which a student is eligible for basic academic skills education.
