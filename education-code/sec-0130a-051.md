# Sec. 130A.051. BASE TIER FORMULA.
The amount of base tier state funding to which a junior college district is entitled for instruction and operations under this subchapter for a state fiscal year is an amount equal to the amount, if any, by which the district's guaranteed instruction and operations funding, as determined under Section 130A.052, exceeds the district's local share of base tier funding, as determined under Section 130A.056.
Added by Acts 2023, 88th Leg., R.S., Ch. 378 (H.B. 8), Sec. 46, eff. September 1, 2023.
