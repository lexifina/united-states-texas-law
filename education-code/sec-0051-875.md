# 51.875
Sec. 51.875. FUNDING. The board may use any available revenue, including legislative appropriations, and may solicit and accept gifts, grants, and donations from a public or private source for the purposes of this subchapter.
Added by Acts 2001, 77th Leg., ch. 1513, Sec. 1, eff. Sept. 1, 2001. Renumbered from Education Code Sec. 51.835 by Acts 2003, 78th Leg., ch. 1275, Sec. 2(27), eff. Sept. 1, 2003.
