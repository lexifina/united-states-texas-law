# Sec. 130A.053. BASIC ALLOTMENT.
The basic allotment for a junior college district for a state fiscal year is an amount per weighted full-time equivalent student set by the General Appropriations Act or other legislative appropriation.
Added by Acts 2023, 88th Leg., R.S., Ch. 378 (H.B. 8), Sec. 46, eff. September 1, 2023.
