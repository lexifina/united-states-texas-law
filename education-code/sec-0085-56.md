# Sec. 85.56. SUBSEQUENT PROCEDURE IF NO BIDS ACCEPTED.
If no bid is accepted by the board at the public auction, any subsequent procedure for the sale of oil, gas, sulphur, mineral ore, and other mineral leases shall be in the manner prescribed by this subchapter.
Acts 1971, 62nd Leg., p. 3197, ch. 1024, art. 1, Sec. 1, eff. Sept. 1, 1971.
