# Sec. 61.9621. DEFINITION.
In this subchapter, "professional nursing program" means an educational program offered by a public or private institution of higher education for preparing students for initial licensure as registered nurses.
Added by Acts 2001, 77th Leg., ch. 1489, Sec. 3, eff. Sept. 1, 2001. Renumbered from Education Code Sec. 61.921 by Acts 2003, 78th Leg., ch. 1275, Sec. 2(42), eff. Sept. 1, 2003.
Amended by:
Acts 2009, 81st Leg., R.S., Ch. 1042 (H.B. 4471), Sec. 1, eff. June 19, 2009.
