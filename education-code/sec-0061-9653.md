# Sec. 61.9653. LIMITATION.
A dental hygienist may receive repayment assistance grants for each of not more than five years.
Added by Acts 2001, 77th Leg., ch. 1035, Sec. 1, eff. Sept. 1, 2001. Renumbered from Education Code Sec. 61.9403 by Acts 2003, 78th Leg., ch. 1275, Sec. 2(43), eff. Sept. 1, 2003.
