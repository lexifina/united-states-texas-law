# Sec. 51.169. PROVISIONS APPLICABLE TO ADDITIONAL ASSOCIATIONS.
Except for Subsection (a), Section 51.153 of this Code, the provisions of this subchapter apply to any additional information network association created by the coordinating board.
Acts 1971, 62nd Leg., p. 3072, ch. 1024, art. 1, Sec. 1, eff. Sept. 1, 1971.
