# Sec. 61.0211. SUNSET PROVISION.
The Texas Higher Education Coordinating Board is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the board is abolished and this chapter expires September 1, 2029.
