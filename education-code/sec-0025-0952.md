# Sec. 25.0952. PROCEDURES APPLICABLE TO PARENT CONTRIBUTING TO NONATTENDANCE OFFENSE.
In a proceeding based on a complaint under Section 25.093, the court shall, except as otherwise provided by this chapter, use the procedures and exercise the powers authorized by Chapter 45A, Code of Criminal Procedure.
