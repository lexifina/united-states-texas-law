# Sec. 1001.054. RULES RESTRICTING ADVERTISING.
The commission by rule may restrict advertising by a branch location of an in-person driver education provider so that the location adequately identifies the main business location of the provider in a solicitation.
Added by Acts 2003, 78th Leg., ch. 1276, Sec. 6.012(a), eff. Sept. 1, 2003.
