# Sec. 33.254. SUNSET PROVISION.
The council is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the council is abolished and this subchapter expires September 1, 2029.
Added by Acts 2013, 83rd Leg., R.S., Ch. 531 (S.B. 503), Sec. 1, eff. June 14, 2013.
