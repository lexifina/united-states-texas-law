# Sec. 22.105. WRITTEN ELECTION REQUIRED.
Each school year, an active employee must elect in writing whether to designate a portion of the employee's compensation to be used as health care supplementation under this subchapter. An election under this section must be made at the same time at which the employee elects to participate in a cafeteria plan, if applicable.
