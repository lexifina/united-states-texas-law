# Sec. 45.307. STATUS OF PROGRAM.
(a) The program is separate from and does not create any claim to the credit enhancement program for school district bonds under Subchapter I.
(b) This subchapter does not create a debt of the state under the Texas Constitution or, except to the extent provided by this subchapter, create a payment obligation.
Added by Acts 2009, 81st Leg., R.S., Ch. 1328 (H.B. 3646), Sec. 75, eff. September 1, 2009.
