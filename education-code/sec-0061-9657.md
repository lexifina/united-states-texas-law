# Sec. 61.9657. ACCEPTANCE OF GIFTS AND GRANTS.
The board may accept gifts, grants, and donations for the purposes of this subchapter.
Added by Acts 2001, 77th Leg., ch. 1035, Sec. 1, eff. Sept. 1, 2001. Renumbered from Education Code Sec. 61.9407 by Acts 2003, 78th Leg., ch. 1275, Sec. 2(43), eff. Sept. 1, 2003.
