# Sec. 61.9728. ACCEPTANCE OF FUNDS.
The board may solicit and accept gifts, grants, and donations for the purposes of this subchapter.
Added by Acts 2001, 77th Leg., ch. 1403, Sec. 1, eff. Sept. 1, 2001. Renumbered from Education Code Sec. 61.958 by Acts 2003, 78th Leg., ch. 1275, Sec. 2(46), eff. Sept. 1, 2003.
