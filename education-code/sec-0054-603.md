# Sec. 54.603. SUNSET PROVISION.
The Prepaid Higher Education Tuition Board is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the board is abolished September 1, 2035.
Added by Acts 1995, 74th Leg., ch. 1032, Sec. 1, eff. Sept. 1, 1995. Amended by Acts 2001, 77th Leg., ch. 1250, Sec. 4, eff. June 15, 2001.
