# Sec. 21.552. PROGRAM ESTABLISHED.
The State Board for Educator Certification by rule shall establish the Teach for Texas Pilot Program consistent with the purposes provided by Section 21.551.
Added by Acts 1999, 76th Leg., ch. 1590, Sec. 8, eff. June 19, 1999. Renumbered from Sec. 21.502 by Acts 2001, 77th Leg., ch. 1420, Sec. 21.001(16), eff. Sept. 1, 2001. Amended by Acts 2001, 77th Leg., ch. 1420, Sec. 21.002(4), eff. Sept. 1, 2001.
