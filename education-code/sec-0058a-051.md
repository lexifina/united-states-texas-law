# Sec. 58A.051. PRIMARY CARE INNOVATION PROGRAM.
Subject to available funds, the board shall establish a grant program under which the board awards incentive payments to medical schools that administer innovative programs designed to increase the number of primary care physicians in this state.
Added by Acts 2013, 83rd Leg., R.S., Ch. 1015 (H.B. 2550), Sec. 2, eff. September 1, 2013.
