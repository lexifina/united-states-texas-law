# Sec. 162.003. EFFECT ON TEXAS LAWS.
If the laws of this state conflict with the compact or a rule adopted under that compact, the compact or rule controls, except that if a conflict exists between the compact or rule and the Texas Constitution, as determined by the courts of this state, the Texas Constitution controls.
Added by Acts 2009, 81st Leg., R.S., Ch. 8 (S.B. 90), Sec. 1, eff. May 5, 2009.
