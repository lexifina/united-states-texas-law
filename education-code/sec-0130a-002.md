# Sec. 130A.002. PURPOSE.
The purpose of the public junior college state finance program established under this chapter is to provide a modern and dynamic finance system that ensures that each public junior college has access to adequate state appropriations and local resources to support the education and training of the workforce of the future.
Added by Acts 2023, 88th Leg., R.S., Ch. 378 (H.B. 8), Sec. 46, eff. September 1, 2023.
