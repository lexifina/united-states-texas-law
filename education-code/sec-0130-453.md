# Sec. 130.453. ADMINISTRATION.
The coordinating board shall administer the program in consultation with the Texas Education Agency and the Texas Workforce Commission.
Added by Acts 2023, 88th Leg., R.S., Ch. 378 (H.B. 8), Sec. 45, eff. June 9, 2023.
Added by Acts 2023, 88th Leg., R.S., Ch. 967 (S.B. 2139), Sec. 1, eff. June 18, 2023.
