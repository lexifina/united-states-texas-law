# Sec. 62.023. SEVERABILITY.
If any provision of this chapter or the application thereof under any circumstance is held invalid, such invalidity shall not affect other provisions or applications of the chapter which can be given effect without the invalid provision or application, and to this end the provisions of this chapter are declared to be severable.
Added by Acts 1985, 69th Leg., ch. 225, Sec. 1, eff. June 3, 1985.
