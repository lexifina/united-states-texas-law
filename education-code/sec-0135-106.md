# Sec. 135.106. STATE FUNDING.
The system is entitled to receive state appropriations on the same formula basis as if the system did not enter into a partnership agreement under this subchapter, and any other participating institution of higher education is entitled to state appropriations on the same formula basis as other similar institutions of higher education.
Added by Acts 2013, 83rd Leg., R.S., Ch. 366 (H.B. 2760), Sec. 1, eff. June 14, 2013.
