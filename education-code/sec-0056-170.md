# Sec. 56.170. CONDITIONAL GUARANTY.
A conditional guaranty of a loan under Section 56.165(a) of this code must provide that the board shall repay the lending institution to which the guaranty is executed the amount of the loan that the board would be required to forgive under Section 56.169 of this code if the loan had been made by the board.
Added by Acts 1993, 73rd Leg., ch. 75, Sec. 1, eff. May 4, 1993.
