# Sec. 61.9704. FUNDING.
The board may use any available revenue, including legislative appropriations, and may solicit and accept gifts, grants, and donations to undertake the campaign.
Added by Acts 2001, 77th Leg., ch. 148, Sec. 1, eff. Sept. 1, 2001. Renumbered from Education Code Sec. 61.954 by Acts 2003, 78th Leg., ch. 1275, Sec. 2(45), eff. Sept. 1, 2003.
