# 51.872
Sec. 51.872. ADMINISTRATION OF FUND. The women's athletic development fund is a fund in the state treasury. The board shall administer the fund.
Added by Acts 2001, 77th Leg., ch. 1513, Sec. 1, eff. Sept. 1, 2001. Renumbered from Education Code Sec. 51.832 by Acts 2003, 78th Leg., ch. 1275, Sec. 2(27), eff. Sept. 1, 2003.
