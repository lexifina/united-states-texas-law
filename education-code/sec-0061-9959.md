# Sec. 61.9959. RULES; POSTING REQUIRED.
(a) The board shall adopt rules necessary for the administration of this subchapter.
(b) The board shall post on the board's Internet website a copy of the rules adopted under this subchapter and information regarding the program established under this subchapter.
Added by Acts 2019, 86th Leg., R.S., Ch. 567 (S.B. 16), Sec. 1, eff. September 1, 2019.
