# Sec. 29.452. APPLICABILITY.
This subchapter applies only to an alleged offender resident of a forensic state supported living center designated under Section 555.002, Health and Safety Code.
Added by Acts 2009, 81st Leg., R.S., Ch. 284 (S.B. 643), Sec. 2, eff. June 11, 2009.
Amended by:
Acts 2017, 85th Leg., R.S., Ch. 207 (S.B. 1300), Sec. 3, eff. September 1, 2017.
