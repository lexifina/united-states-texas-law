# Sec. 5.003. APPEAL.
If an order, decision, or determination is described as final in Chapter 7, 11, 12, 39, or 39A, an interlocutory or intermediate order, decision, report, or determination made or reached before the final order, decision, or determination may be appealed only as specifically authorized by this code or a rule adopted under this code.
Added by Acts 2021, 87th Leg., R.S., Ch. 1046 (S.B. 1365), Sec. 2.01, eff. September 1, 2021.
