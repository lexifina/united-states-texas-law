# Sec. 31.0701. REFERENCES TO STATE-DEVELOPED OPEN EDUCATION RESOURCE INSTRUCTIONAL MATERIAL.
In this chapter, a reference to a state-developed open education resource instructional material means an open education resource instructional material, as defined by Section 31.002.
Added by Acts 2023, 88th Leg., R.S., Ch. 818 (H.B. 1605), Sec. 27, eff. June 13, 2023.
