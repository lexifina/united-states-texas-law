# Sec. 371.073. APPOINTMENT OF AGENT.
(a) A pawnbroker shall maintain on file with the commissioner the name and address of the pawnbroker's registered agent for service of process.
(b) Repealed by Acts 2023, 88th Leg., R.S., Ch. 159 (S.B. 1371), Sec. 34(4), eff. September 1, 2023.
