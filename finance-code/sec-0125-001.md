# Sec. 125.001. DEFINITION.
In this chapter, "multiple-party account" has the meaning assigned by Section 113.004, Estates Code, except that the term includes an account in which one or more of the parties is an organization, association, corporation, or partnership.
Acts 1997, 75th Leg., ch. 1008, Sec. 1, eff. Sept. 1, 1997.
