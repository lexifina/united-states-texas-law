# Sec. 154.133. REFERENCE OR LINK TO WEBSITE.
Any sales literature or a website that offers or promotes the sale of prepaid funeral benefits contracts to the public must include a reference or link to the Internet website required under Section 154.132.
Added by Acts 2009, 81st Leg., R.S., Ch. 1190 (H.B. 3762), Sec. 7, eff. June 1, 2010.
