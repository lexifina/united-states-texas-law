# Sec. 342.003. PURCHASE FROM MORTGAGEE.
For the purposes of this chapter, a purchase from a mortgagee of an interest in a secondary mortgage loan that was made to secure that loan is treated as if it were a secondary mortgage loan.
Amended by Acts 1999, 76th Leg., ch. 62, Sec. 7.19(a), eff. Sept. 1, 1999.
