# Sec. 342.556. APPOINTMENT OF AGENT.
(a) An authorized lender shall maintain on file with the commissioner the name and address of the lender's registered agent for service.
(b) Repealed by Acts 2023, 88th Leg., R.S., Ch. 159 (S.B. 1371), Sec. 34(2), eff. September 1, 2023.
Added by Acts 1999, 76th Leg., ch. 62, Sec. 7.19(a), eff. Sept. 1, 1999.
