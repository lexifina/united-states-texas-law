# Sec. 351.160. SURRENDER OF LICENSE.
A license holder may surrender a license issued under this chapter by complying with the commissioner's written instructions relating to license surrender.
Added by Acts 2007, 80th Leg., R.S., Ch. 1220 (H.B. 2138), Sec. 1, eff. September 1, 2007.
Amended by:
Acts 2023, 88th Leg., R.S., Ch. 159 (S.B. 1371), Sec. 23, eff. September 1, 2023.
