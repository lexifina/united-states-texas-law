# Sec. 66.313. FINAL REPORT.
After paying a final dividend as provided by Section 66.309 and performing any necessary or proper action in liquidating the association's assets for the benefit of the depositors and creditors of the association, the liquidating agent shall file with the commissioner a final report of the liquidation.
Acts 1997, 75th Leg., ch. 1008, Sec. 1, eff. Sept. 1, 1997.
