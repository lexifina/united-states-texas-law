# Sec. 64.083. RULES.
The finance commission shall adopt rules to implement this subchapter, including rules that define the categories of loans and investments described by Section 64.081.
Acts 1997, 75th Leg., ch. 1008, Sec. 1, eff. Sept. 1, 1997. Amended by Acts 2001, 77th Leg., ch. 867, Sec. 29, eff. Sept. 1, 2001.
