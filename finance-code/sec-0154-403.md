# Sec. 154.403. CRIMINAL PENALTY FOR FAILURE TO FILE REPORT.
(a) An officer of a seller commits an offense if the officer fails or refuses to file an annual report required by Section 154.052 before the 31st day after the date the officer is notified by the department of the requirement.
(b) An offense under this section is a misdemeanor and is punishable as provided by Section 154.401.
Acts 1997, 75th Leg., ch. 1008, Sec. 1, eff. Sept. 1, 1997.
