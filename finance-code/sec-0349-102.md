# Sec. 349.102. LIABILITY FOR MULTIPLE VIOLATIONS IN ONE TRANSACTION.
(a) A person who would be liable under Sections 349.001 and 349.003 as a result of the same transaction is liable only for the penalties provided by Section 349.001.
(b) An obligor is entitled to only one recovery for multiple violations of this subtitle that occur in the same transaction.
Acts 1997, 75th Leg., ch. 1008, Sec. 1, eff. Sept. 1, 1997.
