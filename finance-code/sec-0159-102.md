# Sec. 159.102. FOREIGN LANGUAGE REQUIREMENT.
If the negotiations that precede the execution of the wrap mortgage loan agreement are conducted primarily in a language other than English, the wrap lender shall provide a copy of a written disclosure statement required under Section 159.101 of this code or Section 5.016, Property Code, in that language to the wrap borrower.
Added by Acts 2021, 87th Leg., R.S., Ch. 76 (S.B. 43), Sec. 3, eff. January 1, 2022.
