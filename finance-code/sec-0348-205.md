# Sec. 348.205. STATEMENT IF LIABILITY INSURANCE NOT INCLUDED IN CONTRACT.
If liability insurance coverage for bodily injury and property damage caused to others is not included in a retail installment contract, the retail installment contract or a separate writing must contain, in at least 10-point type that is bold-faced, capitalized, underlined, or otherwise conspicuously set out from the surrounding written material, a specific statement that liability insurance coverage for bodily injury and property damage caused to others is not included.
Acts 1997, 75th Leg., ch. 1008, Sec. 1, eff. Sept. 1, 1997.
