# Sec. 92.253. ACTION BY COMMISSIONER ON APPLICATION.
Not later than the 10th day after the date an application to convert is received, the commissioner shall:
(1) consent by written order to the conversion; or
(2) set a hearing on whether the conversion complies with rules adopted under Section 92.251.
Acts 1997, 75th Leg., ch. 1008, Sec. 1, eff. Sept. 1, 1997.
