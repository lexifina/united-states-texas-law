# Sec. 111.254. REASSIGNMENT.
(a) The rights, liens, judgments, and remedies assigned under Section 111.251 of this code may be reassigned by any assignee.
(b) If notice is given as required by Section 111.252 of this code, all rights, liens, judgments, and remedies originally held by the state to enforce and secure the tax claim or judgment pass to each person receiving a reassignment unless the reassignment is expressly limited in writing.
Acts 1981, 67th Leg., p. 1511, ch. 389, Sec. 1, eff. Jan. 1, 1982.
