# Sec. 142.0055. RULES.
The comptroller may adopt rules relating to the administration and collection of the sales and use tax as necessary to comply with the agreement, including rules establishing the requirements for a seller to be a Model 1 seller, Model 2 seller, or Model 3 seller.
Added by Acts 2003, 78th Leg., ch. 1310, Sec. 95, eff. Oct. 1, 2003.
