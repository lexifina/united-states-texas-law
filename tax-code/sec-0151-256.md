# Sec. 151.256. FAILURE TO PROVIDE SECURITY: LOSS OF PERMIT.
If a person fails to provide security under this subchapter as provided by Section 151.251(b) of this code, the comptroller shall revoke or suspend the permit or retailer's registration of the person as provided by Section 151.203 of this code.
Acts 1981, 67th Leg., p. 1557, ch. 389, Sec. 1, eff. Jan. 1, 1982.
