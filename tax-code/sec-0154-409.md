# Sec. 154.409. UNSTAMPED CIGARETTES.
If cigarettes seized under Section 154.403 of this code are unstamped, an officer selling the cigarettes shall affix the required stamps to the cigarettes and deduct the cost of the stamps from the sale proceeds.
Acts 1981, 67th Leg., p. 1658, ch. 389, Sec. 1, eff. Jan. 1, 1982.
