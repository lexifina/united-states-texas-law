# Sec. 151.484. CONFIDENTIALITY.
Except as provided by Section 111.006, information contained in a report required to be filed by this subchapter is confidential and not subject to disclosure under Chapter 552, Government Code.
Added by Acts 2019, 86th Leg., R.S., Ch. 371 (H.B. 1543), Sec. 1, eff. September 1, 2019.
