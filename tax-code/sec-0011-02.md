# Sec. 11.02. INTANGIBLE PERSONAL PROPERTY.
(a) Intangible personal property is not taxable.
(b) Repealed by Acts 2025, 89th Leg., R.S., Ch. 111 (H.B. 22), Sec. 3(1), eff. January 1, 2026.
