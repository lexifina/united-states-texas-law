# Sec. 202.003. AGREEMENT TO PAY TAX NOT IMPAIRED.
This code does not impair a contract in which any person has agreed to pay any part of the tax imposed by this chapter. This code does not relieve any person of any contractual liability.
Acts 1981, 67th Leg., p. 1737, ch. 389, Sec. 1, eff. Jan. 1, 1982.
