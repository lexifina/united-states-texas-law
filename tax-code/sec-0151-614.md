# Sec. 151.614. RES JUDICATA.
In the determination of a suit arising under this chapter, the rule of res judicata applies only if the liability at issue is for the same quarterly period as was at issue in a previously determined suit.
Acts 1981, 67th Leg., p. 1582, ch. 389, Sec. 1, eff. Jan. 1, 1982.
