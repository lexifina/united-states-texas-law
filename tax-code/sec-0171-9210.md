# Sec. 171.9210. APPLICATION FOR CREDIT.
Except as provided by Section 171.9205(c), a taxable entity must apply for a credit under this subchapter on or with the report for the period for which the credit is claimed.
Added by Acts 2025, 89th Leg., R.S., Ch. 1183 (S.B. 2206), Sec. 1, eff. January 1, 2026.
