# Sec. 151.465. APPLICABILITY TO CERTAIN BREWERS.
This subchapter applies only to a brewer permitted under Chapter 12A, Alcoholic Beverage Code.
Added by Acts 2011, 82nd Leg., R.S., Ch. 145 (H.B. 11), Sec. 3, eff. September 1, 2011.
Amended by:
Acts 2013, 83rd Leg., R.S., Ch. 533 (S.B. 516), Sec. 3, eff. June 14, 2013.
