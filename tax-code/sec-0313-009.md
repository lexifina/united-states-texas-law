# Sec. 313.009. CERTAIN ENTITIES INELIGIBLE.
An entity that has been issued a registration number under Section 151.359 or Section 151.3595 is not eligible to receive a limitation on appraised value under this chapter.
Added by Acts 2013, 83rd Leg., R.S., Ch. 1274 (H.B. 1223), Sec. 4, eff. September 1, 2013.
