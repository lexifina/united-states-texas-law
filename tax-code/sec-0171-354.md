# Sec. 171.354. AGENT FOR SERVICE OF PROCESS.
Each taxable entity on which a tax is imposed by this chapter shall designate a resident of this state as the taxable entity's agent for the service of process.
Acts 1981, 67th Leg., p. 1708, ch. 389, Sec. 1, eff. Jan. 1, 1982.
Amended by:
Acts 2006, 79th Leg., 3rd C.S., Ch. 1 (H.B. 3), Sec. 12, eff. January 1, 2008.
