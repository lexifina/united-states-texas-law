# Sec. 202.205. TRANSFER OF OWNERSHIP.
(a) If an oil-producing lease is transferred, or is to be transferred, the producer transferring the lease shall note the name and address of the producer acquiring the lease and the date of the transfer on the last report covering the lease that he is required by Section 202.201 of this code to file.
(b) If an oil-producing lease is transferred, the producer acquiring the lease shall note the date of the transfer and the name and address of the person from whom the lease was acquired on the first report covering the lease that he is required by Section 202.201 of this code to file.
Acts 1981, 67th Leg., p. 1740, ch. 389, Sec. 1, eff. Jan. 1, 1982.
