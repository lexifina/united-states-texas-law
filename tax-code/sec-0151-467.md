# Sec. 151.467. SUSPENSION OR CANCELLATION OF PERMIT.
If a person fails to file a report required by this subchapter or fails to file a complete report, the comptroller may suspend or cancel one or more permits issued to the person under Section 151.203.
Added by Acts 2011, 82nd Leg., R.S., Ch. 145 (H.B. 11), Sec. 3, eff. September 1, 2011.
