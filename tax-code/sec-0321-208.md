# Sec. 321.208. STATE EXEMPTIONS APPLICABLE.
The exemptions provided by Subchapter H, Chapter 151, apply to the taxes authorized by this chapter, except as provided by Sections 151.359(j) and 151.317(b).
Added by Acts 1987, 70th Leg., ch. 191, Sec. 1, eff. Sept. 1, 1987.
Amended by:
Acts 2013, 83rd Leg., R.S., Ch. 1274 (H.B. 1223), Sec. 5, eff. September 1, 2013.
