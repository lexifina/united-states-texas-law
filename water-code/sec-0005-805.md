# Sec. 5.805. RULES; MINIMUM STANDARDS.
The commission shall adopt rules to implement this subchapter and minimum performance and quality assurance standards for accreditation of an environmental testing laboratory.
Added by Acts 1999, 76th Leg., ch. 447, Sec. 1, eff. June 18, 1999. Redesignated from Health and Safety Code Sec. 421.005 and amended by Acts 2001, 77th Leg., ch. 965, Sec. 6.01, eff. Sept. 1, 2001.
