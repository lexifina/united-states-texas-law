# Sec. 17.901. GRANT OR LOAN TO POLITICAL SUBDIVISION.
The board may make a grant or loan to a political subdivision for a conservation program or conservation project. A political subdivision seeking a grant or loan must file an application with the board.
Added by Acts 1989, 71st Leg., ch. 1103, Sec. 1, eff. Sept. 1, 1989. Amended by Acts 2003, 78th Leg., ch. 200, Sec. 19(q), eff. Sept. 1, 2003; Acts 2003, 78th Leg., ch. 352, Sec. 17, eff. Sept. 1, 2003.
