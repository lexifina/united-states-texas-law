# Sec. 17.937. REPORTING AND TRANSPARENCY REQUIREMENTS.
(a) Annually, the board shall post on the board's Internet website a report detailing each project for which the board has provided financial assistance under this subchapter.
(b) The report must include:
(1) a description of each project;
(2) the location of each project;
(3) the number of residents served by each project;
(4) the amount of financial assistance provided or anticipated to be provided for each project;
(5) a statement of whether each project has been completed and, if not, the expected completion date;
(6) the date on which each appropriate political subdivision adopted the model rules developed under Section 16.343; and
(7) the date on which each appropriate political subdivision certified that it enforces the applicable model rules developed under Section 16.343 or a description of measures taken to mitigate any deficiencies in compliance.
Added by Acts 2019, 86th Leg., R.S., Ch. 1222 (S.B. 2452), Sec. 9, eff. November 5, 2019.
