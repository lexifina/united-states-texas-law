# Sec. 17.184. FILING CONSTRUCTION CONTRACT.
The political subdivision shall file with the board a certified copy of each construction contract it enters into for the construction of all or part of a project. Each contract shall contain or have attached to it the specifications, plans, and details of all work included in the contract.
Amended by Acts 1987, 70th Leg., ch. 1103, Sec. 1, eff. Sept. 1, 1987.
