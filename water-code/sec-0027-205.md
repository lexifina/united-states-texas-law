# Sec. 27.205. REPORTING OF INJECTION VOLUMES.
(a) A project operator shall install a meter on each recharge injection well associated with the aquifer recharge project.
(b) Each calendar year, the project operator shall provide to the commission a written or electronic report showing for the preceding calendar year the volume of water injected for recharge.
Added by Acts 2019, 86th Leg., R.S., Ch. 742 (H.B. 720), Sec. 3, eff. June 10, 2019.
