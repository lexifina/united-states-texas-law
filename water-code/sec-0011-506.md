# Sec. 11.506. CONFLICT BETWEEN STATE AND FEDERAL LAW.
If the state definition conflicts with the federal definition in any manner, the federal definition prevails.
Added by Acts 1989, 71st Leg., ch. 1202, Sec. 1, eff. Aug. 28, 1989.
Amended by:
Acts 2009, 81st Leg., R.S., Ch. 87 (S.B. 1969), Sec. 24.005, eff. September 1, 2009.
