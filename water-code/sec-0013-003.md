# Sec. 13.003. APPLICABILITY OF ADMINISTRATIVE PROCEDURE AND TEXAS REGISTER ACT.
Chapter 2001, Government Code applies to all proceedings under this chapter except to the extent inconsistent with this chapter.
Added by Acts 1985, 69th Leg., ch. 795, Sec. 3.005, eff. Sept. 1, 1985. Amended by Acts 1995, 74th Leg., ch. 76, Sec. 5.95(49), eff. Sept. 1, 1995.
