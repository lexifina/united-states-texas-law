# Sec. 5.403. RENEWAL PERIOD FOR CONSOLIDATED PERMIT.
The renewal period for a consolidated permit issued under this subchapter is the shortest term set by any state or federal statute or rule governing one or more of the authorizations sought in the consolidated permit.
Added by Acts 1997, 75th Leg., ch. 1373, Sec. 1, eff. Sept. 1, 1997.
