# Sec. 5.586. NOTICE TO STATE SENATOR AND STATE REPRESENTATIVE.
(a) This section applies only to a permit application for which public notice is required.
(b) The commission shall send notice of receipt of the application for a permit to each state senator and state representative who represent the area in which the facility or activity to which the application relates is or will be located.
Added by Acts 2023, 88th Leg., R.S., Ch. 1102 (S.B. 1397), Sec. 12, eff. September 1, 2023.
