# Sec. 11.505. APPLICABILITY TO STATE REVOLVING LOAN FUND PROGRAM.
This Act shall not apply to the state revolving loan fund program.
Added by Acts 1989, 71st Leg., ch. 1202, Sec. 1, eff. Aug. 28, 1989.
Amended by:
Acts 2009, 81st Leg., R.S., Ch. 87 (S.B. 1969), Sec. 24.004, eff. September 1, 2009.
