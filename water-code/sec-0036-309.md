# Sec. 36.309. APPEALS.
Appeals from any commission order shall be filed and heard in the district court of any of the counties in which the land is located.
Added by Acts 1995, 74th Leg., ch. 933, Sec. 2, eff. Sept. 1, 1995. Renumbered from Water Code Sec. 36.306 and amended by Acts 1997, 75th Leg., ch. 1010, Sec. 4.36, eff. Sept. 1, 1997.
