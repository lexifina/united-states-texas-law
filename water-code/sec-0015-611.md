# Sec. 15.611. LINKED DEPOSIT PROGRAM.
(a) The board by rule may establish a nonpoint source pollution control linked deposit program in accordance with this subchapter.
(b) An eligible lending institution may participate in the program established under this section as provided by this subchapter.
Added by Acts 2003, 78th Leg., ch. 200, Sec. 19(d), eff. Sept. 1, 2003; Acts 2003, 78th Leg., ch. 352, Sec. 4, eff. Sept. 1, 2003.
