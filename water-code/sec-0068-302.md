# Sec. 68.302. PROPOSED ASSESSMENTS.
A security project or security service may be financed under this chapter after a hearing notice given as required by this subchapter and a public hearing by the board on the advisability of:
(1) the security project or security service; and
(2) the proposed assessments.
Added by Acts 2007, 80th Leg., R.S., Ch. 913 (H.B. 3011), Sec. 1, eff. June 15, 2007.
