# Sec. 7.143. VIOLATION OF MINIMUM STATE STANDARDS OR MODEL POLITICAL SUBDIVISION RULES.
(a) A person commits an offense if the person knowingly or intentionally violates a rule adopted under Subchapter J, Chapter 16.
(b) An offense under this section is a Class A misdemeanor.
Added by Acts 1997, 75th Leg., ch. 1072, Sec. 2, eff. Sept. 1, 1997.
