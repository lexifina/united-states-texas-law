# Sec. 51.160. ENGINEERING DATA UNNECESSARY.
If a district contracts with the United States under the provisions of Section 51.155 of this code for use by the district of federal reclamation works, the district need not prepare or file any engineering data for the construction of the works.
Acts 1971, 62nd Leg., p. 110, ch. 58, Sec. 1, eff. Aug. 30, 1971.
