# Sec. 7.1831. VIOLATION OF LOCALLY ENFORCED MOTOR VEHICLE IDLING LIMITATIONS.
(a) A person commits an offense if the person violates a rule adopted by the commission concerning locally enforced motor vehicle idling limitations.
(b) Notwithstanding any other law, an offense under this section is a Class C misdemeanor.
Added by Acts 2011, 82nd Leg., R.S., Ch. 294 (H.B. 1906), Sec. 1, eff. September 1, 2011.
