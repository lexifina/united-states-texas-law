# Sec. 36.402. APPLICABILITY.
Except as provided by Section 36.416, this subchapter applies to the notice and hearing process used by a district for permit and permit amendment applications for which a hearing is required.
Added by Acts 2005, 79th Leg., Ch. 970 (H.B. 1763), Sec. 17, eff. September 1, 2005.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 308 (S.B. 854), Sec. 5, eff. September 1, 2015.
