# Sec. 11.560. COLORADO RIVER BASIN WATERMASTER PROGRAM.
If a watermaster program is established for the entire Colorado River Basin, the Concho River Watermaster Program is discontinued, and the area described by Section 11.553 is under the jurisdiction of the watermaster for the Colorado River Basin Watermaster Program.
Added by Acts 2005, 79th Leg., Ch. 749 (H.B. 2815), Sec. 1, eff. September 1, 2005.
