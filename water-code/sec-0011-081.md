# Sec. 11.081. UNLAWFUL USE OF STATE WATER.
No person may wilfully take, divert, or appropriate any state water for any purpose without first complying with all applicable requirements of this chapter.
Amended by Acts 1977, 65th Leg., p. 2207, ch. 870, Sec. 1, eff. Sept. 1, 1977; Acts 1997, 75th Leg., ch. 1072, Sec. 3, eff. Sept. 1, 1997.
