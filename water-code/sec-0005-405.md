# Sec. 5.405. FEES.
(a) Except as provided by Subsection (b), the fee for a consolidated permit shall be computed as if the permits consolidated had been processed separately.
(b) The commission by rule may reduce the fee for a consolidated permit below the total amount that the applicant would have paid for processing the applications separately if the commission finds that consolidated processing results in savings to the agency.
Added by Acts 1997, 75th Leg., ch. 1373, Sec. 1, eff. Sept. 1, 1997.
