# Sec. 11.140. PERMITS FOR STORAGE FOR PROJECT DEVELOPMENT.
The commission may issue permits for storage solely for the purpose of optimum development of projects. The commission may convert these permits to permits for beneficial use if application to have them converted is made to the commission.
Amended by Acts 1977, 65th Leg., p. 2207, ch. 870, Sec. 1, eff. Sept. 1, 1977.
