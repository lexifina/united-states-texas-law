# Sec. 5.315. DISCOVERY IN CASES USING PREFILED WRITTEN TESTIMONY.
In a contested case hearing delegated by the commission to the State Office of Administrative Hearings that uses prefiled written testimony, all discovery must be completed before the deadline for the submission of that testimony.
Added by Acts 2011, 82nd Leg., R.S., Ch. 1021 (H.B. 2694), Sec. 10.03, eff. September 1, 2011.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 853 (S.B. 1148), Sec. 1, eff. September 1, 2015.
