# Sec. 27.155. REPORTING OF INJECTION AND RECOVERY VOLUMES.
(a) A project operator shall install a meter on each ASR injection well and ASR recovery well associated with the aquifer storage and recovery project.
(b) Each calendar month, the project operator shall provide to the commission a written or electronic report showing for the preceding calendar month the volume of water:
(1) injected for storage; and
(2) recovered for beneficial use.
Added by Acts 2015, 84th Leg., R.S., Ch. 505 (H.B. 655), Sec. 3, eff. June 16, 2015.
