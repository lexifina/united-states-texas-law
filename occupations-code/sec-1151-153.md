# Sec. 1151.153. REGISTRATION APPLICATION.
(a) An application for registration must be made on the printed form provided by the department. In prescribing the contents of an application form, the commission shall ensure that the form requires information sufficient to properly classify the applicant.
(b) Each application form the department provides must be accompanied by the code of ethics.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 2, eff. June 1, 2003.
Amended by:
Acts 2009, 81st Leg., R.S., Ch. 450 (H.B. 2447), Sec. 19, eff. September 1, 2009.
