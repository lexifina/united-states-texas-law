# Sec. 1001.005. APPLICATION OF SUNSET ACT.
The Texas Board of Professional Engineers and Land Surveyors is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the board is abolished and this chapter expires September 1, 2033.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 1, eff. June 1, 2003. Amended by Acts 2003, 78th Leg., ch. 1168, Sec. 2, eff. Sept. 1, 2003.
