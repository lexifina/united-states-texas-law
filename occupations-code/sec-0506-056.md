# Sec. 506.056. SUPERVISED EXPERIENCE.
This chapter does not apply to an unlicensed person pursuing supervised experience in applied behavior analysis if the supervised experience is consistent with the requirements of the certifying entity and commission rules.
Added by Acts 2017, 85th Leg., R.S., Ch. 1156 (S.B. 589), Sec. 2, eff. September 1, 2017.
