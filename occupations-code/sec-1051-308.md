# Sec. 1051.308. INTERN DEVELOPMENT PROGRAM.
The board shall allow a graduate student engineer enrolled in an accredited architectural professional degree program in this state to enroll concurrently in the intern development program required by board rules before an applicant may take the examination under this chapter.
Added by Acts 2011, 82nd Leg., R.S., Ch. 1157 (H.B. 2284), Sec. 3, eff. September 1, 2011.
