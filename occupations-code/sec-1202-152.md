# Sec. 1202.152. BUILDING CODE AMENDMENT.
If a code described by Section 1202.151 is amended after January 1, 1985, the requirements and standards of the amended code shall be used in place of the January 1, 1985, edition if the council determines that use of the amended code is:
(1) in the public interest; and
(2) consistent with the purposes of this chapter.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 2, eff. June 1, 2003.
