# Sec. 1103.352. APPLICATION FOR APPRAISER TRAINEE.
An applicant for a license as an appraiser trainee and each supervisory appraiser of the applicant must apply to the board using the online application on the board's Internet website or on a form prescribed by the board.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 2, eff. June 1, 2003.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 950 (S.B. 1007), Sec. 40, eff. January 1, 2016.
