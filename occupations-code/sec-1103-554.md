# Sec. 1103.554. CRIMINAL PENALTY FOR MISREPRESENTING QUALIFICATIONS.
(a) A person commits an offense if the person knowingly violates Section 1103.401.
(b) An offense under this section is a Class B misdemeanor.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 2, eff. June 1, 2003. Amended by Acts 2003, 78th Leg., ch. 106, Sec. 8, eff. Sept. 1, 2003.
Amended by:
Acts 2023, 88th Leg., R.S., Ch. 55 (S.B. 1222), Sec. 3, eff. September 1, 2023.
