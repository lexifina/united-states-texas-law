# Sec. 602.301. INJUNCTION.
The medical board shall prosecute or file suit to enjoin a violation of this chapter or a rule adopted under this chapter.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 838 (S.B. 202), Sec. 2.086, eff. September 1, 2015.
