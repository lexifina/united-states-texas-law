# Sec. 151.004. APPLICATION OF SUNSET ACT.
The Texas Medical Board is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the board is abolished and this subtitle and Chapters 204, 205, 206, 601, 602, 603, and 604 expire September 1, 2033.
