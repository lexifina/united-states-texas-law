# Sec. 2309.155. NONTRANSFERABILITY OF LICENSE.
A license issued by the executive director is valid throughout this state and is not transferable.
Added by Acts 2009, 81st Leg., R.S., Ch. 783 (S.B. 1095), Sec. 7, eff. September 1, 2009.
