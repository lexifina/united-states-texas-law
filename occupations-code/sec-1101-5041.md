# Sec. 1101.5041. CRIMINAL HISTORY RECORD INFORMATION REQUIREMENT FOR CERTIFICATE.
An applicant for an original certificate of registration as an easement or right-of-way agent or renewal of a certificate of registration as an easement or right-of-way agent must comply with the criminal history record check requirements of Section 1101.3521.
Added by Acts 2011, 82nd Leg., R.S., Ch. 676 (S.B. 1812), Sec. 1, eff. September 1, 2011.
