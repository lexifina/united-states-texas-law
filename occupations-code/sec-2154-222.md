# Sec. 2154.222. SALES DISPLAY AREA.
The sales display area of an indoor retail fireworks site must be sufficiently designed to prevent customers from handling fireworks unless an attendant is directly assisting the customer.
Added by Acts 2017, 85th Leg., R.S., Ch. 374 (H.B. 3907), Sec. 3, eff. June 1, 2017.
