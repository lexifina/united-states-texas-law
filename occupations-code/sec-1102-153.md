# Sec. 1102.153. DEADLINE FOR COMPLETION.
A license applicant who does not satisfy the examination requirement before the first anniversary of the date the application is filed must submit a new application and pay another examination fee to be eligible for examination.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 2, eff. June 1, 2003.
Amended by:
Acts 2013, 83rd Leg., R.S., Ch. 698 (H.B. 2911), Sec. 8, eff. September 1, 2013.
