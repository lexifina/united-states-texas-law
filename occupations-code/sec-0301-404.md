# Sec. 301.404. DUTY OF NURSING EDUCATIONAL PROGRAM TO REPORT.
A nursing educational program that has reasonable cause to suspect that the ability of a nursing student to perform the services of the nursing profession would be, or would reasonably be expected to be, impaired by chemical dependency shall file with the board a written, signed report that includes the identity of the student and any additional information the board requires.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999. Amended by Acts 2003, 78th Leg., ch. 553, Sec. 1.032, eff. Sept. 1, 2003.
