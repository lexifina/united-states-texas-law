# Sec. 1301.055. LP GAS INSTALLERS.
A person is not required to be licensed under this chapter to perform LPG system installation if the person performs the LPG system installation as an LP gas installer licensed under Subchapter D, Chapter 113, Natural Resources Code.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 3, eff. June 1, 2003. Amended by Acts 2003, 78th Leg., ch. 1276, Sec. 14A.303(a), eff. Sept. 1, 2003.
