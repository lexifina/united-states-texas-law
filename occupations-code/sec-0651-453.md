# Sec. 651.453. UNETHICAL ADVERTISING.
A person violates this chapter if the person uses an advertising statement of a character that misleads or deceives the public or uses, in connection with an advertisement, the name of a person who is falsely represented to be a license holder.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
