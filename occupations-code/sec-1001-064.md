# Sec. 1001.064. STATE LAND SURVEYORS.
A licensed state land surveyor is exempt from the requirements of this chapter regulating the practice of engineering in performing the state land surveyor's duties.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 1, eff. June 1, 2003.
Amended by:
Acts 2019, 86th Leg., R.S., Ch. 1232 (H.B. 1523), Sec. 1.05, eff. September 1, 2019.
