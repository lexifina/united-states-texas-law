# Sec. 651.002. APPLICATION OF SUNSET ACT.
The Texas Funeral Service Commission is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the commission is abolished and this chapter expires September 1, 2031.
