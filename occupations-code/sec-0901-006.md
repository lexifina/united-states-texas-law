# Sec. 901.006. APPLICATION OF SUNSET ACT.
The Texas State Board of Public Accountancy is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the board is abolished and this chapter expires September 1, 2033.
