# Sec. 2153.258. CRIMINAL OFFENSE; VIOLATION OF SUBCHAPTER.
(a) A person commits an offense if the person violates this subchapter.
(b) Repealed by Acts 2005, 79th Leg., Ch. 1018, Sec. 7.05, eff. September 1, 2005.
(c) An offense under this section is a Class C misdemeanor.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2005, 79th Leg., Ch. 1018 (H.B. 955), Sec. 7.05, eff. September 1, 2005.
