# Sec. 558.153. PROCESSING OF LICENSE APPLICATION.
The board must complete the processing of a provisional license holder's application for a license not later than the 180th day after the date the provisional license is issued or at the time licenses are issued following the successful completion of the examination, whichever date is later.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
