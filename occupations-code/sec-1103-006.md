# Sec. 1103.006. APPLICATION OF SUNSET ACT.
The Texas Appraiser Licensing and Certification Board is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the board is abolished and this chapter and Chapter 1104 expire September 1, 2033.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 2, eff. June 1, 2003.
