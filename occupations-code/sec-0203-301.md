# Sec. 203.301. APPLICATION FOR LICENSE RENEWAL.
An applicant for renewal of a license under this chapter must apply biennially as provided in Section 203.253.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2005, 79th Leg., Ch. 1240 (H.B. 1535), Sec. 34, eff. September 1, 2005.
