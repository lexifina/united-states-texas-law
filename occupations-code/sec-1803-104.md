# Sec. 1803.104. FAILURE TO FILE TIMELY REPORT.
A public safety entity or public safety publication that fails to timely file the information required by this chapter or that files information required by this chapter that is found to contain material misrepresentation may not use a public safety solicitor until it provides or corrects the information.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
