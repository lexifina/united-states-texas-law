# Sec. 109.001. DEFINITIONS.
In this chapter:
(1) "Administration of criminal justice" and "criminal justice agency" have the meanings assigned by Article 66.001, Code of Criminal Procedure.
(2) "Local law enforcement authority" has the meaning assigned by Article 62.001, Code of Criminal Procedure.
(3) "Sex offender" has the meaning assigned by Article 42A.251(2), Code of Criminal Procedure.
Added by Acts 2003, 78th Leg., ch. 1276, Sec. 14.004(a), eff. Sept. 1, 2003.
