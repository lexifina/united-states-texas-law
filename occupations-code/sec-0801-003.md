# Sec. 801.003. APPLICATION OF SUNSET ACT.
The State Board of Veterinary Medical Examiners is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the board is abolished September 1, 2033.
