# Sec. 205.059. COMPENSATION; PER DIEM.
An acupuncture board member may not receive compensation for service on the acupuncture board but is entitled to receive a per diem as set by legislative appropriation for transportation and related expenses incurred for each day that the member engages in the acupuncture board's business.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
