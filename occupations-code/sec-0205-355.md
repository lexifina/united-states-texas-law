# Sec. 205.355. REQUIRED DISCIPLINARY ACTION FOR FAILURE TO OBTAIN REFERRAL.
Except as provided by Section 205.301(a)(2), a license to practice acupuncture shall be denied or, after notice and hearing, revoked if the applicant or license holder violates Section 205.301(a)(1).
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
