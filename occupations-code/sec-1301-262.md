# Sec. 1301.262. PLUMBING INSPECTOR CODE OF CONDUCT.
The board by rule shall establish a code of conduct for licensed plumbing inspectors. The code of conduct shall require a plumbing inspector to enforce this chapter and board rules in a consistent manner across job sites.
Added by Acts 2003, 78th Leg., ch. 819, Sec. 13, eff. Sept. 1, 2003.
