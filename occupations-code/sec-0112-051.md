# Sec. 112.051. REDUCED LICENSE REQUIREMENTS FOR RETIRED HEALTH CARE PRACTITIONERS PERFORMING CHARITY WORK.
(a) Each licensing entity shall adopt rules providing for reduced fees and continuing education requirements for a retired health care practitioner whose only practice is voluntary charity care.
(b) The licensing entity by rule shall define voluntary charity care.
Added by Acts 2005, 79th Leg., Ch. 1136 (H.B. 2680), Sec. 1, eff. June 18, 2005.
