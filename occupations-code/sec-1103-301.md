# Sec. 1103.301. REGISTRATION REQUIRED.
A person certified or licensed as a real estate appraiser by another state may appraise real property in this state without holding a certificate or license issued under this chapter if the person registers with the board under this subchapter.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 2, eff. June 1, 2003.
