# Sec. 1952.003. EMPLOYMENT OF REGISTERED INDIVIDUAL NOT REQUIRED.
This state or a political subdivision of this state may engage in code enforcement without employing an individual registered under this chapter, if the individual who is engaging in code enforcement for the state or political subdivision is exempt from registration under Section 1952.002.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 4, eff. June 1, 2003.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 1112 (H.B. 4765), Sec. 3, eff. September 1, 2025.
