# Sec. 1101.554. COPY OF SALES AGENT LICENSE.
The commission shall deliver a copy of each sales agent license to the broker that is sponsoring the sales agent.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 2, eff. June 1, 2003.
Amended by:
Acts 2011, 82nd Leg., R.S., Ch. 1064 (S.B. 747), Sec. 22, eff. September 1, 2011.
Acts 2015, 84th Leg., R.S., Ch. 1158 (S.B. 699), Sec. 57, eff. January 1, 2016.
