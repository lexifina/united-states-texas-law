# Sec. 204.051. TEXAS PHYSICIAN ASSISTANT BOARD.
(a) The Texas Physician Assistant Board is an advisory board to the Texas State Board of Medical Examiners.
(b) A reference in any other law to the former Texas State Board of Physician Assistant Examiners means the Texas Physician Assistant Board.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2005, 79th Leg., Ch. 269 (S.B. 419), Sec. 2.03, eff. September 1, 2005.
