# Sec. 455.153. APPLICATION FOR LICENSE.
An applicant for a license under this chapter must:
(1) submit an application in the manner and on a form prescribed by the executive director;
(2) pass any required examination; and
(3) include with the application the application fee set by the commission by rule.
