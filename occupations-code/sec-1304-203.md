# Sec. 1304.203. MULTIPLE VIOLATIONS.
For purposes of this subchapter, violations are of a similar nature if the violations consist of the same or a similar course of conduct, action, or practice, regardless of the number of times the conduct, act, or practice occurred.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 3, eff. June 1, 2003.
