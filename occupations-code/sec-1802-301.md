# Sec. 1802.301. PRACTICING WITHOUT LICENSE; OFFENSE.
(a) A person commits an offense if the person acts as an auctioneer or an associate auctioneer without a license.
(b) An offense under this section is a Class B misdemeanor.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2023, 88th Leg., R.S., Ch. 626 (H.B. 4416), Sec. 25, eff. September 1, 2023.
