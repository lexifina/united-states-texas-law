# Sec. 604.212. LIMIT ON ACCESS TO INVESTIGATION FILES.
The advisory board shall prohibit or limit access to an investigation file relating to a person subject to an informal proceeding in the manner provided by Sections 164.007(c) and 604.175.
Added by Acts 2015, 84th Leg., R.S., Ch. 838 (S.B. 202), Sec. 2.186, eff. September 1, 2015.
