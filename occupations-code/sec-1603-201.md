# Sec. 1603.201. APPLICATION FORM.
An application for a license or permit under this chapter must be made on a form prescribed by the department.
Added by Acts 2005, 79th Leg., Ch. 798 (S.B. 411), Sec. 1.01, eff. September 1, 2005.
Amended by:
Acts 2021, 87th Leg., R.S., Ch. 663 (H.B. 1560), Sec. 3.14, eff. September 1, 2021.
