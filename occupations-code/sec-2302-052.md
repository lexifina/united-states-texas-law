# Sec. 2302.052. DUTY TO SET FEES.
The board shall set application fees, license fees, renewal fees, and other fees as required to implement this chapter. The board shall set the fees in amounts reasonable and necessary to implement and enforce this chapter.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 5, eff. June 1, 2003. Amended by Acts 2003, 78th Leg., ch. 1325, Sec. 17.05, eff. Sept. 1, 2003.
Amended by:
