# Sec. 2021.009. PROHIBITED USE OF STATE APPROPRIATED FUNDS.
This subtitle prohibits the use of state appropriated funds for capital improvements to racetracks or for interest payments on such facilities except for racetracks that were publicly owned on September 1, 1986.
Added by Acts 2019, 86th Leg., R.S., Ch. 467 (H.B. 4170), Sec. 18.003(a), eff. September 1, 2019.
