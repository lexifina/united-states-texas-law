# Sec. 112.102. APPLICABILITY.
(a) Except as provided by Subsection (b), this subchapter applies only to a licensing entity that issues a license to a health care practitioner under this title.
(b) This subchapter does not apply to Subtitle L.
Added by Acts 2025, 89th Leg., R.S., Ch. 354 (S.B. 912), Sec. 2, eff. September 1, 2025.
