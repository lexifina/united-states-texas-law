# Sec. 501.252. PSYCHOLOGIST LICENSE APPLICATION.
(a) To be licensed under this chapter, a person must apply to the executive council for a license. The executive council shall issue a license to an applicant who:
(1) is qualified for the license under Section 501.2525; and
(2) pays the fee set by the executive council.
