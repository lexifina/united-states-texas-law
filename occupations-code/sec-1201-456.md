# Sec. 1201.456. HABITABILITY: EXCEPTION TO WARRANTY REQUIREMENT.
The warranty requirement imposed by Section 1201.455 does not apply to a sale or exchange of a used manufactured home from one consumer to another.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 2, eff. June 1, 2003.
Amended by:
Acts 2017, 85th Leg., R.S., Ch. 408 (H.B. 2019), Sec. 62, eff. September 1, 2017.
