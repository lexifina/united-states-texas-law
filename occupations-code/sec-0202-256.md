# Sec. 202.256. REEXAMINATION.
(a) An applicant who fails an examination and is refused a license based on that failure may retake the examination. The applicant must pay the regular examination fee for any reexamination.
(b) Each reexamination must cover each subject tested in Section 202.254(d).
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
