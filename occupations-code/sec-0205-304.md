# Sec. 205.304. PROFESSIONAL REVIEW ACTION.
Sections 160.002, 160.003, 160.006, 160.007(d), 160.013, 160.014, and 160.015 apply to professional review actions relating to the practice of acupuncture by an acupuncturist or acupuncturist student.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999. Amended by Acts 2001, 77th Leg., ch. 1420, Sec. 14.060, eff. Sept. 1, 2001.
