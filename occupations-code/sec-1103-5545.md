# Sec. 1103.5545. CRIMINAL PENALTY FOR ENGAGING IN ACTIVITY WITHOUT REQUIRED CERTIFICATE OR LICENSE.
(a) A person commits an offense if the person engages in an activity for which a certificate or license is required under this chapter without holding a certificate or license.
(b) An offense under this section is a Class A misdemeanor.
Added by Acts 2003, 78th Leg., ch. 106, Sec. 9, eff. Sept. 1, 2003.
