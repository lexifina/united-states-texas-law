# Sec. 603.402. CONTESTED CASE HEARING.
Chapter 2001, Government Code, and medical board rules for a contested case hearing apply to a proceeding by the medical board under this chapter in which a formal complaint has been filed.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
