# Sec. 2001.312. FAILURE TO FILE FEE REPORTS.
A person is not eligible for a license or a license renewal unless all required reports and requested information have been filed under this chapter.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 1255 (H.B. 1905), Sec. 4, eff. September 1, 2015.
