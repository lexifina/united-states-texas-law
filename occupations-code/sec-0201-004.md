# Sec. 201.004. APPLICATION OF SUNSET ACT.
The Texas Board of Chiropractic Examiners is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the board is abolished and this chapter expires September 1, 2033.
