# Sec. 205.201. LICENSE REQUIRED.
Except as provided by Section 205.303, a person may not practice acupuncture in this state unless the person holds a license to practice acupuncture issued by the acupuncture board under this chapter.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2005, 79th Leg., Ch. 269 (S.B. 419), Sec. 3.12, eff. September 1, 2005.
