# Sec. 454.003. APPLICATION OF SUNSET ACT.
The Texas Board of Occupational Therapy Examiners is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the board is abolished and this chapter expires September 1, 2033.
