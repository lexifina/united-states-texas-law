# Sec. 1103.255. EXPERIENCE REQUIRED BEFORE TAKING EXAMINATION.
An applicant for the examination must fulfill the applicable experience requirement for a certificate or license before taking the examination.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 2, eff. June 1, 2003.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 950 (S.B. 1007), Sec. 35, eff. January 1, 2016.
