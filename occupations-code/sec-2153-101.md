# Sec. 2153.101. INFORMATION FROM LICENSE APPLICATION.
(a) Except as provided by Subsection (b), information contained in a license application is confidential.
(b) After a license is issued under this chapter, the ownership statement contained in the license application is a public record.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
