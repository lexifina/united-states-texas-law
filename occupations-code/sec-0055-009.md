# Sec. 55.009. LICENSE APPLICATION AND EXAMINATION FEES.
Notwithstanding any other law, a state agency that issues a license shall waive the license application and examination fees paid to the state for an applicant who is a military service member, military veteran, or military spouse.
Added by Acts 2015, 84th Leg., R.S., Ch. 328 (S.B. 807), Sec. 1, eff. September 1, 2015.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 686 (H.B. 5629), Sec. 5, eff. September 1, 2025.
