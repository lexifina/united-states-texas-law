# Sec. 1071.304. NOTICE OF FAILURE TO RENEW STATE LAND SURVEYOR LICENSE.
The executive director shall immediately notify the commissioner when the license of a licensed state land surveyor expires due to the person's failure to timely renew the license.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 1, eff. June 1, 2003.
