# Sec. 1103.256. MINIMUM PASSING GRADE REQUIRED.
To pass the examination, an applicant for a certificate or license must achieve the minimum score required by the Appraiser Qualifications Board.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 2, eff. June 1, 2003.
Amended by:
Acts 2005, 79th Leg., Ch. 703 (S.B. 381), Sec. 14, eff. September 1, 2005.
