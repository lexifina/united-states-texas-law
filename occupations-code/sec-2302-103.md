# Sec. 2302.103. APPLICATION FOR SALVAGE VEHICLE DEALER LICENSE.
To apply for a salvage vehicle dealer license, a person must submit to the department an application on a form prescribed by the department and the application fee.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 5, eff. June 1, 2003.
