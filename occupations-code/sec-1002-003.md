# Sec. 1002.003. APPLICATION OF SUNSET ACT.
The Texas Board of Professional Geoscientists is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the board is abolished and this chapter expires September 1, 2033.
Added by Acts 2003, 78th Leg., ch. 1276, Sec. 14A.004(a), eff. Sept. 1, 2003.
