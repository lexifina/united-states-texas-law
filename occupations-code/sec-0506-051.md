# Sec. 506.051. LICENSED PSYCHOLOGISTS.
This chapter does not apply to a person licensed to practice psychology in this state if the applied behavior analysis services provided are within the scope of the licensed psychologist's education, training, and competence.
Added by Acts 2017, 85th Leg., R.S., Ch. 1156 (S.B. 589), Sec. 2, eff. September 1, 2017.
