# Sec. 1151.055. COMPENSATION; REIMBURSEMENT.
A board member may not receive compensation for the member's services.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 2, eff. June 1, 2003.
Amended by:
Acts 2009, 81st Leg., R.S., Ch. 450 (H.B. 2447), Sec. 8, eff. September 1, 2009.
