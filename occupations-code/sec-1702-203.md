# Sec. 1702.203. APPLICATION FOR PERSONAL PROTECTION OFFICER LICENSE.
An applicant for a personal protection officer license must submit a written application on a form prescribed by the commission.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999. Amended by Acts 2001, 77th Leg., ch. 1420, Sec. 14.622, eff. Sept. 1, 2001.
