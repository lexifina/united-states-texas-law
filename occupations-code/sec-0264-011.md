# Sec. 264.011. INFORMAL ASSESSMENT OF ADMINISTRATIVE PENALTY.
This subchapter does not prevent the board from assessing an administrative penalty using an informal proceeding under Section 263.007.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2017, 85th Leg., R.S., Ch. 295 (S.B. 313), Sec. 36, eff. September 1, 2017.
