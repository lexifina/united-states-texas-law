# Sec. 701.252. LICENSE APPLICATION.
(a) Each applicant for a dietitian license must submit an application in the manner and on a form prescribed by the executive director accompanied by the application fee.
(b) The commission by rule shall determine the information and documentation required to be submitted as part of an application.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 838 (S.B. 202), Sec. 1.205, eff. September 1, 2015.
