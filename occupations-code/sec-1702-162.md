# Sec. 1702.162. EMPLOYER'S APPLICATION FOR SECURITY OFFICER COMMISSION.
The employer of a security officer who applies for a security officer commission for the officer must submit an application to the department on a form provided by the department.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999. Amended by Acts 2001, 77th Leg., ch. 1420, Sec. 14.611, eff. Sept. 1, 2001.
