# Sec. 1603.253. WRITTEN EXAMINATION.
The department shall select an examination for each written examination required under this chapter. The written examination must be:
(1) validated by an independent testing professional; or
(2) purchased from a national testing service.
Added by Acts 2005, 79th Leg., Ch. 798 (S.B. 411), Sec. 1.01, eff. September 1, 2005.
Amended by:
Acts 2021, 87th Leg., R.S., Ch. 663 (H.B. 1560), Sec. 3.22, eff. September 1, 2021.
