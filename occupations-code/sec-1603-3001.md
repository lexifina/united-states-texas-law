# Sec. 1603.3001. LICENSE TERMS.
(a) Except as provided by Subsection (b), a license other than a temporary license expires on the second anniversary of the date the license is issued.
(b) A school license expires on the first anniversary of the date the license is issued.
Added by Acts 2021, 87th Leg., R.S., Ch. 663 (H.B. 1560), Sec. 3.24, eff. September 1, 2021.
