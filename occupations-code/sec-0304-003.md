# Sec. 304.003. RULES.
The Texas Board of Nursing may adopt rules necessary to implement this chapter.
Added by Acts 2001, 77th Leg., ch. 1420, Sec. 14.130(a), eff. Sept. 1, 2001. Amended by Acts 2003, 78th Leg., ch. 553, Sec. 2.023, eff. Feb. 1, 2004.
Amended by:
Acts 2007, 80th Leg., R.S., Ch. 889 (H.B. 2426), Sec. 39, eff. September 1, 2007.
