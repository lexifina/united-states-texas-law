# Sec. 1051.003. APPLICATION OF SUNSET ACT.
The Texas Board of Architectural Examiners is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the board is abolished and this subtitle expires September 1, 2033.
Added by Acts 2001, 77th Leg., ch. 1421, Sec. 1, eff. June 1, 2003; Renumbered from Occupations Code Sec. 1051.004 and amended by Acts 2003, 78th, ch. 331, Sec. 1.04, eff. Sept. 1, 2003.
