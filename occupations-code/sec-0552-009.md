# Sec. 552.009. PER DIEM; REIMBURSEMENT.
(a) Each member of the board is entitled to a per diem set by legislative appropriation for each day the member engages in board business.
(b) A member is entitled to reimbursement for travel expenses as prescribed by the General Appropriations Act.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2005, 79th Leg., Ch. 1345 (S.B. 410), Sec. 6, eff. September 1, 2005.
