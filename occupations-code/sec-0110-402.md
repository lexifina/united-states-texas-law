# Sec. 110.402. OFFENSE: RELEASE OF ADJUDICATION INFORMATION.
(a) A person commits an offense if the person releases or discloses in violation of Section 110.156 adjudication information received by the council.
(b) An offense under this section is a Class A misdemeanor.
Added by Acts 2003, 78th Leg., ch. 1276, Sec. 14.005(a), eff. Sept. 1, 2003.
