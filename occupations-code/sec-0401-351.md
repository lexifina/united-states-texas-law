# Sec. 401.351. LICENSE TERM.
A license issued under this chapter is valid for two years.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 1 (S.B. 219), Sec. 5.048, eff. April 2, 2015.
