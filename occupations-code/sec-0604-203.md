# Sec. 604.203. ADMINISTRATIVE PROCEDURE FOR CONTESTED CASE HEARING.
For a contested case hearing in which a formal complaint has been filed under this chapter, the procedure by which the advisory board takes a disciplinary action and the procedure by which a disciplinary action is appealed are governed by:
(1) advisory board rules for a contested case hearing; and
(2) Chapter 2001, Government Code.
Acts 1999, 76th Leg., ch. 388, Sec. 1, eff. Sept. 1, 1999.
