# Sec. 551.005. APPLICATION OF SUNSET ACT.
The Texas State Board of Pharmacy is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the board is abolished and this subtitle expires September 1, 2033.
