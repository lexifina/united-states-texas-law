# Sec. 505.507. CRIMINAL PENALTY.
(a) A person commits an offense if the person knowingly acts as a social worker without holding a license required under this chapter.
(b) An offense under Subsection (a) is a Class B misdemeanor.
Added by Acts 2003, 78th Leg., ch. 892, Sec. 19, eff. Sept. 1, 2003.
