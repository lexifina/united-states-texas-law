# Sec. 14A.060. QUESTIONNAIRE.
To implement this chapter, a court may develop, for use in that court, a questionnaire to be filed by the civilly committed individual.
Added by Acts 2023, 88th Leg., R.S., Ch. 203 (S.B. 1180), Sec. 1, eff. May 24, 2023.
Added by Acts 2023, 88th Leg., R.S., Ch. 351 (S.B. 1179), Sec. 10, eff. September 1, 2023.
