# Sec. 113.006. NO WAIVER OF IMMUNITY TO SUIT FOR TORT LIABILITY.
This chapter does not waive sovereign immunity to suit for a cause of action for a negligent or intentional tort.
Added by Acts 2013, 83rd Leg., R.S., Ch. 1138 (H.B. 3511), Sec. 1, eff. June 14, 2013.
