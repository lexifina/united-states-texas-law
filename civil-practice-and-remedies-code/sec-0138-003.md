# Sec. 138.003. PLEADINGS.
In an action described in Section 138.002(b)(1), the initiating petition must state with particularity:
(1) the federal and state statutes allegedly violated; and
(2) the facts that are alleged to have proximately caused the injury claimed.
Added by Acts 2005, 79th Leg., Ch. 906 (H.B. 107), Sec. 1, eff. June 18, 2005.
