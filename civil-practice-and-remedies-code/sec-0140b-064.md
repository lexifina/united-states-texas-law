# Sec. 140B.064. NONEXCLUSIVE PROCEDURES.
Nothing in this chapter precludes the attorney general or local prosecutor from using any procedure not specified in this chapter in conducting a racketeering investigation.
Added by Acts 2023, 88th Leg., R.S., Ch. 885 (H.B. 4635), Sec. 2, eff. September 1, 2023.
