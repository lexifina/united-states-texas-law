# Sec. 671A.003. CRIMINAL PENALTY FOR FAILURE TO POST NOTICE.
(a) A private autopsy facility commits an offense if the facility fails to post the notice required by this chapter.
(b) An offense under this section is a Class C misdemeanor.
Added by Acts 2011, 82nd Leg., R.S., Ch. 374 (S.B. 256), Sec. 1, eff. September 1, 2011.
