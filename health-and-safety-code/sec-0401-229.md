# Sec. 401.229. APPLICATION PROCESSING FEE.
An application for a compact waste disposal facility license must include payment to the commission of an application processing fee of $500,000. The commission may not review an application for administrative completeness until the commission receives the application processing fee. The application processing fee is nonrefundable. If the commission's costs in processing an application under this subchapter exceed the $500,000 application processing fee, the commission may assess and collect additional fees from the applicant to recover the costs. Recoverable costs include costs incurred by the commission for administrative review, technical review, and hearings associated with the application.
Added by Acts 2003, 78th Leg., ch. 1067, Sec. 7, eff. Sept. 1, 2003.
