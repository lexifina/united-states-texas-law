# Sec. 403.004. COMPENSATION.
A host state commissioner is not entitled to compensation for performing the duties of host state commissioner but is entitled to reimbursement for actual and necessary expenses incurred in the performance of the duties of host state commissioner.
Added by Acts 1993, 73rd Leg., ch. 460, Sec. 1, eff. Aug. 30, 1993.
Amended by:
Acts 2011, 82nd Leg., R.S., Ch. 1102 (S.B. 1605), Sec. 3, eff. September 1, 2011.
