# Sec. 327.002. PUBLIC AVAILABILITY OF PRICE INFORMATION REQUIRED.
Notwithstanding any other law, a facility must make public:
(1) a digital file in a machine-readable format that contains a list of all standard charges for all facility items or services as described by Section 327.003; and
(2) a consumer-friendly list of standard charges for a limited set of shoppable services as provided in Section 327.004.
Added by Acts 2021, 87th Leg., R.S., Ch. 1044 (S.B. 1137), Sec. 1, eff. September 1, 2021.
