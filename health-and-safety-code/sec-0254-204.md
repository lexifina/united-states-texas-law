# Sec. 254.204. CRIMINAL PENALTY.
(a) A person commits an offense if the person violates Section 254.051.
(b) An offense under this section is a Class C misdemeanor.
(c) Each day of a continuing violation constitutes a separate offense.
Added by Acts 2009, 81st Leg., R.S., Ch. 1273 (H.B. 1357), Sec. 1, eff. September 1, 2010.
