# Sec. 1.006. REPORTS.
Notwithstanding any other law, each report that is required by this code to be submitted to the governor or a member of the legislature must be submitted not later than December 1 of the year that the report is due.
Added by Acts 2025, 89th Leg., R.S., Ch. 664 (H.B. 4666), Sec. 11, eff. June 20, 2025.
