# Sec. 110.006. REPORT.
Not later than December 1 of each even-numbered year, the task force shall submit to the legislature a report that includes:
(1) a summary of civil or criminal actions brought on behalf of the state and administrative actions by state regulatory agencies in the preceding biennium for conduct that violates Chapter 164 of this code or Chapter 102, Occupations Code; and
(2) legislative recommendations for preventing conduct that violates Chapter 164 of this code or Chapter 102, Occupations Code, and improving enforcement of those chapters.
Added by Acts 2025, 89th Leg., R.S., Ch. 527 (H.B. 4454), Sec. 1, eff. September 1, 2025.
