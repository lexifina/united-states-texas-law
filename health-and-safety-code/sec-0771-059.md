# Sec. 771.059. TARGET DATE FOR STATEWIDE NEXT GENERATION 9-1-1 SERVICE.
Before September 1, 2025, all parts of the state must be covered by next generation 9-1-1 service.
Acts 1989, 71st Leg., ch. 678, Sec. 1, eff. Sept. 1, 1989.
Amended by:
Acts 2021, 87th Leg., R.S., Ch. 830 (H.B. 2911), Sec. 2, eff. September 1, 2021.
