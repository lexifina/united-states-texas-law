# Sec. 442A.002. PRESCRIPTION DRUG SAFE DISPOSAL PILOT PROGRAM.
The board by rule shall develop and implement a prescription drug safe disposal pilot program to increase the number of locations in this state where unused, unwanted, or expired prescription drugs are collected from the public for safe disposal.
Added by Acts 2023, 88th Leg., R.S., Ch. 293 (S.B. 2173), Sec. 1, eff. September 1, 2023.
