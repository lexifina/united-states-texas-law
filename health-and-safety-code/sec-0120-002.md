# Sec. 120.002. SUNSET PROVISION.
The task force is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the task force is abolished and this chapter expires September 1, 2029.
Added by Acts 2017, 85th Leg., R.S., Ch. 754 (S.B. 1680), Sec. 1, eff. September 1, 2017.
