# Sec. 247.0441. LICENSE REQUIRED; CRIMINAL PENALTY.
(a) A person commits an offense if the person operates an assisted living facility without holding a license issued under this chapter.
(b) An offense under this section is a Class A misdemeanor, except the offense is a felony of the third degree if the person has been previously convicted of an offense under this section.
Added by Acts 2025, 89th Leg., R.S., Ch. 410 (H.B. 2510), Sec. 2, eff. September 1, 2025.
