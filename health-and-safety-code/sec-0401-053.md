# Sec. 401.053. CLASSIFICATION SYSTEM FOR LOW-LEVEL RADIOACTIVE WASTE.
The department may establish a classification system for low-level radioactive waste that is based on radiological, chemical, and biological characteristics and on physical state so that low-level radioactive waste can be managed safely and compatibly.
Acts 1989, 71st Leg., ch. 678, Sec. 1, eff. Sept. 1, 1989. Amended by Acts 1999, 76th Leg., ch. 1367, Sec. 4, eff. Sept. 1, 1999.
