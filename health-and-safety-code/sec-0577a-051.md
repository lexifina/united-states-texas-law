# Sec. 577A.051. VOLUNTARY QUALITY STANDARDS CERTIFICATION.
The commission shall, using existing resources to the extent feasible, develop and implement a voluntary quality standards certification process to certify a psychiatric residential youth treatment facility that meets standards for certification under this chapter.
Added by Acts 2021, 87th Leg., R.S., Ch. 1032 (H.B. 3121), Sec. 2, eff. September 1, 2021.
