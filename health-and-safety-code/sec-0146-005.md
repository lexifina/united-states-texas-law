# Sec. 146.005. FEES.
The executive commissioner by rule shall set license and license renewal fees in amounts necessary to administer this chapter.
Added by Acts 1993, 73rd Leg., ch. 580, Sec. 1, eff. Sept. 1, 1993. Amended by Acts 2003, 78th Leg., ch. 1226, Sec. 4, eff. Sept. 1, 2003.
