# Sec. 194.001. REPORT OF MARRIAGE.
(a) The county clerk shall file with the vital statistics unit a copy of each completed marriage license application and a copy of any affidavit of an absent applicant submitted with an application. The clerk shall file the copies not later than the 90th day after the date of the application. The clerk may not collect a fee for filing the copies.
(b) The county clerk shall file with the vital statistics unit a copy of each declaration of informal marriage executed under Section 2.402, Family Code. The clerk shall file the copy not later than the 90th day after the date on which the declaration is executed.
