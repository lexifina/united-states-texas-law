# Sec. 110.002. PURPOSE.
The task force is established to study and make recommendations on preventing conduct that violates Chapter 164 of this code or Chapter 102, Occupations Code, and to improve enforcement of those chapters.
Added by Acts 2025, 89th Leg., R.S., Ch. 527 (H.B. 4454), Sec. 1, eff. September 1, 2025.
