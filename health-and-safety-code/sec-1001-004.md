# Sec. 1001.004. REFERENCES IN LAW MEANING DEPARTMENT.
In this code or any other law, a reference to the department in relation to a function described by Section 1001.002(c) means the department. A reference in law to the department in relation to any other function has the meaning assigned by Section 521.0002, Government Code.
Added by Acts 2015, 84th Leg., R.S., Ch. 837 (S.B. 200), Sec. 1.17, eff. September 1, 2017.
Amended by:
Acts 2023, 88th Leg., R.S., Ch. 769 (H.B. 4611), Sec. 2.66, eff. April 1, 2025.
