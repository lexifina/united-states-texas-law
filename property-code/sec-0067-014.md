# Sec. 67.014. CERTAIN RIGHTS OF OPERATOR NOT IMPAIRED.
This chapter does not impair an operator's right to be paid, set-off, or withhold funds from another interest owner as security for or in satisfaction of a debt or security interest.
Added by Acts 2021, 87th Leg., R.S., Ch. 284 (H.B. 3794), Sec. 4, eff. September 1, 2021.
