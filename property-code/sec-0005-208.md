# Sec. 5.208. VENUE.
Notwithstanding any other law, an action brought under this subchapter, other than an action brought by the attorney general, must be brought in the county in which the real property is located.
Added by Acts 2025, 89th Leg., R.S., Ch. 1094 (H.B. 4170), Sec. 1, eff. September 1, 2025.
