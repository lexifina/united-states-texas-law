# Sec. 53.238. NOTICE OF BOND.
The official with whom the bond is filed shall send an exact copy of the bond by certified mail, return receipt requested, to all claimants.
Acts 1983, 68th Leg., p. 3556, ch. 576, Sec. 1, eff. Jan. 1, 1984.
Amended by:
Acts 2021, 87th Leg., R.S., Ch. 690 (H.B. 2237), Sec. 31, eff. January 1, 2022.
