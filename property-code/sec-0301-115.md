# Sec. 301.115. ORDER IN PRECEDING FIVE YEARS.
If the commission issues an order against a respondent against whom another order was issued within the preceding five years under Section 301.112, the commission shall send a copy of each order to the attorney general.
Added by Acts 1993, 73rd Leg., ch. 268, Sec. 40, eff. Sept. 1, 1993.
