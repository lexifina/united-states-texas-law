# Sec. 5.005. ALIENS.
Except as provided by Subchapter H, an alien has the same real and personal property rights as a United States citizen.
Acts 1983, 68th Leg., p. 3481, ch. 576, Sec. 1, eff. Jan. 1, 1984.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 956 (S.B. 17), Sec. 3, eff. September 1, 2025.
