# Sec. 113.031. DIGITAL ASSETS.
(a) In this section, "digital asset" has the meaning assigned by Section 2001.002, Estates Code.
(b) A trustee may access digital assets as provided by Chapter 2001, Estates Code.
Added by Acts 2017, 85th Leg., R.S., Ch. 400 (S.B. 1193), Sec. 6, eff. September 1, 2017.
