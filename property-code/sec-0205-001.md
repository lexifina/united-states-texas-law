# Sec. 205.001. DEFINITIONS.
In this chapter:
(1) "Restrictions" and "subdivision" have the meanings assigned by Section 201.003.
(2) "Property owners' association" has the meaning assigned by Section 202.001.
Added by Acts 1995, 74th Leg., ch. 1040, Sec. 3, eff. Aug. 28, 1995. Amended by Acts 1997, 75th Leg., ch. 451, Sec. 4, eff. Sept. 1, 1997.
