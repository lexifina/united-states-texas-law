# Sec. 141.009. RECEIPT FOR CUSTODIAL PROPERTY.
A written acknowledgment of delivery by a custodian constitutes a sufficient receipt and discharge for custodial property transferred to the custodian under this chapter.
Amended by Acts 1995, 74th Leg., ch. 1043, Sec. 1, eff. Sept. 1, 1995. Renumbered from Property Code Sec. 9 by Acts 1997, 75th Leg., ch. 165, Sec. 31.01(72), eff. Sept. 1, 1997.
