# Sec. 77.305. VENUE FOR PRE-COMPLIANCE REVIEW.
A person receiving a subpoena under this chapter may, before the return date specified in the subpoena, petition a district court in Travis County for an order to modify or quash the subpoena.
Added by Acts 2017, 85th Leg., R.S., Ch. 351 (H.B. 1866), Sec. 4, eff. September 1, 2017.
