# Sec. 67.007. PRIORITY IN RELATION TO OTHER LIENS OR SECURITY INTERESTS.
Except for a permitted lien, an oil and gas lien takes priority over any other lien, whether arising by contract, law, equity, or otherwise, or any security interest.
Added by Acts 2021, 87th Leg., R.S., Ch. 284 (H.B. 3794), Sec. 4, eff. September 1, 2021.
