# Sec. 205.003. RESTRICTIONS APPLICABLE TO REVISED SUBDIVISIONS.
(a) If all or part of a subdivision plat is revised to provide for another subdivision of land within all or part of the earlier subdivision, the restrictions that apply to the subdivision before the revision apply to the newly created subdivision.
(b) The property owners of the newly created subdivision must comply with the petition procedures prescribed by Chapter 204 to modify the restrictions.
Added by Acts 1995, 74th Leg., ch. 1040, Sec. 3, eff. Aug. 28, 1995.
