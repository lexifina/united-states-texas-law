# Sec. 76.104. CONFIDENTIALITY OF PROPERTY REPORT.
(a) Except as provided by this chapter, a property report filed with the treasurer of the holder is confidential until the second anniversary of the date the report is filed.
(b) Notwithstanding other law, the social security number of an owner that is reported to the treasurer of the holder is confidential.
Added by Acts 1997, 75th Leg., ch. 1037, Sec. 38, eff. Sept. 1, 1997.
