# Sec. 181.053. RELEASE BY GUARDIAN.
If a person under a disability holds a power, the guardian of the person's estate may release the power in the manner provided in this chapter on the order of the court in this state in which the guardian was appointed or in which the guardianship proceeding is pending.
Acts 1983, 68th Leg., p. 3725, ch. 576, Sec. 1, eff. Jan. 1, 1984.
