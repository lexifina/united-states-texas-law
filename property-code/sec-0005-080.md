# Sec. 5.080. LIABILITY FOR DISCLOSURES.
For purposes of this subchapter, a disclosure required by this subchapter that is made by a seller's agent is a disclosure made by the seller.
Added by Acts 1995, 74th Leg., ch. 994, Sec. 3, eff. Sept. 1, 1995. Renumbered from Property Code Sec. 5.103 and amended by Acts 2001, 77th Leg., ch. 693, Sec. 1, eff. Sept. 1, 2001.
