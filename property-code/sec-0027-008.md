# Sec. 27.008. EFFECT OF ARBITRATION ON LIMITATIONS PERIOD.
The submission of an action subject to this chapter to arbitration has the same effect on the running of a limitations period as a filing in a court in this state.
Added by Acts 2023, 88th Leg., R.S., Ch. 441 (H.B. 2022), Sec. 7, eff. September 1, 2023.
