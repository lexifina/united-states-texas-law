# Sec. 251.008. CONFLICT WITH OTHER LAW.
If there is a conflict between this chapter and other law, this chapter prevails.
Added by Acts 2023, 88th Leg., R.S., Ch. 135 (H.B. 2308), Sec. 4, eff. September 1, 2023.
Added by Acts 2023, 88th Leg., R.S., Ch. 319 (H.B. 1750), Sec. 5, eff. September 1, 2023.
