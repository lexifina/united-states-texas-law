# Sec. 201.0225. RIO GRANDE VEGETATIVE MANAGEMENT PROGRAM.
The state board shall develop and implement the Rio Grande vegetative management program to manage Carrizo cane and other noxious vegetation that impedes border security along the Rio Grande River.
Added by Acts 2015, 84th Leg., R.S., Ch. 431 (S.B. 1734), Sec. 1, eff. June 10, 2015.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 440 (H.B. 3479), Sec. 1, eff. June 20, 2025.
