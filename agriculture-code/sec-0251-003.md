# Sec. 251.003. ESTABLISHED DATE OF OPERATION.
For purposes of this chapter, the established date of operation is the date on which an agricultural operation commenced agricultural operations.
Added by Acts 1981, 67th Leg., p. 2595, ch. 693, Sec. 21, eff. Aug. 31, 1981.
Amended by:
Acts 2023, 88th Leg., R.S., Ch. 135 (H.B. 2308), Sec. 3, eff. September 1, 2023.
