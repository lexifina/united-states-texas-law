# Sec. 122.351. DEFINITION.
In this subchapter, "peace officer" has the meaning assigned by Article 2A.001, Code of Criminal Procedure.
Added by Acts 2019, 86th Leg., R.S., Ch. 764 (H.B. 1325), Sec. 2, eff. June 10, 2019.
Amended by:
Acts 2023, 88th Leg., R.S., Ch. 765 (H.B. 4504), Sec. 2.001, eff. January 1, 2025.
