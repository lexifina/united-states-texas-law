# Sec. 264.195. PROGRAM DEVELOPMENT REPORT.
Not later than January 1, 2027, the department shall submit a report to the legislature regarding the pilot program model developed under this subchapter. The department shall implement the pilot program only if the pilot program is sufficiently funded.
Added by Acts 2025, 89th Leg., R.S., Ch. 9 (S.B. 513), Sec. 1, eff. September 1, 2025.
