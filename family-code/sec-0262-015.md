# Sec. 262.015. FILING REQUIREMENT FOR PETITION REGARDING MORE THAN ONE CHILD.
Each suit under this chapter based on allegations of abuse or neglect arising from the same incident or occurrence and involving children that live in the same home must be filed in the same court.
Added by Acts 2017, 85th Leg., R.S., Ch. 910 (S.B. 999), Sec. 3, eff. September 1, 2017.
Redesignated from Family Code, Section 262.013 by Acts 2019, 86th Leg., R.S., Ch. 467 (H.B. 4170), Sec. 21.001(15), eff. September 1, 2019.
