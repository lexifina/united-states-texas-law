# Sec. 159.702. APPLICABILITY.
This subchapter applies only to a support proceeding under the Convention. In such a proceeding, if a provision of this subchapter is inconsistent with Subchapters B through G, this subchapter controls.
Added by Acts 2015, 84th Leg., R.S., Ch. 368 (H.B. 3538), Sec. 58, eff. July 1, 2015.
