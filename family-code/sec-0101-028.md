# Sec. 101.028. SCHOOL.
"School" means an elementary or secondary school in which a child is enrolled or, if the child is not enrolled in an elementary or secondary school, the public school district in which the child primarily resides. For purposes of this section, a reference to elementary school includes prekindergarten.
Added by Acts 1995, 74th Leg., ch. 20, Sec. 1, eff. April 20, 1995.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 1167 (S.B. 821), Sec. 2, eff. September 1, 2015.
