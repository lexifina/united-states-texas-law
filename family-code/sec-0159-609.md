# Sec. 159.609. PROCEDURE TO REGISTER CHILD SUPPORT ORDER OF ANOTHER STATE FOR MODIFICATION.
A party or support enforcement agency seeking to modify, or to modify and enforce, a child support order issued in another state shall register that order in this state in the same manner provided in Sections 159.601 through 159.608 if the order has not been registered. A petition for modification may be filed at the same time as a request for registration, or later. The pleading must specify the grounds for modification.
Added by Acts 1995, 74th Leg., ch. 20, Sec. 1, eff. April 20, 1995.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 368 (H.B. 3538), Sec. 48, eff. July 1, 2015.
