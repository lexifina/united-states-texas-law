# Sec. 30.000126. COMPLAINT; PLEADING.
Complaints and pleadings must substantially conform to the relevant provisions of Chapters 27 and 45A, Code of Criminal Procedure.
Added by Acts 1999, 76th Leg., ch. 691, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 204 (H.B. 1620), Sec. 8.003, eff. September 1, 2025.
