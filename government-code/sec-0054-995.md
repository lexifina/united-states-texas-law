# Sec. 54.995. ORDER OF REFERRAL.
(a) To refer one or more criminal cases to a magistrate, a judge must issue an order specifying the magistrate's duties.
(b) An order of referral may set forth general powers and limitations of authority of the magistrate that apply to any case referred.
Added by Acts 1993, 73rd Leg., ch. 577, Sec. 1, eff. Aug. 30, 1993.
