# Sec. 1203.022. REGISTRATION OF PUBLIC SECURITY; CONFLICT WITH PUBLIC SECURITY AUTHORIZATION.
(a) A fully registrable public security may be registered as provided by the public security authorization relating to the security.
(b) To the extent of a conflict between this chapter and a public security authorization that provides that a public security is fully registrable, this chapter prevails.
Added by Acts 1999, 76th Leg., ch. 227, Sec. 1, eff. Sept. 1, 1999.
