# Sec. 844.701. APPLICABILITY.
Except for a county described by Section 844.601, this subchapter applies to each subdivision that participates in the retirement system.
Added by Acts 1991, 72nd Leg., ch. 460, Sec. 21, eff. Jan. 1, 1992.
Amended by:
Acts 2009, 81st Leg., R.S., Ch. 300 (H.B. 407), Sec. 23, eff. January 1, 2010.
