# Sec. 2304.005. AUTHORITY OF DEPARTMENT TO ADOPT MINIMUM HOUSING CODE STANDARDS.
The department shall adopt the minimum housing, building, fire, and related code standards that apply in designated areas for which a housing rehabilitation plan is approved by the department and for which local government standards are not in effect.
Added by Acts 1993, 73rd Leg., ch. 268, Sec. 1, eff. Sept. 1, 1993.
