# Sec. 24.027. GRAND AND PETIT JURORS.
All grand and petit jurors selected in a county before a new district court is created or the composition of an existing district court is modified by an amendment to this chapter are considered to be selected for the new or modified district court, as applicable.
Added by Acts 2011, 82nd Leg., 1st C.S., Ch. 3 (H.B. 79), Sec. 3.04, eff. January 1, 2012.
