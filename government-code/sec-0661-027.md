# Sec. 661.027. EQUAL TREATMENT.
A state employee absent while using time withdrawn from the family leave pool may use the time as sick leave earned by the employee. The employee shall be treated for all purposes as if the employee is absent on earned sick leave.
Added by Acts 2021, 87th Leg., R.S., Ch. 684 (H.B. 2063), Sec. 1, eff. September 1, 2021.
