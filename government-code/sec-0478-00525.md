# Sec. 478.00525. SINGLE YEAR CLASSIFICATION FOR ELIGIBILITY PURPOSES FOR CERTAIN SPORTING EVENTS.
For purposes of Sections 478.0051(b)(1) and (3), a sporting event listed in Section 478.0001(3) is considered to be held one time in each year if the event is held only one time in any annual season for that sport.
Added by Acts 2023, 88th Leg., R.S., Ch. 974 (S.B. 2325), Sec. 5, eff. September 1, 2023.
