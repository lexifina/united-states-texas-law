# Sec. 548.0401. TELEHEALTH TREATMENT PROGRAM FOR SUBSTANCE USE DISORDERS.
The executive commissioner by rule shall establish a program to increase opportunities and expand access to telehealth treatment for substance use disorders in this state.
Added by Acts 2023, 88th Leg., R.S., Ch. 769 (H.B. 4611), Sec. 1.01, eff. April 1, 2025.
