# Sec. 540.0502. AUTOMATIC ENROLLMENT IN MEDICAID MANAGED CARE PLAN.
(a) If the commission determines that it is feasible and notwithstanding any other law, the commission may implement an automatic enrollment process under which an applicant determined eligible for Medicaid is automatically enrolled in a Medicaid managed care plan the applicant chooses.
(b) The commission may elect to implement the automatic enrollment process for certain recipient populations.
Added by Acts 2023, 88th Leg., R.S., Ch. 769 (H.B. 4611), Sec. 1.01, eff. April 1, 2025.
