# Sec. 1201.064. SUBMISSION OF NEW PUBLIC SECURITY TO ATTORNEY GENERAL.
Except as provided by Section 1201.067, an issuer that changes or converts a public security that has been registered by the comptroller shall submit the new public security to the attorney general for approval.
Added by Acts 1999, 76th Leg., ch. 227, Sec. 1, eff. Sept. 1, 1999.
