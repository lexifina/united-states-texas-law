# Sec. 156.053. PROCESS SERVER CERTIFICATION RENEWAL; FEES.
Certification of a process server expires on the last day of the month in which the second anniversary of the date on which the certification was issued occurs unless it is renewed on or before that date. On renewal of certification, each process server must pay a fee to the commission in accordance with Section 152.2015.
Added by Acts 2017, 85th Leg., R.S., Ch. 516 (S.B. 43), Sec. 28, eff. September 1, 2017.
