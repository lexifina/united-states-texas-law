# Sec. 559.002. RIGHT TO BE INFORMED ABOUT INFORMATION COLLECTED.
It is the policy of this state that an individual is entitled to be informed about information that a state governmental body collects about the individual unless the state governmental body is allowed to withhold the information from the individual under Section 552.023.
Added by Acts 2001, 77th Leg., ch. 1059, Sec. 1, eff. Sept. 1, 2001.
