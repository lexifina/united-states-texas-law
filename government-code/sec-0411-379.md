# Sec. 411.379. TERMINATION.
The director shall terminate any activation of the alert system for a particular active shooter if:
(1) the active shooter situation is resolved; or
(2) the director or a local law enforcement agency determines the alert system is no longer an effective tool for providing relevant information to the public about the active shooter.
Added by Acts 2021, 87th Leg., R.S., Ch. 125 (H.B. 103), Sec. 2, eff. September 1, 2021.
