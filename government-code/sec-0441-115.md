# Sec. 441.115. RELOCATION.
The state library shall review each library that receives a print access aid under this subchapter once every two years to determine whether to relocate an aid provided to that library. The state library shall make a relocation decision based on population shifts, the use of the equipment, and community need.
Added by Acts 1997, 75th Leg., ch. 165, Sec. 11.01(a), eff. Sept. 1, 1997.
