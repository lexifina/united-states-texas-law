# Sec. 2204.304. REVERSION TO STATE ON NONUSE.
A grant under this subchapter must contain a reservation providing that if any part of the property granted ceases to be used for the purposes set out in Section 2204.301 for a continuous period of five years, that part shall immediately and automatically revert to this state at the end of that period.
Added by Acts 1993, 73rd Leg., ch. 268, Sec. 1, eff. Sept. 1, 1993.
