# Sec. 2054.161. DATA CLASSIFICATION, SECURITY, AND RETENTION REQUIREMENTS.
On initiation of an information resources technology project, including an application development project and any information resources projects described in this subchapter, a state agency shall classify the data produced from or used in the project and determine appropriate data security and applicable retention requirements under Section 441.185 for each classification.
Added by Acts 2021, 87th Leg., R.S., Ch. 567 (S.B. 475), Sec. 5, eff. June 14, 2021.
