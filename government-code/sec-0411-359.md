# Sec. 411.359. SYSTEM NAME.
The director by rule may assign a name other than America's Missing: Broadcast Emergency Response (AMBER) to the alert system when the system is activated regarding a missing person with an intellectual disability.
Added by Acts 2011, 82nd Leg., R.S., Ch. 737 (H.B. 1075), Sec. 7, eff. September 1, 2011.
