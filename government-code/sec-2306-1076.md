# Sec. 2306.1076. FUNDING.
(a) The department shall ensure that a loan under this section is structured in a way that complies with any requirements associated with the source of the funds used for the loan.
(b) In addition to funds set aside for the program under Section 1372.023, the department may solicit and accept funding for the program from gifts and grants for the purposes of this section.
