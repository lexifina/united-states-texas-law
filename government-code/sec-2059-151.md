# Sec. 2059.151. PAYMENT FOR SERVICES.
The department shall develop a system of billings and charges for services provided by the command in operating and administering the network security system that allocates the total state cost to each state agency or other entity served by the system based on proportionate usage.
Added by Acts 2005, 79th Leg., Ch. 760 (H.B. 3112), Sec. 1, eff. September 1, 2005.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 331 (H.B. 150), Sec. 44, eff. September 1, 2025.
