# Sec. 2054.707. DISCLOSURE REQUIREMENTS.
A state agency that procures, develops, deploys, or uses a public-facing artificial intelligence system shall provide clear disclosure of interaction with the system to the public as provided by the artificial intelligence system code of ethics established under Section 2054.702. The disclosure is not required if a reasonable person would know the person is interacting with an artificial intelligence system.
Added by Acts 2025, 89th Leg., R.S., Ch. 1148 (S.B. 1964), Sec. 5, eff. September 1, 2025.
