# Sec. 54.2208. FORFEITURES.
Bail bonds and personal bonds may be forfeited by the magistrate court in the manner provided by Chapter 22, Code of Criminal Procedure, and those forfeitures shall be filed with:
(1) the district clerk if associated with a felony case;
(2) the county clerk if associated with a Class A or Class B misdemeanor case; or
(3) the same justice court clerk associated with the Class C misdemeanor case in which the bond was originally filed.
Added by Acts 2019, 86th Leg., R.S., Ch. 606 (S.B. 891), Sec. 5.04, eff. September 1, 2019.
