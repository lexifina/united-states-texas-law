# Sec. 2306.908. REPORT.
The council shall submit annually a progress report to the governing bodies of the agencies represented on the council.
Added by Acts 1995, 74th Leg., ch. 76, Sec. 5.80(a), eff. Sept. 1, 1995. Renumbered from Government Code Sec. 2307.005 by Acts 2001, 77th Leg., ch. 432, Sec. 3, eff. Sept. 1, 2001. Renumbered from Government Code Sec. 2306.788 by Acts 2003, 78th Leg., ch. 1275, Sec. 2(88), eff. Sept. 1, 2003.
