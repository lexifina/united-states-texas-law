# Sec. 171.0102. ELIGIBILITY REQUIREMENTS FOR PROGRAM PROVIDER LICENSE.
(a) The commission by rule shall establish eligibility requirements and criteria for the issuance of a program provider license under this chapter.
(b) The commission by rule may establish eligibility requirements based on:
(1) the type of court-ordered program the applicant seeks to provide;
(2) whether the program is offered in-person or online; and
(3) if the program is offered in-person, the location where the program will be provided.
Added by Acts 2021, 87th Leg., R.S., Ch. 948 (S.B. 1480), Sec. 1, eff. September 1, 2021.
