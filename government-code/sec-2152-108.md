# Sec. 2152.108. CAREER LADDER.
The executive director or the executive director's designated representative shall develop an intra-agency career ladder program. The program must require intra-agency posting of all non-entry-level positions concurrently with any public posting.
Added by Acts 1995, 74th Leg., ch. 41, Sec. 1, eff. Sept. 1, 1995.
