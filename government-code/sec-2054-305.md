# Sec. 2054.305. PROCUREMENT PLAN AND METHOD FOR MONITORING CONTRACTS.
Before issuing a solicitation for a contract subject to review under Section 2054.158(b)(4), the state agency must develop, consistent with any acquisition plan provided in the guide developed under Section 2262.051:
(1) a procurement plan with anticipated service levels and performance standards for each contractor; and
(2) a method to monitor changes to the scope of each contract.
Added by Acts 2005, 79th Leg., Ch. 1068 (H.B. 1516), Sec. 1.06, eff. September 1, 2005.
