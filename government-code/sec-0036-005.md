# Sec. 36.005. FAILURE TO REPORT.
If a court in this state fails to provide to the clerk of the court the information required for the report submitted under Section 36.004, the court is ineligible for any grant money awarded by this state or a state agency for the next state fiscal biennium.
Added by Acts 2015, 84th Leg., R.S., Ch. 1199 (S.B. 1369), Sec. 1, eff. September 1, 2015.
