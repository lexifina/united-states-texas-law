# Sec. 2059.051. COMMAND RESPONSIBLE FOR PROVIDING COMPUTER NETWORK SECURITY SERVICES.
The command shall provide network security services to:
(1) state agencies; and
(2) other entities by agreement as provided by Section 2059.058.
Added by Acts 2005, 79th Leg., Ch. 760 (H.B. 3112), Sec. 1, eff. September 1, 2005.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 331 (H.B. 150), Sec. 29, eff. September 1, 2025.
