# Sec. 478.0151. MAJOR EVENTS REIMBURSEMENT PROGRAM FUND.
The major events reimbursement program fund is established outside the state treasury and is held in trust by the comptroller for administration of this subtitle.
Added by Acts 2019, 86th Leg., R.S., Ch. 301 (H.B. 4174), Sec. 1.01, eff. April 1, 2021.
