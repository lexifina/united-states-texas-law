# Sec. 2054.152. DEFINITION.
In this subchapter, "project management practices" includes the documented and repeatable activities through which a state agency applies knowledge, skills, tools, and techniques to satisfy project activity requirements.
Added by Acts 1997, 75th Leg., ch. 606, Sec. 19, eff. Sept. 1, 1997.
