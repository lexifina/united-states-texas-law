# Sec. 30.000125. SEAL.
(a) The governing body shall provide each municipal court of record with a seal.
(b) The seal's use must substantially conform to Article 45A.052, Code of Criminal Procedure. The seal must include the phrase "Municipal Court of/in __________, Texas."
Added by Acts 1999, 76th Leg., ch. 691, Sec. 1, eff. Sept. 1, 1999.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 204 (H.B. 1620), Sec. 8.002, eff. September 1, 2025.
