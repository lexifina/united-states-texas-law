# Sec. 91.011. LIBRARY SERVICE FEES.
The director of the state law library may set and charge a fee for services provided by state law library staff.
Added by Acts 1991, 72nd Leg., 1st C.S., ch. 5, Sec. 9.12, eff. Sept. 1, 1991.
Amended by:
Acts 2005, 79th Leg., Ch. 398 (S.B. 1491), Sec. 1, eff. June 17, 2005.
