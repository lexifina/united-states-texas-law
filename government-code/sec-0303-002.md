# Sec. 303.002. CHAIRMAN.
(a) Before any contributions are accepted or any expenditures are made for a governor for a day or speaker's reunion day ceremony, the president pro tempore or the speaker, as appropriate, shall designate a chairman to be responsible for conducting the ceremony.
(b) The chairman is responsible for filing each report required by this chapter.
Acts 1985, 69th Leg., ch. 479, Sec. 1, eff. Sept. 1, 1985. Amended by Acts 1995, 74th Leg., ch. 21, Sec. 2, eff. April 20, 1995.
