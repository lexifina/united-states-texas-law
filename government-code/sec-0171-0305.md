# Sec. 171.0305. INFORMATION REQUIRED.
A program provider shall maintain and make available to participants information regarding course fees, schedules, methods of course delivery, and locations, as applicable, for all court-ordered programs provided by the program provider.
Added by Acts 2021, 87th Leg., R.S., Ch. 948 (S.B. 1480), Sec. 1, eff. September 1, 2021.
