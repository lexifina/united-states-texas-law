# Sec. 421.004. PROVISIONS GOVERNING MOBILE TRACKING DEVICES.
In the event of a conflict between Subchapter E, Chapter 18B, Code of Criminal Procedure, and this chapter or a rule adopted under this chapter, Subchapter E, Chapter 18B, Code of Criminal Procedure, controls.
Added by Acts 2003, 78th Leg., ch. 1312, Sec. 1, eff. June 21, 2003.
Amended by:
Acts 2017, 85th Leg., R.S., Ch. 1058 (H.B. 2931), Sec. 3.09, eff. January 1, 2019.
