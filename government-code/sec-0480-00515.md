# Sec. 480.00515. SINGLE YEAR CLASSIFICATION FOR ELIGIBILITY PURPOSES FOR CERTAIN SPORTING EVENTS.
For purposes of Sections 480.0051(1) and (3), a sporting event is considered to be held one time in each year if the event is held only one time in any annual season for that sport.
Added by Acts 2023, 88th Leg., R.S., Ch. 974 (S.B. 2325), Sec. 7, eff. September 1, 2023.
