# Sec. 443.01526. AFRICAN AMERICAN TEXANS MONUMENT.
The State Preservation Board shall establish an African American Texans memorial monument on the State Capitol grounds that pays tribute to the contributions of African Americans to the State of Texas.
Added by Acts 2011, 82nd Leg., R.S., Ch. 207 (S.B. 1928), Sec. 1, eff. September 1, 2011.
