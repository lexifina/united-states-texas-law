# Sec. 2166.204. USING AGENCY RECOMMENDATIONS.
The commission shall request that the using agency make recommendations regarding private design professionals. The commission shall consider the recommendations in selecting a private design professional to be retained for a particular project.
Added by Acts 1995, 74th Leg., ch. 41, Sec. 1, eff. Sept. 1, 1995. Amended by Acts 1997, 75th Leg., ch. 165, Sec. 17.07, eff. Sept. 1, 1997.
