# Sec. 481.456. RULEMAKING.
The executive director shall adopt rules relating to the implementation of the program and any other rules necessary to accomplish the purposes of this subchapter, including rules that provide criteria under which community development financial institutions may qualify for the program.
Added by Acts 2021, 87th Leg., R.S., Ch. 1004 (H.B. 3271), Sec. 1, eff. June 18, 2021.
