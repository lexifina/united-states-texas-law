# Sec. 2059.1055. NETWORK SECURITY IN A STATE OF DISASTER.
The department, in coordination with the command, shall disconnect the computer network of an entity receiving security services under this chapter from the Internet if the governor issues an order under Section 418.0195 to disconnect the network because of a substantial external threat to the entity's computer network.
Added by Acts 2011, 82nd Leg., R.S., Ch. 1310 (H.B. 3333), Sec. 2, eff. September 1, 2011.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 331 (H.B. 150), Sec. 42, eff. September 1, 2025.
