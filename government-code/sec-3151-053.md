# Sec. 3151.053. CONFLICT WITH OTHER REQUIREMENTS.
If a requirement of this chapter conflicts with a requirement enacted by a municipality or with any other requirement under state law, the stricter requirement prevails.
Added by Acts 2001, 77th Leg., ch. 1420, Sec. 7.001, eff. Sept. 1, 2001.
Amended by:
Acts 2013, 83rd Leg., R.S., Ch. 1288 (H.B. 2256), Sec. 4, eff. June 14, 2013.
