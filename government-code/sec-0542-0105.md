# Sec. 542.0105. STAKEHOLDER INPUT.
As part of developing and implementing the pilot program, the commission, in collaboration with the advisory committee and pilot program work group, shall develop a process to receive and evaluate:
(1) input from:
(A) statewide stakeholders; and
(B) stakeholders from a STAR+PLUS Medicaid managed care service area in which the pilot program will be implemented; and
(2) other evaluations and data.
Added by Acts 2023, 88th Leg., R.S., Ch. 769 (H.B. 4611), Sec. 1.01, eff. April 1, 2025.
