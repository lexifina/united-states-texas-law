# Sec. 411.065. OFFENSES.
(a) A person commits an offense if the person violates a rule of the department adopted under Section 411.062 or a rule of the State Preservation Board adopted under Section 411.063.
(b) An offense under this section is a Class C misdemeanor, except that an offense is a Class B misdemeanor if the person violates a rule adopted under Section 411.062(d-1).
Added by Acts 1993, 73rd Leg., ch. 790, Sec. 14, eff. Sept. 1, 1993. Amended by Acts 1997, 75th Leg., ch. 270, Sec. 7, eff. May 26, 1997; Acts 2001, 77th Leg., ch. 1462, Sec. 7, eff. June 17, 2001.
