# Sec. 542.0053. IMPLEMENTATION OF SYSTEM REDESIGN.
The commission shall, in collaboration with the advisory committee, implement the acute care services and long-term services and supports system for individuals with an intellectual or developmental disability in the manner and in the stages described by this chapter.
Added by Acts 2023, 88th Leg., R.S., Ch. 769 (H.B. 4611), Sec. 1.01, eff. April 1, 2025.
