# Sec. 442.203. POSTING OF RULES.
All specific or general rules applying to a historic site described by Subchapter C must be posted in a conspicuous place at the site. A copy of the rules shall be made available on request to persons visiting the site.
Added by Acts 2011, 82nd Leg., R.S., Ch. 1245 (S.B. 1518), Sec. 5, eff. June 17, 2011.
