# Sec. 45.130. CALLAHAN COUNTY.
If there is no county attorney in Callahan County, the criminal district attorney in Taylor County shall represent the state in all matters pending before the 42nd District Court in Callahan County.
Acts 1985, 69th Leg., ch. 480, Sec. 1, eff. Sept. 1, 1985. Amended by Acts 1987, 70th Leg., ch. 148, Sec. 2.52(c), eff. Sept. 1, 1987; Acts 1991, 72nd Leg., 1st C.S., ch. 8, Sec. 10, eff. Sept. 1, 1991.
