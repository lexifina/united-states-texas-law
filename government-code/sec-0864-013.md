# Sec. 864.013. COST-OF-LIVING INCREASE.
The state board by rule may provide a cost-of-living increase for any benefit provided by the pension system. If benefits are increased, the state board shall require an increase in monthly contributions if necessary to maintain an actuarially sound pension system.
Added by Acts 2005, 79th Leg., Ch. 803 (S.B. 522), Sec. 1, eff. September 1, 2005.
Amended by:
Acts 2019, 86th Leg., R.S., Ch. 1165 (H.B. 3247), Sec. 20, eff. September 1, 2019.
