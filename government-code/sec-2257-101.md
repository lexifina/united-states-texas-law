# Sec. 2257.101. DEFINITION.
In this subchapter, "participating institution" means a financial institution that holds one or more deposits of public funds and that participates in the pooled collateral program under this subchapter.
Added by Acts 2009, 81st Leg., R.S., Ch. 486 (S.B. 638), Sec. 1, eff. September 1, 2009.
