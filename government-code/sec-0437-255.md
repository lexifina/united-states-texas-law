# Sec. 437.255. ASSISTING TEXAS STATE GUARD WITH CYBER OPERATIONS.
To serve the state and safeguard the public from malicious cyber activity, the governor may command the Texas National Guard to assist the Texas State Guard with defending the state's cyber operations.
Added by Acts 2019, 86th Leg., R.S., Ch. 509 (S.B. 64), Sec. 3, eff. September 1, 2019.
