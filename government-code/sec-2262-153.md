# Sec. 2262.153. FORMS FOR REPORTING CONTRACTOR PERFORMANCE.
As part of the uniform forms published under Section 2262.152, the comptroller shall develop forms for use by state agencies in reporting a contractor's performance for use in the vendor performance tracking system under Section 2262.055.
Added by Acts 2013, 83rd Leg., R.S., Ch. 1227 (S.B. 1681), Sec. 7, eff. November 1, 2013.
