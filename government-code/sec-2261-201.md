# Sec. 2261.201. DOUBLE-BILLING.
Each state agency that makes procurements to which this chapter applies shall design and implement procedures to detect and report double-billing by contractors.
Added by Acts 1999, 76th Leg., ch. 1498, Sec. 5, eff. Sept. 1, 1999. Renumbered from Sec. 2259.201 by Acts 2001, 77th Leg., ch. 1420, Sec. 21.001(71), eff. Sept. 1, 2001.
