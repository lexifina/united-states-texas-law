# Sec. 2175.187. DISPOSITION BY DIRECT SALE TO PUBLIC.
(a) If the commission determines that selling the property by competitive bid or auction, including a sale using an Internet auction site, would not maximize the resale value of the property to the state, the commission may sell surplus property directly to the public.
(b) The commission shall set a fixed price for the property in cooperation with the state agency that owns the property.
Added by Acts 2001, 77th Leg., ch. 1422, Sec. 11.03, eff. Jan. 1, 2002.
