# Sec. 2253.079. CRIMINAL OFFENSE FOR FALSE AND FRAUDULENT CLAIM.
(a) A person commits an offense if the person wilfully files a false and fraudulent claim under this chapter.
(b) An offense under this section is subject to the penalty for false swearing.
Added by Acts 1993, 73rd Leg., ch. 268, Sec. 1, eff. Sept. 1, 1993.
