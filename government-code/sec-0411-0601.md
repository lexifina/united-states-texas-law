# Sec. 411.0601. DEFINITION.
In this subchapter, "criminal justice agency" has the meaning assigned by Article 66.001, Code of Criminal Procedure.
Added by Acts 2009, 81st Leg., R.S., Ch. 1152 (H.B. 2932), Sec. 1, eff. September 1, 2009.
Amended by:
Acts 2017, 85th Leg., R.S., Ch. 1058 (H.B. 2931), Sec. 4.09, eff. January 1, 2019.
