# Sec. 2110.007. REPORT TO THE LEGISLATIVE BUDGET BOARD.
A state agency that has established an advisory committee shall report to the Legislative Budget Board the information developed in the evaluation required by Section 2110.006. The agency shall file the report biennially in connection with the agency's request for appropriations.
Added by Acts 1997, 75th Leg., ch. 165, Sec. 16.01(a), eff. Sept. 1, 1997. Amended by Acts 2001, 77th Leg., ch. 1158, Sec. 51, eff. Sept. 1, 2001.
