# Sec. 487.052. RULES.
The department may adopt rules as necessary to implement this chapter.
Added by Acts 2001, 77th Leg., ch. 1424, Sec. 1, eff. Sept. 1, 2001.
Amended by:
Acts 2007, 80th Leg., R.S., Ch. 1241 (H.B. 2542), Sec. 10, eff. June 15, 2007.
Acts 2013, 83rd Leg., R.S., Ch. 148 (H.B. 1493), Sec. 5, eff. September 1, 2013.
