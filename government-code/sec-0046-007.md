# Sec. 46.007. INELIGIBILITY FOR CERTAIN OTHER STATE FUNDS.
Subchapter C, Chapter 41, does not apply to a county if the county is served by a state prosecutor who serves in a district or county listed in Section 46.002.
Acts 1985, 69th Leg., ch. 480, Sec. 1, eff. Sept. 1, 1985. Amended by Acts 1999, 76th Leg., ch. 1570, Sec. 1, eff. Sept. 1, 1999.
