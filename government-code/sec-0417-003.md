# Sec. 417.003. STATUS AS STATE-COMMISSIONED OFFICER.
The state fire marshal is a state-commissioned officer and functions in that capacity subject to rules of the commissioner.
Acts 1987, 70th Leg., ch. 147, Sec. 1, eff. Sept. 1, 1987. Amended by Acts 1991, 72nd Leg., ch. 628, Sec. 5, eff. Sept. 1, 1991; Acts 1997, 75th Leg., ch. 1172, Sec. 3.01, eff. Sept. 1, 1997.
