# Sec. 21.006. JUDICIAL FUND.
The judicial fund is created in a separate fund in the state treasury to be administered by the comptroller. The fund shall be used only for court-related purposes for the support of the judicial branch of this state.
Added by Acts 1986, 69th Leg., 2nd C.S., ch. 11, Sec. 1, eff. Sept. 22, 1986.
