# Sec. 54A.201. DEFINITION.
In this subchapter, "statutory probate court" has the meaning assigned by Chapter 22, Estates Code.
Transferred, redesignated and amended from Government Code, Subchapter G, Chapter 54 by Acts 2011, 82nd Leg., 1st C.S., Ch. 3 (H.B. 79), Sec. 6.02, eff. January 1, 2012.
Amended by:
Acts 2017, 85th Leg., R.S., Ch. 324 (S.B. 1488), Sec. 22.030, eff. September 1, 2017.
