# Sec. 171.0202. PROGRAM PROVIDER CHANGE OF OWNERSHIP.
Not less than 30 days before the date of a change in ownership of a program provider, the proposed new owner must apply for a new program provider license with an endorsement for each type of court-ordered program to be offered by the new owner.
Added by Acts 2021, 87th Leg., R.S., Ch. 948 (S.B. 1480), Sec. 1, eff. September 1, 2021.
