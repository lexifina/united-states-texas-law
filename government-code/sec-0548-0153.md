# Sec. 548.0153. CERTAIN TELEDENTISTRY DENTAL SERVICES REIMBURSEMENT DENIALS PROHIBITED.
A request for reimbursement may not be denied solely because an in-person dental service between a dentist and a patient did not occur.
Added by Acts 2023, 88th Leg., R.S., Ch. 769 (H.B. 4611), Sec. 1.01, eff. April 1, 2025.
