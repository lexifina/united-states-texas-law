# Sec. 411.421. DEFINITION.
In this subchapter, "regulated material" has the meaning assigned by Section 1956.001, Occupations Code.
Added by Acts 2011, 82nd Leg., R.S., Ch. 1234 (S.B. 694), Sec. 20, eff. September 1, 2011.
Redesignated from Government Code, Subchapter N, Chapter 411 by Acts 2013, 83rd Leg., R.S., Ch. 161 (S.B. 1093), Sec. 22.001(21), eff. September 1, 2013.
