# Sec. 1231.084. REPORT OF STATE SECURITY SOLD THROUGH PRIVATE PLACEMENT.
A report concerning a state security sold through private placement must state:
(1) each component of the private placement fee, including the:
(A) management fee;
(B) placement agent fee; and
(C) expenses; and
(2) the placement agent's counsel's fee.
Added by Acts 1999, 76th Leg., ch. 227, Sec. 1, eff. Sept. 1, 1999.
