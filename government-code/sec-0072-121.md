# Sec. 72.121. DEFINITIONS.
In this subchapter:
(1) "Estate" has the meaning assigned by Section 1002.010, Estates Code.
(1-a) "Financial institution" has the meaning assigned by Section 201.101, Finance Code.
(1-b) "Guardianship proceeding" has the meaning assigned by Section 1002.015, Estates Code.
(2) "Program" means the guardianship abuse, fraud, and exploitation deterrence program established by this subchapter.
(3) "Ward" has the meaning assigned by Section 1002.030, Estates Code.
Added by Acts 2019, 86th Leg., R.S., Ch. 1226 (S.B. 31), Sec. 1, eff. September 1, 2019.
Amended by:
Acts 2021, 87th Leg., R.S., Ch. 181 (S.B. 692), Sec. 1, eff. May 30, 2021.
