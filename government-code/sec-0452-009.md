# Sec. 452.009. REPORT.
Not later than September 1, 2037, the commission shall file a report with the governor and the legislature containing information about the effects of the bicentennial activities conducted in this state on the state's economy.
Added by Acts 2025, 89th Leg., R.S., Ch. 496 (S.B. 1350), Sec. 1, eff. September 1, 2025.
