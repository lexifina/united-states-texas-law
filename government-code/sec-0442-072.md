# Sec. 442.072. COMMISSION JURISDICTION; AGREEMENTS FOR HISTORIC SITES.
(a) The following historic sites in this state are under the commission's jurisdiction:
(1) Acton State Historic Site;
(2) Barrington Living History Farm State Historic Site;
(3) Bush Family Home State Historic Site;
(4) Caddo Mounds State Historic Site;
(5) Casa Navarro State Historic Site;
(6) Confederate Reunion Grounds State Historic Site;
(7) Eisenhower Birthplace State Historic Site;
(8) Fannin Battleground State Historic Site;
(9) Fanthorp Inn State Historic Site;
(10) Fort Griffin State Historic Site;
(11) Fort Lancaster State Historic Site;
(12) Fort Martin Scott State Historic Site;
(13) Fort McKavett State Historic Site;
(14) French Legation State Historic Site;
(15) Fulton Mansion State Historic Site;
(16) Goodnight Ranch State Historic Site;
(17) Harvey House State Historic Site;
(18) Iwo Jima Monument and Museum State Historic Site;
(19) Kreische Brewery State Historic Site;
(20) Landmark Inn State Historic Site;
(21) Levi Jordan State Historic Site;
(22) Lipantitlan State Historic Site;
(23) Magoffin Home State Historic Site;
(24) Mission Dolores State Historic Site;
(25) Monument Hill State Historic Site;
(26) National Museum of the Pacific War;
(27) Old Socorro Mission State Historic Site;
(28) Palmito Ranch Battlefield State Historic Site;
(29) Port Isabel Lighthouse State Historic Site;
(30) Presidio La Bahia State Historic Site;
(31) Sabine Pass Battleground State Historic Site;
(32) Sam Bell Maxey House State Historic Site;
(33) Sam Rayburn House State Historic Site;
(34) San Felipe de Austin State Historic Site;
(35) San Jacinto Battleground State Historic Site;
(36) Star of the Republic Museum State Historic Site;
(37) Starr Family Home State Historic Site;
(38) Stephen F. Austin Memorial State Historic Site;
(39) Varner-Hogg Plantation State Historic Site; and
(40) Washington-on-the-Brazos State Historic Site.
(b) The commission may enter into an agreement with a nonprofit or for-profit corporation, foundation, association, or other nonprofit or for-profit entity for the expansion, renovation, management, operation, or financial support of a historic site.
