# Sec. 1510.001. DEFINITION.
In this chapter, "state highway system" means the highways in this state included in the plan providing for a system of state highways prepared under Section 201.103, Transportation Code.
Added by Acts 2007, 80th Leg., R.S., Ch. 426 (S.B. 1536), Sec. 1, eff. June 15, 2007.
