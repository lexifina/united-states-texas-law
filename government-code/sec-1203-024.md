# Sec. 1203.024. CHANGE OF NAME OR ADDRESS OF REGISTERED OWNER.
If the comptroller is designated under this chapter as registrar of a public security and the comptroller's registration book reflects the change of name or address of a registered owner of the security, the comptroller shall notify each paying agent of the change.
Added by Acts 1999, 76th Leg., ch. 227, Sec. 1, eff. Sept. 1, 1999.
