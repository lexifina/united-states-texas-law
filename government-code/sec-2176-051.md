# Sec. 2176.051. INTERAGENCY MAIL SERVICE.
(a) The comptroller shall operate a messenger service for delivering unstamped written communications and packages between the following entities located in Travis County:
(1) state agencies;
(2) the legislature; and
(3) legislative agencies.
(b) All entities described by Subsection (a) shall use the service.
Added by Acts 1995, 74th Leg., ch. 41, Sec. 1, eff. Sept. 1, 1995.
Amended by:
Acts 2019, 86th Leg., R.S., Ch. 1071 (H.B. 1524), Sec. 113, eff. September 1, 2019.
