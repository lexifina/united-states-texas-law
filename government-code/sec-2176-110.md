# Sec. 2176.110. RULES.
The comptroller shall adopt rules for state agencies to implement this chapter. Before adopting a rule under this section, the comptroller must conduct a public hearing regarding the proposed rule regardless of whether the requirements of Section 2001.029(b) are met.
Added by Acts 1995, 74th Leg., ch. 41, Sec. 1, eff. Sept. 1, 1995.
Amended by:
Acts 2007, 80th Leg., R.S., Ch. 937 (H.B. 3560), Sec. 1.41, eff. September 1, 2007.
