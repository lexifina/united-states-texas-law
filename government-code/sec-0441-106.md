# Sec. 441.106. PAYMENT FOR PRINTING OF STATE PUBLICATIONS.
If a state agency's printing is done by contract, an account for the printing may not be approved and a warrant may not be issued unless the agency first furnishes to the comptroller a receipt from the state librarian for the publication or a written waiver from the state librarian exempting the publication from this subchapter.
Acts 1987, 70th Leg., ch. 147, Sec. 1, eff. Sept. 1, 1987.
