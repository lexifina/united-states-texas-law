# Sec. 2166.154. USE OF PROJECT ANALYSIS OR COST ESTIMATE IN APPROPRIATIONS PROCESS.
The using agency shall use the cost of the project as determined by the project analysis or the cost estimate developed under Section 2166.155 as the basis of a request to the state's budget offices.
Added by Acts 1995, 74th Leg., ch. 41, Sec. 1, eff. Sept. 1, 1995.
