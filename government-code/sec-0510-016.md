# Sec. 510.016. EFFECT ON TEXAS LAWS.
In the event the laws of this state conflict with the compact, the compact controls, except that in the event of a conflict between the compact and the Texas Constitution, as determined by the courts of this state, the Texas Constitution controls.
Added by Acts 2001, 77th Leg., ch. 543, Sec. 1, eff. June 11, 2001.
