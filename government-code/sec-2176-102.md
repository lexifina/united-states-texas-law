# Sec. 2176.102. EVALUATION.
The comptroller shall evaluate the outgoing first-class mail practices of state agencies located in Travis County, including the lists, systems, and formats used to create mail.
Added by Acts 1995, 74th Leg., ch. 41, Sec. 1, eff. Sept. 1, 1995.
Amended by:
Acts 2019, 86th Leg., R.S., Ch. 1071 (H.B. 1524), Sec. 114, eff. September 1, 2019.
