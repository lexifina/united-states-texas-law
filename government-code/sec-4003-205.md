# Sec. 4003.205. DEALER NAMED IN OFFER.
A dealer whose name is included in a written, printed, or broadcast offer along with the name of a registered dealer is not deemed, on that fact alone, to have made an offer in this state to sell a security.
Added by Acts 2019, 86th Leg., R.S., Ch. 491 (H.B. 4171), Sec. 1.01, eff. January 1, 2022.
