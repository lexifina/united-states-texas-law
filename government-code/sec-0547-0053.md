# Sec. 547.0053. IMPLEMENTATION.
The commission shall:
(1) monitor the implementation of a system of care framework under Section 547.0052; and
(2) adopt rules necessary to facilitate or adjust that implementation.
Added by Acts 2023, 88th Leg., R.S., Ch. 769 (H.B. 4611), Sec. 1.01, eff. April 1, 2025.
