# Sec. 2059.106. PRIVATE VENDOR.
The command may contract with a private vendor to build and operate the center and act as an authorized agent to acquire, install, integrate, maintain, configure, and monitor the network security services and security infrastructure elements.
Added by Acts 2005, 79th Leg., Ch. 760 (H.B. 3112), Sec. 1, eff. September 1, 2005.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 331 (H.B. 150), Sec. 43, eff. September 1, 2025.
