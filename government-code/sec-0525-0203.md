# Sec. 525.0203. HEALTH INFORMATION EXCHANGE SYSTEM IMPLEMENTATION IN STAGES.
The commission shall implement the health information exchange system in stages as described by this subchapter, except that the commission may deviate from those stages if technological advances make a deviation advisable or more efficient.
Added by Acts 2023, 88th Leg., R.S., Ch. 769 (H.B. 4611), Sec. 1.01, eff. April 1, 2025.
