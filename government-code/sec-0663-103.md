# Sec. 663.103. SPECIFICATIONS FOR CHILD CARE FACILITY SITES.
The commission shall set specifications for each child care facility site, including the location, size, and design for the facility.
Added by Acts 1993, 73rd Leg., ch. 268, Sec. 1, eff. Sept. 1, 1993. Amended by Acts 2001, 77th Leg., ch. 761, Sec. 3, eff. Sept. 1, 2001.
