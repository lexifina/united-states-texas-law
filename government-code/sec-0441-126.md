# Sec. 441.126. AUTHORITY TO ESTABLISH SYSTEMS.
The commission may establish and develop major resource systems or regional library systems in conformity with the plan for a state library system as provided by this subchapter.
Acts 1987, 70th Leg., ch. 147, Sec. 1, eff. Sept. 1, 1987. Amended by Acts 1993, 73rd Leg., ch. 155, Sec. 2, eff. Sept. 1, 1993.
