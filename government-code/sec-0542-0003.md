# Sec. 542.0003. DELAYED IMPLEMENTATION AUTHORIZED.
Notwithstanding any other law, the commission may delay implementing a provision of this chapter without additional investigation, adjustment, or legislative action if the commission determines implementing the provision would adversely affect the system of services and supports to persons and programs to which this chapter applies.
Added by Acts 2023, 88th Leg., R.S., Ch. 769 (H.B. 4611), Sec. 1.01, eff. April 1, 2025.
