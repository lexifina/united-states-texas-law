# Sec. 2306.909. GIFTS AND GRANTS.
The council may accept gifts and grants from a public or private source for use in carrying out the council's duties under this subchapter.
Added by Acts 1995, 74th Leg., ch. 76, Sec. 5.80(a), eff. Sept. 1, 1995. Renumbered from Government Code Sec. 2307.008 and amended by Acts 2001, 77th Leg., ch. 432, Sec. 3, eff. Sept. 1, 2001. Renumbered from Government Code Sec. 2306.789 by Acts 2003, 78th Leg., ch. 1275, Sec. 2(88), eff. Sept. 1, 2003.
