# Sec. 559.004. RIGHT TO CORRECTION OF INCORRECT INFORMATION.
Each state governmental body shall establish a reasonable procedure under which an individual is entitled to have the state governmental body correct information about the individual that is possessed by the state governmental body and that is incorrect. The procedure may not unduly burden an individual using the procedure.
Added by Acts 2001, 77th Leg., ch. 1059, Sec. 1, eff. Sept. 1, 2001.
