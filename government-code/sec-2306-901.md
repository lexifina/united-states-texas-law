# Sec. 2306.901. DEFINITION.
In this subchapter, "council" means the Texas Interagency Council for the Homeless.
Added by Acts 1995, 74th Leg., ch. 76, Sec. 5.80(a), eff. Sept. 1, 1995. Renumbered from Government Code Sec. 2307.001 and amended by Acts 2001, 77th Leg., ch. 432, Sec. 3, eff. Sept. 1, 2001. Renumbered from Government Code Sec. 2306.781 by Acts 2003, 78th Leg., ch. 1275, Sec. 2(88), eff. Sept. 1, 2003.
