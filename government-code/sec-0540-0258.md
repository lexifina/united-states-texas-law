# Sec. 540.0258. PRIMARY CARE PROVIDER ASSIGNMENT.
A contract to which this subchapter applies must require the contracting Medicaid managed care organization to make initial and subsequent primary care provider assignments and changes.
Added by Acts 2023, 88th Leg., R.S., Ch. 769 (H.B. 4611), Sec. 1.01, eff. April 1, 2025.
