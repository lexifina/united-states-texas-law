# Sec. 32.107. LOCATION OF FLOATING CABIN IN CERTAIN SITES PROHIBITED.
(a) A floating cabin may not be located in a state park, state wildlife refuge, state wildlife sanctuary, or state coastal preserve.
(b) Each owner of a floating cabin is liable for a violation of this section.
Added by Acts 2001, 77th Leg., ch. 1273, Sec. 1, eff. June 15, 2001.
