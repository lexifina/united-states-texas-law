# Sec. 66.121. PENALTY.
A person who violates Section 66.109, 66.110, 66.111, or 66.117(b) of this code or a regulation adopted under Section 66.115 of this code commits an offense that is a Class C Parks and Wildlife Code misdemeanor.
Added by Acts 1985, 69th Leg., ch. 267, art. 3, Sec. 64, eff. Sept. 1, 1985. Renumbered from Sec. 66.119 by Acts 1987, 70th Leg., ch. 167, Sec. 5.01(a)(41), eff. Sept. 1, 1987.
