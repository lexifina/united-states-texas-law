# Sec. 45.005. RECORDS OF LIVE BIRD AND EGG SALES.
(a) No holder of a commercial game bird breeder's license may sell a live game bird or game bird egg without issuing a written document showing the name and serial number of the game bird breeder, the name and address of the purchaser, and the kind or species and number of game birds or game bird eggs sold. The document shall be delivered to the purchaser.
(b) The department shall issue to each holder of a commercial game bird breeder's license a serial number which shall remain the number of the person holding the license as long as he continues to hold a license.
