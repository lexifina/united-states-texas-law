# Sec. 43.404. FISHING LICENSE REQUIRED.
The acquisition of a saltwater sportfishing stamp does not authorize a person to fish for sporting purposes in saltwater without having acquired a fishing license required by Chapter 46 of this code or authorize saltwater sportfishing at any time or by any means not otherwise authorized by this code.
Added by Acts 1985, 69th Leg., ch. 640, Sec. 1, eff. Jan. 1, 1986.
