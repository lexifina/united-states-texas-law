# Sec. 13.205. PENALTY.
A person who violates a regulation made by the commission under Section 13.201 of this code commits an offense that is a Class C Parks and Wildlife Code misdemeanor.
Acts 1975, 64th Leg., p. 1405, ch. 545, Sec. 1, eff. Sept. 1, 1975. Amended by Acts 1985, 69th Leg., ch. 267, art. 3, Sec. 7, eff. Sept. 1, 1985.
