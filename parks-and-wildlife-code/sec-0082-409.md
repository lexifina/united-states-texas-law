# Sec. 82.409. PENALTY.
A person who violates any provision of this subchapter commits an offense that is a Class B Parks and Wildlife Code misdemeanor.
Acts 1975, 64th Leg., p. 1405, ch. 545, Sec. 1, eff. Sept. 1, 1975. Amended by Acts 1985, 69th Leg., ch. 267, art. 3, Sec. 98, eff. Sept. 1, 1985.
