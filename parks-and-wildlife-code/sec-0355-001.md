# Sec. 355.001. OFFENSES THAT ARE CLASS C PARKS AND WILDLIFE CODE MISDEMEANORS.
Except as provided by Section 355.002 or 355.003 of this code, a person who violates a provision of Title 7 of this code commits an offense that is a Class C Parks and Wildlife Code misdemeanor.
Added by Acts 1985, 69th Leg., ch. 267, art. 4, Sec. 15, eff. Sept. 1, 1985.
