# Sec. 50.003. OTHER LICENSES NOT REQUIRED.
A resident who has acquired a combination hunting and fishing license is not required to obtain the hunting license required by Chapter 42 of this code or the fishing license required by Chapter 46 of this code.
Acts 1975, 64th Leg., p. 1405, ch. 545, Sec. 1, eff. Sept. 1, 1975.
