# Sec. 42.0121. LIFETIME RESIDENT HUNTING LICENSE FEE.
The fee for a lifetime resident hunting license is $300 or an amount set by the commission, whichever amount is more.
Added by Acts 1985, 69th Leg., ch. 267, art. 2, Sec. 13, eff. Sept. 1, 1986. Amended by Acts 1995, 74th Leg., ch. 931, Sec. 8, eff. June 16, 1995.
