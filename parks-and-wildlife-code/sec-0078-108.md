# Sec. 78.108. EXPIRATION OF LICENSE.
A license required by this subchapter is valid only during the period for which it is issued without regard to the date on which the license is acquired. Each period is one year beginning on September 1 or another date set by the commission.
Added by Acts 1997, 75th Leg., ch. 1256, Sec. 127, eff. Sept. 1, 1997.
