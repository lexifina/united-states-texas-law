# Sec. 42.0143. NONRESIDENT FIVE-DAY HUNTING LICENSE.
(a) A nonresident five-day hunting license is not valid for a mule deer, white-tailed deer, turkey, pronghorn antelope, desert bighorn sheep, or alligator.
(b) A nonresident five-day hunting license is valid for five consecutive days.
(c) A nonresident may acquire multiple nonresident five-day hunting licenses during a license year.
(d) The fee for a nonresident five-day hunting license is set by the commission in an amount not to exceed 50 percent of the amount of the fee set for a nonresident general hunting license.
Added by Acts 1987, 70th Leg., ch. 609, Sec. 4, eff. Sept. 1, 1987. Amended by Acts 1995, 74th Leg., ch. 931, Sec. 12, eff. June 16, 1995.
