# Sec. 62.024. IMPORTATION OF GAME.
No person may bring into this state any bird or animal protected by this code during the closed season for that bird or animal except as provided by this code.
Acts 1975, 64th Leg., p. 1405, ch. 545, Sec. 1, eff. Sept. 1, 1975. Amended by Acts 1985, 69th Leg., ch. 267, art. 3, Sec. 45, eff. Sept. 1, 1985.
