# Sec. 67.001. DEFINITION.
In this chapter, "nongame" means those species of vertebrate and invertebrate wildlife indigenous to Texas that are not classified as game animals, game birds, game fish, fur-bearing animals, endangered species, alligators, marine penaeid shrimp, or oysters.
