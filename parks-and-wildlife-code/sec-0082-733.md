# Sec. 82.733. PENALTY.
A person who violates Section 82.732 of this code commits an offense that is a Class C Parks and Wildlife Code misdemeanor.
Added by Acts 1981, 67th Leg., p. 2080, ch. 471, Sec. 1, eff. Aug. 31, 1981. Amended by Acts 1985, 69th Leg., ch. 267, art. 3, Sec. 103, eff. Sept. 1, 1985.
