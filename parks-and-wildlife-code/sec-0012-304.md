# Sec. 12.304. MORE THAN ONE DEFENDANT.
If more than one defendant is named in a suit brought under this subchapter, each defendant against whom judgment is rendered is jointly and severally liable for the recovery provided by this subchapter.
Added by Acts 1985, 69th Leg., ch. 267, art. 1, Sec. 34, eff. Sept. 1, 1985.
