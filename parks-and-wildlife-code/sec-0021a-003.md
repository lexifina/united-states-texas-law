# Sec. 21A.003. REQUEST FOR DISTRIBUTION.
The department may request from the trust company a distribution from the fund for the purpose of acquiring real property in this state for the creation and improvement of publicly accessible state parks.
Added by Acts 2023, 88th Leg., R.S., Ch. 290 (S.B. 1648), Sec. 1, eff. January 1, 2024.
