# Sec. 82.763. PENALTY.
A person who violates Section 82.762 of this code commits an offense that is a Class C Parks and Wildlife Code misdemeanor.
Added by Acts 1979, 66th Leg., p. 2083, ch. 814, Sec. 1, eff. Aug. 27, 1979. Amended by Acts 1985, 69th Leg., ch. 267, art. 3, Sec. 104, eff. Sept. 1, 1985.
