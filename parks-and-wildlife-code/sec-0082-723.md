# Sec. 82.723. PENALTY.
A person who violates Section 82.722 of this code commits an offense that is a Class C Parks and Wildlife Code misdemeanor.
Added by Acts 1977, 65th Leg., p. 2072, ch. 823, Sec. 2, eff. Aug. 29, 1977. Amended by Acts 1985, 69th Leg., ch. 267, art. 3, Sec. 102, eff. Sept. 1, 1985.
