# Sec. 43.902. FEE.
The fee for a reptile and amphibian stamp is $10. The department may issue other editions of the stamp that are not valid for capturing by nonlethal means a species covered by this subchapter for a fee set by the commission.
Added by Acts 2011, 82nd Leg., R.S., Ch. 1351 (H.B. 1788), Sec. 1, eff. September 1, 2011.
