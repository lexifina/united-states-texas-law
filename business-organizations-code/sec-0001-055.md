# Sec. 1.055. DOCTRINE OF INDEPENDENT LEGAL SIGNIFICANCE.
An action validly taken under a provision of this code may not be considered invalid because the action is identical or similar in substance to an action that could have been taken under another provision of this code but fails to satisfy one or more requirements prescribed by that other provision.
Added by Acts 2023, 88th Leg., R.S., Ch. 27 (S.B. 1514), Sec. 2, eff. September 1, 2023.
