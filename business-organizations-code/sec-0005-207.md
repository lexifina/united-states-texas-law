# Sec. 5.207. DESIGNATION OF REGISTERED AGENT WITHOUT CONSENT; PENALTIES AND LIABILITIES.
Sections 4.007 and 4.008 apply with respect to a false statement in a registered agent filing that names a person the registered agent of a represented entity without the person's consent.
Added by Acts 2009, 81st Leg., R.S., Ch. 1123 (H.B. 1787), Sec. 5, eff. January 1, 2010.
