# Sec. 3953.103. LOCATION OF IMPROVEMENT PROJECT.
An improvement project described by Section 3953.102 may be located:
(1) in the district; or
(2) in an area outside the district if the project is for the purpose of extending a public infrastructure improvement beyond the district's boundaries to a logical terminus.
Added by Acts 2017, 85th Leg., R.S., Ch. 630 (H.B. 4297), Sec. 1, eff. June 12, 2017.
