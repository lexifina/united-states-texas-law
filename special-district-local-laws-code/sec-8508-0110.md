# Sec. 8508.0110. CONSULTATION WITH COUNTY JUDGE FOR CERTAIN PROPOSED PROJECTS.
Before voting on a proposed project for which the board will seek a permit, the board shall obtain advice on the project from the county judge of each county in which the project is proposed to be located.
Added by Acts 2019, 86th Leg., R.S., Ch. 468 (H.B. 4172), Sec. 1.03, eff. April 1, 2021.
