# Sec. 3911.163. ACQUISITION OF PROPERTY.
An improvement project may include the acquisition of property or an interest in property in connection with an improvement project, including a project authorized by Subchapter A, Chapter 372, Local Government Code.
Added by Acts 2011, 82nd Leg., R.S., Ch. 587 (H.B. 3852), Sec. 1, eff. June 17, 2011.
