# Sec. 1083.053. BALLOT APPLICATION.
A person seeking to have the person's name printed on the ballot as a candidate for director must file an application in accordance with Chapter 144, Election Code, with the board secretary.
Added by Acts 2009, 81st Leg., R.S., Ch. 1139 (H.B. 2619), Sec. 1.01, eff. April 1, 2011.
Amended by:
Acts 2011, 82nd Leg., R.S., Ch. 91 (S.B. 1303), Sec. 22.012(c), eff. September 1, 2011.
