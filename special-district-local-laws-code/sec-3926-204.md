# Sec. 3926.204. NOTICE AND RECORDING OF ORDER.
Not later than the 30th day after the date of an order dividing the district, the district shall:
(1) file the order with the commission; and
(2) record the order in the real property records of the county.
Added by Acts 2015, 84th Leg., R.S., Ch. 977 (H.B. 3603), Sec. 1, eff. September 1, 2015.
