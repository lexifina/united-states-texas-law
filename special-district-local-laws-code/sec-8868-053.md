# Sec. 8868.053. APPOINTMENT OF DIRECTORS BY ADDITIONAL COUNTIES.
When a county is added to the district, the board may change the number of directors so that an equal number of directors are appointed from each county and one director is appointed jointly by the counties.
Added by Acts 2013, 83rd Leg., R.S., Ch. 112 (S.B. 1026), Sec. 1.05, eff. April 1, 2015.
