# Sec. 8109.202. BOARD DETERMINATION REQUIRED.
The district may not undertake a project under this subchapter unless the board determines the project to be necessary to accomplish a public purpose of the district.
Added by Acts 2011, 82nd Leg., R.S., Ch. 1194 (H.B. 3845), Sec. 2, eff. June 17, 2011.
