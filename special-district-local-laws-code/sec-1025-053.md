# Sec. 1025.053. BALLOT APPLICATION.
A person who wants to have the person's name printed on the ballot as a candidate for director must file an application with the board secretary in accordance with Chapter 144, Election Code.
Added by Acts 2007, 80th Leg., R.S., Ch. 920 (H.B. 3166), Sec. 1.02, eff. April 1, 2009.
Amended by:
Acts 2009, 81st Leg., R.S., Ch. 87 (S.B. 1969), Sec. 21.006, eff. September 1, 2009.
