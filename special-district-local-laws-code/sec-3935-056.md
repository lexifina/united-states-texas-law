# Sec. 3935.056. INITIAL VOTING DIRECTORS ON CONVERSION TO MANAGEMENT DISTRICT.
(a) On the conversion of the district to a management district, the initial board consists of the following directors:
|  |  |  |  |
| --- | --- | --- | --- |
|  | Pos. No. |  | Name of Director |
|  | 1. |  | Kenneth Berger |
|  | 2. |  | Orville Wient |
|  | 3. |  | Robert C. Hargarther |
|  | 4. |  | Donald P. Cox |
|  | 5. |  | Nick Alexander Jr. |
(b) Of the initial directors, the terms of directors appointed for positions one through three expire May 14, 2016, and the terms of directors appointed for positions four and five expire May 12, 2018.
(c) Sections 3935.051 and 3935.052 do not apply to the appointment or terms of directors appointed under Subsection (a). A director appointed to succeed a director appointed under Subsection (a) serves until May 1 of the appropriate year.
Added by Acts 2015, 84th Leg., R.S., Ch. 885 (H.B. 4180 ), Sec. 2, eff. June 18, 2015.
