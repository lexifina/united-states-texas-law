# Sec. 1096.158. TAX EXEMPTION.
Because property owned by the district is held for public purposes only and is devoted exclusively to the use and benefit of the public, the property is exempt from taxation of every character.
Added by Acts 2013, 83rd Leg., R.S., Ch. 112 (S.B. 1026), Sec. 1.01, eff. April 1, 2015.
