# Sec. 8851.053. ELECTION DATE.
On the uniform election date in November of each even-numbered year, the appropriate number of directors shall be elected.
Added by Acts 2011, 82nd Leg., R.S., Ch. 70 (S.B. 1147), Sec. 1.03, eff. April 1, 2013.
Amended by:
Acts 2013, 83rd Leg., R.S., Ch. 161 (S.B. 1093), Sec. 18.017(a), eff. September 1, 2013.
