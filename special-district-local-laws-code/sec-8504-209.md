# Sec. 8504.209. BOARD DETERMINATION CONCLUSIVE.
A determination by the board that a program is intended and expected to carry out the program's stated purposes is conclusive with respect to whether the purposes of this subchapter are satisfied.
Added by Acts 2013, 83rd Leg., R.S., Ch. 112 (S.B. 1026), Sec. 1.04, eff. April 1, 2015.
