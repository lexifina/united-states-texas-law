# Sec. 3001.212. REHEARING.
A motion for rehearing is subject to Section 2001.146, Government Code, except that the property owner must file the motion for rehearing not later than the 30th day after the date on which the assessment order is issued.
Acts 2003, 78th Leg., ch. 1277, Sec. 1, eff. April 1, 2005.
