# Sec. 1011.053. BALLOT PETITION.
(a) A person who wants to have the person's name printed on the ballot as a candidate for director must file with the board secretary a petition requesting that action. The petition must be signed by not fewer than 10 registered voters.
(b) The petition and an application for a place on the ballot that meets the requirements of the Election Code must be filed in the manner provided by Chapter 144, Election Code.
Added by Acts 2011, 82nd Leg., R.S., Ch. 70 (S.B. 1147), Sec. 1.01, eff. April 1, 2013.
