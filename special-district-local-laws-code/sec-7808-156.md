# Sec. 7808.156. REUSE PROJECT FINANCING.
The district may finance a reuse project with property taxes, mandatory fees, or voluntary contributions.
Added by Acts 2013, 83rd Leg., R.S., Ch. 824 (S.B. 1854), Sec. 1, eff. June 14, 2013.
Amended by:
Acts 2019, 86th Leg., R.S., Ch. 1200 (H.B. 4712), Sec. 2, eff. June 14, 2019.
