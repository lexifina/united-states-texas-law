# Sec. 3897.163. ACQUISITION OF PROPERTY.
If the governing body of the municipality where the improvement project is located consents, an improvement project may include the acquisition of property or an interest in property in connection with an improvement project, including a project authorized by Subchapter A, Chapter 372, Local Government Code.
Added by Acts 2011, 82nd Leg., R.S., Ch. 656 (S.B. 1184), Sec. 1, eff. June 17, 2011.
