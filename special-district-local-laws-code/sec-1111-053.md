# Sec. 1111.053. REQUEST TO APPEAR ON BALLOT.
A person who wants to have the person's name printed on the ballot as a candidate for manager must file a written request with the board secretary. The request must be:
(1) signed by at least 20 district voters; and
(2) filed by the deadline imposed by Section 144.005, Election Code.
Added by Acts 2011, 82nd Leg., R.S., Ch. 70 (S.B. 1147), Sec. 1.01, eff. April 1, 2013.
