# Sec. 8111.105. DISTRICT NAMES FOLLOWING DIVISION.
The area designated by the board as the original district retains the name of the original district. The resulting new districts are assigned consecutive letters to be appended to the name of the original district.
Added by Acts 2005, 79th Leg., Ch. 1168 (H.B. 3497), Sec. 1, eff. September 1, 2005.
