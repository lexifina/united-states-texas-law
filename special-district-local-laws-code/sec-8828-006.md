# Sec. 8828.006. CONFLICTS OF LAW.
(a) Except as otherwise provided by this chapter, if there is a conflict between this chapter and Chapter 36 or 49, Water Code, this chapter controls.
(b) If there is a conflict between Chapters 36 and 49, Water Code, Chapter 36 controls.
Added by Acts 2009, 81st Leg., R.S., Ch. 1139 (H.B. 2619), Sec. 1.05, eff. April 1, 2011.
