# Sec. 8446.051. GOVERNING BODY; TERMS.
(a) The district is governed by a board of five elected directors.
(b) Except as provided by Section 8446.052, directors serve staggered four-year terms.
Added by Acts 2013, 83rd Leg., R.S., Ch. 1250 (S.B. 1910), Sec. 3, eff. September 1, 2013.
