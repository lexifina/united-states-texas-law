# Sec. 8865.055. QUORUM; VOTE REQUIRED FOR BOARD ACTION.
(a) A quorum exists when at least two-thirds of the directors are present.
(b) A majority vote of a quorum of the board is required for board action. If there is a tie vote, the proposed action fails.
Added by Acts 2013, 83rd Leg., R.S., Ch. 112 (S.B. 1026), Sec. 1.05, eff. April 1, 2015.
