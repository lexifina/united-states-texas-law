# Sec. 5016.0053. FILING OF FINANCIAL STATEMENT BY PORT COMMISSIONERS.
(a) Not later than April 30 of each year, a port commissioner shall file with the Texas Ethics Commission a financial statement that complies with Sections 572.022-572.024, Government Code.
(b) The filed statement is a public record.
Added by Acts 2019, 86th Leg., R.S., Ch. 468 (H.B. 4172), Sec. 1.01, eff. April 1, 2021.
