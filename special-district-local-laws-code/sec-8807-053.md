# Sec. 8807.053. CHANGE IN COMPOSITION; ADDITIONAL COUNTY.
If a county is added to the district under Section 8807.005, the board may change the number of directors so that an equal number of directors is appointed from each county and one director is appointed jointly by the counties in the district.
Added by Acts 2005, 79th Leg., Ch. 863 (S.B. 1017), Sec. 1, eff. June 17, 2005.
