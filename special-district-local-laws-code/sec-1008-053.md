# Sec. 1008.053. BALLOT APPLICATION.
(a) A person must file an application with the board secretary to have the person's name printed on the ballot as a candidate for director.
(b) The application must be filed at least 45 days before the date of the election.
Added by Acts 2005, 79th Leg., Ch. 729 (H.B. 2019), Sec. 1.01, eff. April 1, 2007.
