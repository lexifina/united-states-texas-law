# Sec. 3906.206. NONPOTABLE WATER USER CHARGES.
The district may establish user charges for the use of nonpotable water for irrigation purposes, subject to approval of the governing body of the municipality in which the user is located.
Added by Acts 2011, 82nd Leg., R.S., Ch. 1269 (S.B. 1922), Sec. 1, eff. June 17, 2011.
