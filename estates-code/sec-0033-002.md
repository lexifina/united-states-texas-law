# Sec. 33.002. ACTION RELATED TO PROBATE PROCEEDING IN STATUTORY PROBATE COURT.
Except as provided by Section 33.003, venue for any cause of action related to a probate proceeding pending in a statutory probate court is proper in the statutory probate court in which the decedent's estate is pending.
Added by Acts 2011, 82nd Leg., R.S., Ch. 1338 (S.B. 1198), Sec. 2.04, eff. January 1, 2014.
