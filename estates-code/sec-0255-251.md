# Sec. 255.251. DEFINITIONS.
In this subchapter:
(1) "Securities" has the meaning assigned by Section 4001.068, Government Code.
(2) "Stock" means securities.
Added by Acts 2009, 81st Leg., R.S., Ch. 680 (H.B. 2502), Sec. 1, eff. January 1, 2014.
Amended by:
Acts 2019, 86th Leg., R.S., Ch. 491 (H.B. 4171), Sec. 2.10, eff. January 1, 2022.
