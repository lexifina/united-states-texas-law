# Sec. 2001.003. APPLICABILITY.
(a) This chapter applies to a custodian if the user resides in this state or resided in this state at the time of the user's death.
(b) This chapter does not apply to a digital asset of an employer used by an employee in the ordinary course of the employer's business.
Added by Acts 2017, 85th Leg., R.S., Ch. 400 (S.B. 1193), Sec. 1, eff. September 1, 2017.
