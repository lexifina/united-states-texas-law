# Sec. 501.003. CITATION AND NOTICE.
(a) Citation or notice is not required for an application described by Section 501.002(a).
(b) For an application described by Section 501.002(b), a citation shall be issued and served by a qualified delivery method on each devisee and heir identified in the application.
Added by Acts 2009, 81st Leg., R.S., Ch. 680 (H.B. 2502), Sec. 1, eff. January 1, 2014.
Amended by:
Acts 2023, 88th Leg., R.S., Ch. 205 (S.B. 1373), Sec. 44, eff. September 1, 2023.
