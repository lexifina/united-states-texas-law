# Sec. 153.002. INAPPLICABILITY OF CHAPTER.
This chapter does not apply to:
(1) an account with a beneficiary designation;
(2) a P.O.D. account;
(3) a trust account; or
(4) an account that provides for a right of survivorship.
Added by Acts 2015, 84th Leg., R.S., Ch. 217 (H.B. 705), Sec. 1, eff. September 1, 2015.
