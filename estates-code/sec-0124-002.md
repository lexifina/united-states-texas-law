# Sec. 124.002. REFERENCES TO INTERNAL REVENUE CODE.
A reference in this subchapter to a section of the Internal Revenue Code of 1986 refers to that section as it exists at the time in question. The reference also includes a corresponding section of a subsequent Internal Revenue Code and, if the referenced section is renumbered, the section as renumbered.
Added by Acts 2009, 81st Leg., R.S., Ch. 680, Sec. 1, eff. January 1, 2014.
