# Sec. 33.051. COMMENCEMENT OF PROCEEDING.
For purposes of this subchapter, a probate proceeding is considered commenced on the filing of an application for the proceeding that avers facts sufficient to confer venue on the court in which the application is filed.
Added by Acts 2011, 82nd Leg., R.S., Ch. 1338 (S.B. 1198), Sec. 2.04, eff. January 1, 2014.
