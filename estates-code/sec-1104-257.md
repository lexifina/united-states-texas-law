# Sec. 1104.257. INFORMATION REGARDING SERVICES PROVIDED BY GUARDIANSHIP PROGRAM.
Not later than January 31 of each year, each guardianship program operating in a county shall submit to the county clerk a copy of the report submitted to the guardianship certification program of the Judicial Branch Certification Commission under Section 155.105, Government Code.
Added by Acts 2011, 82nd Leg., R.S., Ch. 823 (H.B. 2759), Sec. 1.02, eff. January 1, 2014.
Amended by:
Acts 2013, 83rd Leg., R.S., Ch. 42 (S.B. 966), Sec. 2.13, eff. September 1, 2014.
