# Sec. 361.001. RESIGNATION APPLICATION.
A personal representative who wishes to resign the representative's trust shall file a written application with the court clerk, accompanied by a complete and verified exhibit and final account showing the true condition of the estate entrusted to the representative's care.
Added by Acts 2009, 81st Leg., R.S., Ch. 680 (H.B. 2502), Sec. 1, eff. January 1, 2014.
