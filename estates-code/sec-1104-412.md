# Sec. 1104.412. EFFECT OF SUBCHAPTER ON DEPARTMENT'S AUTHORITY TO OBTAIN OR USE INFORMATION.
This subchapter does not prohibit the department from obtaining and using criminal history record information as provided by other law.
Added by Acts 2011, 82nd Leg., R.S., Ch. 823 (H.B. 2759), Sec. 1.02, eff. January 1, 2014.
