# Sec. 153.001. DEFINITIONS.
In this chapter:
(1) "Account" has the meaning assigned by Section 113.001.
(2) "Financial institution" has the meaning assigned by Section 201.101, Finance Code.
(3) "P.O.D. account" and "trust account" have the meanings assigned by Section 113.004.
Added by Acts 2015, 84th Leg., R.S., Ch. 217 (H.B. 705), Sec. 1, eff. September 1, 2015.
