# Sec. 1355.151. APPLICABILITY OF SUBCHAPTER.
This subchapter applies only to money of a resident of an eleemosynary institution of this state that is on deposit in a court registry and does not exceed $10,000.
Added by Acts 2011, 82nd Leg., R.S., Ch. 823 (H.B. 2759), Sec. 1.02, eff. January 1, 2014.
