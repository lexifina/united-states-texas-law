# Sec. 1104.357. NONRESIDENT WITHOUT RESIDENT AGENT.
A person may not be appointed guardian if the person is a nonresident who has failed to file with the court the name of a resident agent to accept service of process in all actions or proceedings relating to the guardianship.
Added by Acts 2011, 82nd Leg., R.S., Ch. 823 (H.B. 2759), Sec. 1.02, eff. January 1, 2014.
