# Sec. 1352.058. SWORN REPORT OF EXPENDITURES.
When the parent or managing conservator has spent the proceeds of a home equity loan authorized under this subchapter, the parent or managing conservator shall file with the county clerk a sworn report accounting for the proceeds.
Added by Acts 2011, 82nd Leg., R.S., Ch. 823 (H.B. 2759), Sec. 1.02, eff. January 1, 2014.
