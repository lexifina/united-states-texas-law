# Sec. 255.154. DEVISEE UNDER CLASS GIFT.
For purposes of this subchapter, a person who would have been a devisee under a class gift if the person had survived the testator is treated as a devisee unless the person died before the date the will was executed.
Added by Acts 2009, 81st Leg., R.S., Ch. 680 (H.B. 2502), Sec. 1, eff. January 1, 2014.
