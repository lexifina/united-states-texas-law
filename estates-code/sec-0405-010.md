# Sec. 405.010. ISSUANCE OF LETTERS.
At any time before the authority of an independent executor has been terminated in the manner set forth in this subtitle, the clerk shall issue such number of letters testamentary as the independent executor shall request.
Added by Acts 2011, 82nd Leg., R.S., Ch. 1338 (S.B. 1198), Sec. 2.53, eff. January 1, 2014.
