# Sec. 1104.411. CRIMINAL OFFENSE FOR UNAUTHORIZED RELEASE OR DISCLOSURE.
(a) A person commits an offense if the person releases or discloses any information received under this subchapter without the authorization prescribed by Section 1104.405 or 1104.408.
(b) An offense under this section is a Class A misdemeanor.
Added by Acts 2011, 82nd Leg., R.S., Ch. 823 (H.B. 2759), Sec. 1.02, eff. January 1, 2014.
