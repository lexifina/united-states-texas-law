# Sec. 51.031. OFFENSE; PENALTY.
(a) Except as provided by Subsection (b), an offense under this chapter is a Class B misdemeanor.
(b) An offense under Section 51.014(d), 51.0145, or 51.016(i)(3) is a Class A misdemeanor.
