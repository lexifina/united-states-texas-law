# Sec. 301.022. AUDIT.
The financial transactions of the commission are subject to audit by the state auditor in accordance with Chapter 321, Government Code.
Acts 1993, 73rd Leg., ch. 269, Sec. 1, eff. Sept. 1, 1993. Renumbered from Labor Code Sec. 202.022 by Acts 1995, 74th Leg., ch. 655, Sec. 11.02(b), eff. Sept. 1, 1995.
