# Sec. 410.119. EFFECT OF AWARD.
(a) An arbitrator's award is final and binding on all parties. Except as provided by Section 410.121, there is no right to appeal.
(b) An arbitrator's award is a final order of the division.
Acts 1993, 73rd Leg., ch. 269, Sec. 1, eff. Sept. 1, 1993.
