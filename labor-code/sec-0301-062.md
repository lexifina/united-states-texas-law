# Sec. 301.062. FINDINGS.
Both the commission and the executive director may make findings and determine issues under this title as necessary to administer this title.
Acts 1993, 73rd Leg., ch. 269, Sec. 1, eff. Sept. 1, 1993. Renumbered from Labor Code Sec. 202.062 and amended by Acts 1995, 74th Leg., ch. 655, Sec. 11.02(b), eff. Sept. 1, 1995.
