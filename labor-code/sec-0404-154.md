# Sec. 404.154. PUBLIC INFORMATION.
The office shall widely disseminate information about the ombudsman program.
Acts 1993, 73rd Leg., ch. 269, Sec. 1, eff. Sept. 1, 1993. Renumbered from Labor Code Sec. 409.042 by Acts 1995, 74th Leg., ch. 980, Sec. 1.31, eff. Sept. 1, 1995.
Redesignated from Labor Code, Section 409.044 and amended by Acts 2005, 79th Leg., Ch. 265 (H.B. 7), Sec. 3.017, eff. September 1, 2005.
