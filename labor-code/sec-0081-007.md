# Sec. 81.007. RULES.
The commission may adopt rules to implement this chapter.
Added by Acts 1993, 73rd Leg., ch. 269, Sec. 1, eff. Sept. 1, 1993.
Amended by:
Acts 2005, 79th Leg., Ch. 263 (H.B. 2962), Sec. 3, eff. May 30, 2005.
Acts 2023, 88th Leg., R.S., Ch. 846 (H.B. 2975), Sec. 1, eff. September 1, 2023.
