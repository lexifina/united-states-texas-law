# Sec. 302.306. RULES; REVIEW.
The commission shall:
(1) adopt rules for the administration of this subchapter; and
(2) periodically verify that grant money awarded to a nonprofit organization under the program is being used appropriately.
Added by Acts 2025, 89th Leg., R.S., Ch. 329 (S.B. 2448), Sec. 1, eff. September 1, 2025.
