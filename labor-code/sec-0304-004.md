# Sec. 304.004. COOPERATION BY STATE AGENCIES AND POLITICAL SUBDIVISIONS.
State agencies and political subdivisions of the state shall cooperate with the commission in obtaining suitable employment for displaced homemakers counseled by the commission.
Acts 1993, 73rd Leg., ch. 269, Sec. 1, eff. Sept. 1, 1993. Renumbered from Labor Code Sec. 302.004 by Acts 1995, 74th Leg., ch. 655, Sec. 11.04, eff. Sept. 1, 1995.
