# Sec. 415.034. HEARING PROCEDURES.
On the request of the charged party or the commissioner, the State Office of Administrative Hearings shall set a hearing. The hearing shall be conducted in the manner provided for a contested case under Chapter 2001, Government Code (the administrative procedure law).
