# Sec. 201.030. PROFESSIONAL EMPLOYER ORGANIZATION.
For the purposes of this subtitle, "professional employer organization" has the meaning assigned by Section 91.001.
Added by Acts 1997, 75th Leg., ch. 1379, Sec. 20, eff. Sept. 1, 1997.
Amended by:
Acts 2013, 83rd Leg., R.S., Ch. 117 (S.B. 1286), Sec. 18, eff. September 1, 2013.
