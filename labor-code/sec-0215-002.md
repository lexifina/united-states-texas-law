# Sec. 215.002. SHARED WORK UNEMPLOYMENT COMPENSATION PROGRAM.
(a) The commission, under a voluntary shared work unemployment compensation program designed to reduce unemployment and stabilize the work force, shall allow participating employees shared work benefits.
(b) The commission may adopt rules and establish procedures necessary to administer the shared work program.
Acts 1993, 73rd Leg., ch. 269, Sec. 1, eff. Sept. 1, 1993.
