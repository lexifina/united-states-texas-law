# Sec. 207.112. APPLICATION.
This subchapter applies only if arrangements have been made for reimbursement by the state agency for the administrative costs incurred by the commission under this subchapter that are attributable to the repayment of uncollected overissuances to the state agency.
Added by Acts 1997, 75th Leg., ch. 93, Sec. 3, eff. Sept. 1, 1997.
