# Sec. 120.1025. TREATMENT OF REPORTED CONTENT.
(a) If a social media platform determines that content reported by a user is not explicit deep fake material, the social media platform may restore the material.
(b) If a social media platform determines that content reported by a user is explicit deep fake material, the social media platform shall implement measures to ensure the same material is not posted on the social media platform again.
Added by Acts 2025, 89th Leg., R.S., Ch. 749 (H.B. 3133), Sec. 5, eff. September 1, 2025.
