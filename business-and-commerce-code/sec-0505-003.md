# Sec. 505.003. RETENTION OF ZIP CODE PROHIBITED.
A business that obtains a customer's zip code under Section 505.002 may not retain the zip code in any form after the purchase of the good or service has been completed.
Added by Acts 2009, 81st Leg., R.S., Ch. 87 (S.B. 1969), Sec. 4.010(a), eff. September 1, 2009.
