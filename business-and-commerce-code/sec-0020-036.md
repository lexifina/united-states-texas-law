# Sec. 20.036. NOTIFICATION OF SECURITY FREEZE.
A consumer reporting agency shall notify a person who requests a consumer report if a security freeze is in effect for the consumer file involved in that report.
Added by Acts 2003, 78th Leg., ch. 1326, Sec. 3, eff. Sept. 1, 2003.
Assigned by Acts 2013, 83rd Leg., R.S., Ch. 64 (S.B. 60), Sec. 3, eff. January 1, 2014.
