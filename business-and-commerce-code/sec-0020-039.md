# Sec. 20.039. RESPECT OF SECURITY FREEZE.
A consumer reporting agency shall honor a security freeze placed on a consumer file by another consumer reporting agency.
Added by Acts 2003, 78th Leg., ch. 1326, Sec. 3, eff. Sept. 1, 2003.
Assigned by Acts 2013, 83rd Leg., R.S., Ch. 64 (S.B. 60), Sec. 3, eff. January 1, 2014.
