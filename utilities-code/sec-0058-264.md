# Sec. 58.264. COMPLAINTS LIMITED.
(a) Notwithstanding any other provision of this title, an electing company is subject to a complaint under this subchapter only by an entity described by Section 58.253(a).
(b) An entity may only complain that the company provided a private network service under this subchapter preferentially to a similarly situated customer.
Acts 1997, 75th Leg., ch. 166, Sec. 1, eff. Sept. 1, 1997.
