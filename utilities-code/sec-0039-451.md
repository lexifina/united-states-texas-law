# Sec. 39.451. APPLICABILITY.
This subchapter applies only to an investor-owned electric utility that is operating solely outside of ERCOT in areas of this state that were included in the Southeastern Electric Reliability Council on January 1, 2005.
Added by Acts 2005, 79th Leg., Ch. 1072 (H.B. 1567), Sec. 1, eff. June 18, 2005.
