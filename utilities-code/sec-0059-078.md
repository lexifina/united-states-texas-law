# Sec. 59.078. PRIVATE LINE OR SPECIAL ACCESS RATES.
(a) On request by an educational institution or a library, an electing company shall provide 1.544 megabits a second private line or special access service at 110 percent of the service's long run incremental cost, including installation costs.
(b) The rate provided by Subsection (a) is in lieu of the discount provided by Subchapter B, Chapter 57.
Acts 1997, 75th Leg., ch. 166, Sec. 1, eff. Sept. 1, 1997.
