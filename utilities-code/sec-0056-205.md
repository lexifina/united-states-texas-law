# Sec. 56.205. HEARING.
If the commission finds that the petition complies with Section 56.204, the commission shall hold an evidentiary hearing to determine if a telecommunications provider is willing to be designated to provide service to those premises or, if a provider is not willing to be designated, to determine the telecommunications provider that is best able to serve those premises under the criteria prescribed by this subchapter.
Added by Acts 2001, 77th Leg., ch. 651, Sec. 4, eff. Sept. 1, 2001.
