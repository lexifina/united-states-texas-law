# Sec. 251.008. EFFECT ON CIVIL REMEDIES.
Except as otherwise specifically provided by this chapter, this chapter, including Section 251.201, does not affect any civil remedy for personal injury or for property damage, including any damage to an underground facility.
Added by Acts 1999, 76th Leg., ch. 62, Sec. 18.17(a), eff. Sept. 1, 1999.
