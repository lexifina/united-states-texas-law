# Sec. 52.255. AVAILABILITY OF RECORDS.
Notwithstanding Section 14.152, a book, account, record, or memorandum of a public utility may be removed from this state if the book, account, record, or memorandum is returned to this state for any commission inspection authorized by this title.
Acts 1997, 75th Leg., ch. 166, Sec. 1, eff. Sept. 1, 1997.
