# Sec. 56.030. AFFIDAVITS OF COMPLIANCE.
On or before September 1 of each year, a telecommunications provider that receives disbursements from the universal service fund shall file with the commission an affidavit certifying that the telecommunications provider is in compliance with the requirements for receiving money from the universal service fund and requirements regarding the use of money from each universal service fund program for which the telecommunications provider receives disbursements.
Added by Acts 2005, 79th Leg., 2nd C.S., Ch. 2 (S.B. 5), Sec. 15, eff. September 7, 2005.
