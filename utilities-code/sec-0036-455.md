# Sec. 36.455. COMMISSION REGULATION OF CORPORATION.
The commission shall regulate the corporation as provided by this subchapter and consistent with the manner in which it regulates public utilities. Notwithstanding the regulation authorized by this section, the corporation is not a public utility.
Added by Acts 2021, 87th Leg., R.S., Ch. 198 (H.B. 1510), Sec. 2, eff. June 1, 2021.
