# Sec. 58.259. TARIFF RATE FOR CERTAIN INTRALATA SERVICE.
(a) An electing company shall file a flat monthly tariff rate for point-to-point intraLATA 1.544 megabits a second service for the entities described by Section 58.253(a).
(b) The tariff rate may not be:
(1) distance sensitive; or
(2) higher than 110 percent of the service's statewide average long run incremental cost, including installation.
Acts 1997, 75th Leg., ch. 166, Sec. 1, eff. Sept. 1, 1997.
