# Sec. 55.081. DEFINITION.
In this subchapter, "operator service" means a service using live operator or automated operator functions to handle telephone service such as toll calling using collect, third-number billing, and calling card services. The term does not include a call for which the called party has arranged to be billed (800 service).
Acts 1997, 75th Leg., ch. 166, Sec. 1, eff. Sept. 1, 1997.
