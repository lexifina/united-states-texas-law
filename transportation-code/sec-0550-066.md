# Sec. 550.066. ADMISSIBILITY OF CERTAIN COLLISION REPORT INFORMATION.
An individual's response to the information requested on a collision report form as provided by Section 550.064(b)(4) is not admissible evidence in a civil trial.
Acts 1995, 74th Leg., ch. 165, Sec. 1, eff. Sept. 1, 1995.
Amended by:
Acts 2023, 88th Leg., R.S., Ch. 709 (H.B. 2190), Sec. 58, eff. September 1, 2023.
