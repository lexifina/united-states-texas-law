# Sec. 623.070. NONAPPLICABILITY OF SUBCHAPTER.
This subchapter does not apply to the transportation of an intermodal shipping container as defined by Section 623.401, regardless of whether the container is sealed or unsealed.
Added by Acts 2017, 85th Leg., R.S., Ch. 108 (S.B. 1524), Sec. 7, eff. January 1, 2018.
