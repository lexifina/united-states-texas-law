# Sec. 504.205. INFORMATION PROVIDED WITH PLATES.
The department shall include with each set of specialty license plates issued under this subchapter a document that provides:
(1) information on laws governing parking for persons with disabilities; and
(2) instructions for reporting alleged violations of Chapter 681.
Added by Acts 2019, 86th Leg., R.S., Ch. 1159 (H.B. 3163), Sec. 2, eff. September 1, 2019.
