# Sec. 203.091. DEFINITION.
In this subchapter, "utility" includes a publicly, privately, or cooperatively owned utility that provides telephone, telegraph, communications, electric, gas, heating, water, railroad, storm sewer, sanitary sewer, or pipeline service.
Acts 1995, 74th Leg., ch. 165, Sec. 1, eff. Sept. 1, 1995.
