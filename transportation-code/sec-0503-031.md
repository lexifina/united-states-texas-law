# Sec. 503.031. APPLICATION FOR DRIVE-A-WAY IN-TRANSIT LICENSE.
(a) An applicant for a drive-a-way in-transit license must submit to the commission an application containing the information required by the commission.
(b) The license application must be accompanied by the registration fee prescribed by Section 503.007(c).
Acts 1995, 74th Leg., ch. 165, Sec. 1, eff. Sept. 1, 1995.
