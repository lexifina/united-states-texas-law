# Sec. 366.161. TURNPIKE PROJECTS EXTENDING INTO OTHER COUNTIES.
An authority may acquire, construct, operate, maintain, expand, or extend a turnpike project in:
(1) a county that is a part of the authority; or
(2) subject to Sections 366.031(e) and 366.0311, a county in which the authority operates or is constructing a turnpike project if the turnpike project in the affected county is a continuation of the authority's turnpike project or system extending from an adjacent county.
Added by Acts 1997, 75th Leg., ch. 1171, Sec. 7.24, eff. Sept. 1, 1997.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 727 (H.B. 1394), Sec. 3, eff. September 1, 2015.
