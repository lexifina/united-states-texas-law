# Sec. 71.101. PILOT QUALIFICATIONS.
The pilot board of a navigation district in Cameron County shall examine and determine the qualifications of each applicant for the position of branch pilot or deputy branch pilot in that navigation district before licensing the branch pilot or certifying the deputy branch pilot, as applicable.
Added by Acts 2025, 89th Leg., R.S., Ch. 821 (S.B. 1353), Sec. 2, eff. September 1, 2025.
