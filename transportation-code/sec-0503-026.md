# Sec. 503.026. REQUIREMENT FOR EACH TYPE OF DEALER VEHICLE.
A person must obtain a dealer general distinguishing number for each type of vehicle the person intends to sell.
Acts 1995, 74th Leg., ch. 165, Sec. 1, eff. Sept. 1, 1995. Amended by Acts 1997, 75th Leg., ch. 871, Sec. 1, eff. Sept. 1, 1997.
