# Sec. 623.366. TIME OF MOVEMENT.
A permit issued under this subchapter must specify the time during which movement authorized by the permit is allowed.
Added by Acts 2013, 83rd Leg., R.S., Ch. 635 (H.B. 474), Sec. 1, eff. September 1, 2013.
Redesignated from Transportation Code, Section 623.325 by Acts 2015, 84th Leg., R.S., Ch. 1236 (S.B. 1296), Sec. 21.001(61), eff. September 1, 2015.
