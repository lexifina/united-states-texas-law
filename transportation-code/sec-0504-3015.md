# Sec. 504.3015. FEES FOR MILITARY SPECIALTY LICENSE PLATES.
(a) A person applying for a set of license plates under this subchapter shall pay the registration fee required under Chapter 502, except that one set of license plates shall be issued without the payment of the registration fee under:
(1) Section 504.308;
(2) Section 504.310(b);
(3) Section 504.315, other than Subsections (c) and (q) of that section; and
(4) Section 504.319.
(b) Except as otherwise provided by this subchapter, there is no additional fee for a specialty license plate issued under this subchapter.
(c) A surviving spouse applying for a set of license plates under Section 504.302 shall pay the fees required for the type of license plate for which the surviving spouse is eligible.
