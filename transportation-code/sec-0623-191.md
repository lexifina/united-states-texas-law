# Sec. 623.191. OPTIONAL PROCEDURE.
This subchapter provides an optional procedure for the issuance of a permit for the movement of an unladen lift equipment motor vehicle that because of its design for use as lift equipment exceeds the maximum weight and width limitations prescribed by statute.
Acts 1995, 74th Leg., ch. 165, Sec. 1, eff. Sept. 1, 1995.
