# Sec. 391.184. DISPOSAL OF STATE REAL PROPERTY.
An interest in real property acquired to implement this chapter that becomes surplus and is determined by the commission as no longer necessary to the state for the purpose for which it was acquired or for a highway purpose shall be disposed of in accordance with Subchapter B, Chapter 202.
Acts 1995, 74th Leg., ch. 165, Sec. 1, eff. Sept. 1, 1995.
