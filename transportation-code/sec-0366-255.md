# Sec. 366.255. COMPENSATION OF DIRECTOR.
Each director is entitled to reimbursement for the director's actual expenses necessarily incurred in the performance of the director's duties. A director is not entitled to any additional compensation for the director's services.
Added by Acts 1997, 75th Leg., ch. 1171, Sec. 7.24, eff. Sept. 1, 1997.
