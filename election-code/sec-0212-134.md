# Sec. 212.134. EARLY VOTING VOTES TREATED AS PRECINCT.
(a) Except as provided by Subsection (b), for the purpose of specifying which election precincts are to be included in a recount, all the early voting votes canvassed by a local canvassing authority shall be treated as constituting one election precinct.
(b) Each early voting polling place in which voting machines were used shall be treated as constituting one election precinct.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986. Amended by Acts 1991, 72nd Leg., ch. 203, Sec. 2.67; Acts 1991, 72nd Leg., ch. 554, Sec. 38, eff. Sept. 1, 1991.
