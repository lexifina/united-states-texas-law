# Sec. 216.003. INITIATING AUTOMATIC RECOUNT.
For purposes of initiating an automatic recount, the authority designated under Section 212.026 shall order the recount.
Added by Acts 2001, 77th Leg., ch. 851, Sec. 3, eff. Sept. 1, 2001.
Amended by:
Acts 2021, 87th Leg., R.S., Ch. 711 (H.B. 3107), Sec. 95, eff. September 1, 2021.
