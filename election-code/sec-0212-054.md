# Sec. 212.054. APPLICATION FOR SUPPLEMENTARY RECOUNT REQUIRED.
A supplementary recount may not be conducted unless a person authorized to obtain the recount submits, as provided by this subchapter, an application for the recount that complies with the applicable requirements prescribed by this title.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986.
