# Sec. 277.001. APPLICABILITY OF CHAPTER.
This chapter applies to a petition authorized or required to be filed under a law outside this code in connection with an election.
Added by Acts 1987, 70th Leg., ch. 54, Sec. 16(c), eff. Sept. 1, 1987. Amended by Acts 1993, 73rd Leg., ch. 728, Sec. 81, eff. Sept. 1, 1993.
Amended by:
Acts 2009, 81st Leg., R.S., Ch. 1235 (S.B. 1970), Sec. 25, eff. September 1, 2009.
