# Sec. 1.018. APPLICABILITY OF PENAL CODE.
In addition to Section 1.03, Penal Code, and to other titles of the Penal Code that may apply to this code, Titles 2 and 4, Penal Code, apply to offenses prescribed by this code.
Added by Acts 2003, 78th Leg., ch. 393, Sec. 2, eff. Sept. 1, 2003.
Amended by:
Acts 2021, 87th Leg., 2nd C.S., Ch. 1 (S.B. 1), Sec. 1.07, eff. December 2, 2021.
