# Sec. 111.003. APPLICATION REQUIRED.
(a) To be entitled to vote a restricted ballot, a person must make an application for the ballot.
(b) A restricted ballot application is subject to the applicable provisions of Chapter 84.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986. Amended by Acts 1991, 72nd Leg., ch. 203, Sec. 2.29; Acts 1991, 72nd Leg., ch. 554, Sec. 1, eff. Sept. 1, 1991.
