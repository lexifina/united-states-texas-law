# Sec. 1.021. NOTICE OF POLLING PLACE LOCATION.
When this code requires notice of a polling place location, the written notice must state the building name, if any, and the street address, including the suite or room number, if any, of the polling place.
Added by Acts 2019, 86th Leg., R.S., Ch. 42 (H.B. 1241), Sec. 1, eff. September 1, 2019.
