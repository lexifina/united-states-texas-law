# Sec. 146.0232. NUMBER OF PETITION SIGNATURES REQUIRED.
The minimum number of signatures that must appear on the petition authorized by Section 146.023(b) is the number prescribed by Section 172.025 to appear on a petition of a candidate for nomination for the same office in a general primary election.
Added by Acts 1991, 72nd Leg., ch. 170, Sec. 1, eff. Sept. 1, 1991.
