# Sec. 211.006. PROMPT PERFORMANCE OF RECOUNT FUNCTIONS.
(a) Each authority responsible for performing a function in a recount shall perform the function diligently and shall take prompt action at every stage of the proceeding.
(b) This section is enforceable by writ of mandamus.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986.
