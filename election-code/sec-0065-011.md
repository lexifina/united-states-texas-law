# Sec. 65.011. OVERVOTING.
If a voter marks the ballot for more candidates for an office than the number of persons to be elected for that office, none of the votes may be counted for that office.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986. Amended by Acts 1993, 73rd Leg., ch. 728, Sec. 19, eff. Sept. 1, 1993.
Amended by:
Acts 2017, 85th Leg., R.S., Ch. 404 (H.B. 25), Sec. 4, eff. September 1, 2020.
