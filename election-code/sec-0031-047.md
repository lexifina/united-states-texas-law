# Sec. 31.047. ACTION BY WRONG OFFICER.
If a statute specifies that an action is to be taken by the county clerk without specifying that it is to be taken by the county elections administrator in a county having that position, an action taken by the county clerk without objection from the administrator has the same legal effect as if taken by the administrator.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986.
