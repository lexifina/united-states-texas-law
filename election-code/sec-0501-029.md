# Sec. 501.029. OFFENSE: MISREPRESENTATION OF PETITION.
(a) A person commits an offense if the person misrepresents the purpose or effect of a petition issued under this chapter.
(b) An offense under this section is a Class B misdemeanor.
Added by Acts 2005, 79th Leg., Ch. 975 (H.B. 1799), Sec. 1, eff. September 1, 2005.
