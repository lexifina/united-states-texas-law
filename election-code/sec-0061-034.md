# Sec. 61.034. TRANSLATING BALLOT.
If a voter cannot comprehend the language in which the ballot is printed, the voter may receive assistance in accordance with Subchapter B, Chapter 64.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986.
Amended by:
Acts 2021, 87th Leg., R.S., Ch. 556 (S.B. 331), Sec. 3, eff. June 14, 2021.
