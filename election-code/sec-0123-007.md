# Sec. 123.007. ADOPTION OF MORE THAN ONE VOTING SYSTEM FOR SAME ELECTION.
If more than one kind of voting system is adopted for use at the polling places in the same election, the adopting authority shall determine the polling place or places at which each system is to be used, subject to Section 123.009.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986. Amended by Acts 2001, 77th Leg., ch. 557, Sec. 2, eff. Sept. 1, 2001.
