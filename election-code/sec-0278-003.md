# Sec. 278.003. STATEMENT FILED BY CANDIDATE.
If the secretary of state implements a voter information service program, a candidate may file with the secretary not later than the 70th day before the date of the judicial election an informational statement, on a form prescribed by the secretary, to be included in the voter information guide for that election.
Added by Acts 2001, 77th Leg., ch. 1285, Sec. 1, eff. Sept. 1, 2001.
