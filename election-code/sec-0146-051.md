# Sec. 146.051. CANDIDATE'S NAME REQUIRED TO APPEAR ON LIST.
In an election for city officers, a write-in vote may not be counted unless the name written in appears on the list of write-in candidates.
Added by Acts 1991, 72nd Leg., ch. 363, Sec. 1, eff. Sept. 1, 1991. Amended by Acts 2001, 77th Leg., ch. 215, Sec. 1, eff. Sept. 1, 2001.
