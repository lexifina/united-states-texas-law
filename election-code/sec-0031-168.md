# Sec. 31.168. ACTION BY WRONG OFFICER.
If a statute specifies that an action is to be taken by an officer without specifying that it is to be taken by the elections administrator of a political subdivision having that position, an action taken by the officer without objection from the administrator has the same legal effect as if taken by the administrator.
Added by Acts 2007, 80th Leg., R.S., Ch. 148 (S.B. 493), Sec. 1, eff. September 1, 2007.
