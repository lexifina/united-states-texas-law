# Sec. 212.025. PETITION FOR INITIAL RECOUNT REQUIRED.
An initial recount may not be conducted unless a person authorized to obtain the recount submits, as provided by this subchapter, a petition for the recount that complies with the applicable requirements prescribed by this title.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986.
