# Sec. 172.0221. NOTICE TO CANDIDATE REGARDING POSTING OF CERTAIN INFORMATION.
The authority with whom an application is filed must inform the candidate that the candidate's public mailing address and, if provided on the application, the candidate's electronic mail address will be posted by the secretary of state on the secretary's publicly viewable website.
Added by Acts 2015, 84th Leg., R.S., Ch. 1179 (S.B. 1073), Sec. 3, eff. September 1, 2015.
