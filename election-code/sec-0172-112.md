# Sec. 172.112. WRITE-IN VOTING.
Write-in voting in a primary election is not permitted.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986. Amended by Acts 1997, 75th Leg., ch. 864, Sec. 145, eff. Sept. 1, 1997.
Amended by:
Acts 2017, 85th Leg., R.S., Ch. 828 (H.B. 1735), Sec. 33, eff. September 1, 2017.
