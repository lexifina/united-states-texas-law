# Sec. 127.091. TEST OF TABULATING EQUIPMENT REQUIRED.
The automatic tabulating equipment used for counting ballots in an election shall be tested as provided by this subchapter.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 1015 (S.B. 2166), Sec. 1, eff. September 1, 2025.
