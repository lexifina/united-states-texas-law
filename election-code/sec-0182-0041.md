# Sec. 182.0041. APPLICATION FOR NOMINATION.
(a) To be entitled to be considered for nomination by a convention held under this chapter, a person must make an application for nomination.
(b) Subchapter B, Chapter 181, applies to an application for nomination under this chapter.
Added by Acts 1987, 70th Leg., ch. 472, Sec. 49, eff. Sept. 1, 1987.
