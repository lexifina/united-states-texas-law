# Sec. 173.061. FEE PAID TO COUNTY CHAIR.
Except as provided by Section 173.0341(c)(2), the county chair shall deposit in the county primary fund each filing fee accompanying an application for a place on the ballot filed with the county chair.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986. Amended by Acts 1997, 75th Leg., ch. 864, Sec. 162, eff. Sept. 1, 1997.
