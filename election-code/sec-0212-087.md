# Sec. 212.087. PROCESSING APPLICATION.
An application for including remaining paper ballot precincts is subject to review, amendment, and action by the recount coordinator in the same manner as a petition submitted under this subchapter, except that Section 212.084 does not apply.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986.
