# Sec. 111.006. MANUALLY COUNTING ELECTRONIC SYSTEM BALLOT.
If a restricted electronic system ballot cannot be automatically counted with other electronic system ballots voted in the election that are to be counted automatically, the restricted ballot shall be counted manually.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986. Amended by Acts 1991, 72nd Leg., ch. 203, Sec. 2.29; Acts 1991, 72nd Leg., ch. 554, Sec. 1, eff. Sept. 1, 1991.
