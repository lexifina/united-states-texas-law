# Sec. 68.007. POSTING REPORTS FOR PUBLIC INSPECTION.
(a) The secretary of state shall post for public inspection, on publication, one copy of each report published under Section 68.004.
(b) The secretary of state may post for public inspection any of the reports prepared under this subchapter.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986.
