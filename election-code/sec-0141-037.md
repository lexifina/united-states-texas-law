# Sec. 141.037. FORM OF NAME CERTIFIED FOR PLACEMENT ON BALLOT.
An authority responsible for certifying the names of candidates for placement on the ballot shall certify each name in the form indicated on the candidate's application for a place on the ballot, subject to Subchapter B, Chapter 52.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986.
