# Sec. 127.010. TRAINING.
The secretary of state shall provide a standardized training program and materials for members of a counting station in the same manner it provides such a program under Subchapter F, Chapter 32.
Added by Acts 2023, 88th Leg., R.S., Ch. 415 (H.B. 1632), Sec. 5, eff. September 1, 2023.
