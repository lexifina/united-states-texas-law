# Sec. 32.003. JUDGES FOR CONSOLIDATED COUNTY ELECTION PRECINCTS.
If election precincts are consolidated in a special election in which the regular county election precincts are required to be used, the commissioners court shall appoint the election judges to serve in each consolidated precinct from among the judges appointed for the precincts comprising the consolidated precinct.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986.
