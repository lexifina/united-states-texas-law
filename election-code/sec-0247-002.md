# Sec. 247.002. PROCEDURE.
A candidate in an election may file a petition for an action under this chapter in any county where a defendant resided at the time of the election. If the election is for a statewide office, the candidate may also file the petition in a district court in Travis County.
Added by Acts 2021, 87th Leg., 2nd C.S., Ch. 1 (S.B. 1), Sec. 8.03, eff. December 2, 2021.
