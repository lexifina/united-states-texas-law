# Sec. 173.034. MANAGING PRIMARY FUND.
(a) The county chair shall manage the county primary fund.
(b) The state chair shall manage the state primary fund.
Acts 1985, 69th Leg., ch. 211, Sec. 1, eff. Jan. 1, 1986.
Amended by:
Acts 2017, 85th Leg., R.S., Ch. 828 (H.B. 1735), Sec. 53, eff. September 1, 2017.
