# Sec. 216.001. APPLICABILITY OF CHAPTER.
This chapter applies only to an election that results in a tie vote as provided by Sections 2.002(i), 2.023(b) and (c), and 2.028.
Added by Acts 2001, 77th Leg., ch. 851, Sec. 3, eff. Sept. 1, 2001. Amended by Acts 2003, 78th Leg., ch. 652, Sec. 4, eff. Sept. 1, 2003.
