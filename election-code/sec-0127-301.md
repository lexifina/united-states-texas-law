# Sec. 127.301. APPLICABILITY OF SUBCHAPTER.
This subchapter applies to an election:
(1) that occurs after August 31, 2026;
(2) that contains a race or measure that is voted on statewide; and
(3) in which an auditable voting system described by Section 129.003(a) is used.
Added by Acts 2021, 87th Leg., R.S., Ch. 573 (S.B. 598), Sec. 1, eff. September 1, 2021.
