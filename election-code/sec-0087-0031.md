# Sec. 87.0031. TRAINING.
The secretary of state shall provide a standardized training program and materials for members of an early voting ballot board in the same manner it provides such a program under Subchapter F, Chapter 32.
Added by Acts 2023, 88th Leg., R.S., Ch. 415 (H.B. 1632), Sec. 3, eff. September 1, 2023.
