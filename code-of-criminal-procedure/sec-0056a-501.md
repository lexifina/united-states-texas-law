# 56A.501
Art. 56A.501. DEFINITION. In this subchapter, "correctional facility" has the meaning assigned by Section 1.07, Penal Code.
Added by Acts 2019, 86th Leg., R.S., Ch. 469 (H.B. 4173), Sec. 1.05, eff. January 1, 2021.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 797 (S.B. 1120), Sec. 6, eff. September 1, 2025.
