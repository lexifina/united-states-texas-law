# Art. 24A.0015. DEFINITION.
In this chapter, "online service provider" means an Internet service provider, search engine, web hosting company, web browsing company, manufacturer of devices providing online application platforms, or company providing online social media platforms.
Added by Acts 2017, 85th Leg., R.S., Ch. 69 (S.B. 1203 ), Sec. 2, eff. September 1, 2017.
