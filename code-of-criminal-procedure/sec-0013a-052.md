# Art. 13A.052. OFFENSE COMMITTED OUTSIDE THIS STATE BY PERSON ACTING FOR STATE.
An offense committed outside this state by any officer acting under the authority of this state under circumstances that give this state jurisdiction to prosecute the defendant may be prosecuted in:
(1) the county in which the defendant resides; or
(2) if a nonresident of this state, Travis County.
Added by Acts 2023, 88th Leg., R.S., Ch. 765 (H.B. 4504 ), Sec. 1.001, eff. January 1, 2025.
