# 17.141
Art. 17.141. ELIGIBLE BAIL BOND SURETIES IN CERTAIN COUNTIES. In a county in which a county bail bond board regulated under Chapter 1704, Occupations Code, does not exist, the sheriff may post a list of eligible bail bond sureties whose security has been determined to be sufficient. Each surety listed under this article must file annually a sworn financial statement with the sheriff.
Added by Acts 2005, 79th Leg., Ch. 743 (H.B. 2767), Sec. 2, eff. September 1, 2005.
