# 18A.002
Art. 18A.002. NONAPPLICABILITY. This chapter does not apply to conduct described as an affirmative defense under Section 16.02(c), Penal Code, except as otherwise specifically provided by that section.
Added by Acts 2017, 85th Leg., R.S., Ch. 1058 (H.B. 2931), Sec. 1.01, eff. January 1, 2019.
