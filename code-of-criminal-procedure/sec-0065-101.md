# Art. 65.101. EXPIRATION OF DUTY TO REGISTER.
The duty to register for a person ends when a judge in a court of competent jurisdiction determines that the person no longer represents a threat to public safety.
Added by Acts 2023, 88th Leg., R.S., Ch. 935 (S.B. 1518 ), Sec. 1, eff. September 1, 2023.
