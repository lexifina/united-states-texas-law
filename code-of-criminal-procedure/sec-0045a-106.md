# Art. 45A.106. DEFENDANT PLACED IN JAIL.
If a peace officer is authorized by this title to retain a defendant in custody, the officer may place the defendant in jail in accordance with this code or other law.
Added by Acts 2023, 88th Leg., R.S., Ch. 765 (H.B. 4504 ), Sec. 1.001, eff. January 1, 2025.
