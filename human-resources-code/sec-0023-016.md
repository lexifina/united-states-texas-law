# Sec. 23.016. RULES, FORMS, AND PROCEDURES.
The executive commissioner by rule shall prescribe forms and procedures for the implementation of this chapter.
Added by Acts 1997, 75th Leg., ch. 1153, Sec. 5.01(a), eff. Sept. 1, 1997.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 1 (S.B. 219), Sec. 4.038, eff. April 2, 2015.
