# Sec. 40.0027. REFERENCES IN LAW MEANING COMMISSIONER OR DESIGNEE.
In this code or in any other law, a reference to the commissioner or the executive commissioner in relation to a function described by Section 40.0025(b) means the commissioner.
Added by Acts 2015, 84th Leg., R.S., Ch. 837 (S.B. 200), Sec. 1.19, eff. September 1, 2017.
Amended by:
Acts 2017, 85th Leg., R.S., Ch. 316 (H.B. 5), Sec. 28, eff. September 1, 2017.
