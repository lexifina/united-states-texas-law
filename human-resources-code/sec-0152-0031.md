# Sec. 152.0031. APPLICATION OF SUBCHAPTER.
Except as otherwise provided by this chapter, this subchapter does not apply to a county that is served by a juvenile board created under Subchapter C or D.
Added by Acts 1989, 71st Leg., ch. 352, Sec. 1, eff. Sept. 1, 1989.
Amended by:
Acts 2011, 82nd Leg., R.S., Ch. 198 (S.B. 1886), Sec. 1, eff. May 28, 2011.
