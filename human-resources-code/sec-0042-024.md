# Sec. 42.024. ADMINISTRATIVE PROCEDURE.
Chapter 2001, Government Code applies to all procedures under this chapter except where it is contrary to or inconsistent with the provisions of this chapter.
Acts 1979, 66th Leg., p. 2361, ch. 842, art. 1, Sec. 1, eff. Sept. 1, 1979. Amended by Acts 1995, 74th Leg., ch. 76, Sec. 5.95(49), eff. Sept. 1, 1995.
