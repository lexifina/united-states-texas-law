# Sec. 43.012. PENALTY.
A person who serves as a child-care or child-placing agency administrator without the license required by this chapter commits a Class C misdemeanor.
Acts 1979, 66th Leg., p. 2369, ch. 842, art. 1, Sec. 1, eff. Sept. 1, 1979. Amended by Acts 1997, 75th Leg., ch. 1063, Sec. 8, eff. Sept. 1, 1997.
