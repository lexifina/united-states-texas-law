# Sec. 112.023. SUNSET PROVISION.
The Texas Council for Developmental Disabilities is subject to Chapter 325, Government Code (Texas Sunset Act). Unless continued in existence as provided by that chapter, the council is abolished and this chapter expires September 1, 2027.
