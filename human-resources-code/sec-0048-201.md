# Sec. 48.201. APPLICATION OF SUBCHAPTER.
Except as otherwise provided, this subchapter does not apply to an investigation conducted under Subchapter F.
Added by Acts 1999, 76th Leg., ch. 907, Sec. 21, eff. Sept. 1, 1999.
