# Sec. 1.002. CONSTRUCTION OF CODE.
The Code Construction Act (Chapter 311, Government Code) applies to the construction of each provision of this code, except as otherwise expressly provided by this code.
Acts 1979, 66th Leg., p. 2335, ch. 842, art. 1, Sec. 1, eff. Sept. 1, 1979. Amended by Acts 1985, 69th Leg., ch. 479, Sec. 75, eff. Sept. 1, 1985.
