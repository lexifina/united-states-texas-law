# Sec. 33.012. CHEMICAL DEPENDENCY TREATMENT PROGRAM AS REPRESENTATIVE.
The commission shall provide an individual's supplemental nutrition assistance program allotment to the residential chemical dependency treatment program in which the person resides to the extent allowed under Section 8(f), Food Stamp Act of 1977 (7 U.S.C. Section 2017(e)), if the individual designates the program as the individual's authorized representative.
Added by Acts 1997, 75th Leg., ch. 663, Sec. 2, eff. Sept. 1, 1997.
Amended by:
Acts 2015, 84th Leg., R.S., Ch. 1 (S.B. 219), Sec. 4.163, eff. April 2, 2015.
