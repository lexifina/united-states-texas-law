# Sec. 38.05. OTHER CODE PROVISIONS INAPPLICABLE.
The provisions of this code do not apply to alcohol intended for industrial, medicinal, mechanical, or scientific purposes.
Acts 1977, 65th Leg., p. 449, ch. 194, Sec. 1, eff. Sept. 1, 1977.
Amended by:
