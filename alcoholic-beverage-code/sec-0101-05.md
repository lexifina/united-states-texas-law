# Sec. 101.05. NEGATION OF EXCEPTION: INFORMATION, COMPLAINT, OR INDICTMENT.
An information, complaint, or indictment charging a violation of this code need not negate an exception to an act prohibited by this code, but the exception may be urged by the defendant as a defense to the offense charged.
Acts 1977, 65th Leg., p. 492, ch. 194, Sec. 1, eff. Sept. 1, 1977.
