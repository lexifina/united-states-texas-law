# Sec. 6.05. CORPORATE LIABILITY.
A corporation with an ownership interest in a corporation holding a permit under Section 6.03(k) of this code and which shares space, employees, business facilities, or services is subject to liability under Chapter 2 of this code.
Added by Acts 1993, 73rd Leg., ch. 934, Sec. 17, eff. Sept. 1, 1993.
