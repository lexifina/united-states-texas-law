# Sec. 58.003. AUTHORIZATION BY NONRESIDENT BREWER REQUIRED.
A nonresident brewer's agent must be authorized to act as the agent of a nonresident brewer the person proposes to represent.
Added by Acts 2019, 86th Leg., R.S., Ch. 1161 (H.B. 3222), Sec. 2(b), eff. September 1, 2021.
Redesignated by Acts 2021, 87th Leg., R.S., Ch. 915 (H.B. 3607), Sec. 21.001(3), eff. September 1, 2021.
