# Sec. 30.02. AUTHORIZED ACTIVITIES.
The holder of a nonprofit entity temporary event permit may sell for consumption on the premises for which the permit is issued any alcoholic beverage that is authorized to be sold where the event is held.
Acts 1977, 65th Leg., p. 433, ch. 194, Sec. 1, eff. Sept. 1, 1977. Amended by Acts 1983, 68th Leg., p. 1346, ch. 278, Sec. 20, eff. Sept. 1, 1983.
