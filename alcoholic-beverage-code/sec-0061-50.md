# Sec. 61.50. RENEWAL OF RETAIL DEALER'S LICENSE: GROUNDS FOR DENIAL.
The commission may deny an application for a renewal of a retail dealer's license and require the applicant to make an original application if it is found that circumstances exist which would warrant the denial of an original application under any pertinent provision of this code.
Acts 1977, 65th Leg., p. 468, ch. 194, Sec. 1, eff. Sept. 1, 1977.
Amended by:
Acts 2019, 86th Leg., R.S., Ch. 1359 (H.B. 1545), Sec. 194, eff. December 31, 2020.
