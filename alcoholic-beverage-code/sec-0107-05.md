# Sec. 107.05. IMPORTATION OF LIQUOR.
(a) No person may import liquor into the state and deliver it to a person not authorized to import it.
(b) This section does not apply to the transportation of liquor into the state as authorized by Section 107.07 of this code.
Acts 1977, 65th Leg., p. 517, ch. 194, Sec. 1, eff. Sept. 1, 1977.
