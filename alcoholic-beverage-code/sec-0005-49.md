# Sec. 5.49. PRINTED COPIES OF CODE AND RULES.
The commission from time to time may have as many copies of this code and any commission rule governing the collection or refund of the gross receipts tax printed in pamphlet form for distribution as it finds necessary.
Acts 1977, 65th Leg., p. 402, ch. 194, Sec. 1, eff. Sept. 1, 1977. Amended by Acts 1983, 68th Leg., p. 5225, ch. 956, Sec. 3, eff. Aug. 29, 1983.
