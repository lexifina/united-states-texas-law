# Sec. 102.06. RELATIONSHIP BETWEEN AGENT AND PACKAGE STORE.
An agent acting under Chapter 35 or 36 may not directly or indirectly have an interest in a package store permit or wine only package store permit or be residentially domiciled with a person who has a financial interest in a package store permit or wine only package store permit.
Acts 1977, 65th Leg., p. 499, ch. 194, Sec. 1, eff. Sept. 1, 1977.
Amended by:
Acts 2019, 86th Leg., R.S., Ch. 1359 (H.B. 1545), Sec. 284, eff. September 1, 2019.
