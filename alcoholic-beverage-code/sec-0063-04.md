# Sec. 63.04. APPLICATION OF CODE PROVISIONS AND RULES.
A holder of a nonresident brewer's license is subject to all applicable provisions of this code and all applicable rules of the commission which apply to holders of brewer's licenses, including rules relating to the quality, purity, and identity of malt beverages and to protecting the public health. The commission may suspend or cancel a nonresident brewer's license and apply penalties in the same manner as it does with respect to a brewer's license.
Acts 1977, 65th Leg., p. 477, ch. 194, Sec. 1, eff. Sept. 1, 1977.
