# Sec. 828.051. EXCEPTION TO LIMITATION ON PURCHASING SHARES OF OTHER COMPANY.
Subchapters C and D, Chapter 425, do not apply to a purchase or contract described by Section 828.001 if all requirements of this subchapter are met.
Added by Acts 2001, 77th Leg., ch. 1419, Sec. 1, eff. June 1, 2003.
Amended by:
Acts 2007, 80th Leg., R.S., Ch. 730 (H.B. 2636), Sec. 2E.015, eff. April 1, 2009.
