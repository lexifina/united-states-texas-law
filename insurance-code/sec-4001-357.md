# Sec. 4001.357. DENIAL OR REVOCATION OF LICENSE.
If the applicant's license application is denied or the applicant's license is revoked, an applicant is subject to Section 4005.105 with respect to an application for a provisional permit under this subchapter.
Added by Acts 2015, 84th Leg., R.S., Ch. 404 (H.B. 2145), Sec. 1, eff. September 1, 2015.
