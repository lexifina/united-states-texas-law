# Sec. 1105.057. REFILING OF POLICY PROVISIONS NOT REQUIRED.
Notwithstanding any provision of this code to the contrary, as to a policy to which this subchapter applies, a refiling of nonforfeiture values or of the method of computing nonforfeiture values for a previously approved policy form that involves only a change in the interest rate or mortality table used to compute nonforfeiture values does not require refiling of any provision of the policy form.
Added by Acts 2001, 77th Leg., ch. 1419, Sec. 2, eff. June 1, 2003.
