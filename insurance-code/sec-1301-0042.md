# Sec. 1301.0042. APPLICABILITY OF INSURANCE LAW.
(a) Except as provided by Subsection (b), a provision of this code or another insurance law of this state that applies to a preferred provider benefit plan applies to an exclusive provider benefit plan except to the extent that the commissioner determines the provision to be inconsistent with the function and purpose of an exclusive provider benefit plan.
(b) An exclusive provider benefit plan may not provide dental care benefits.
Added by Acts 2011, 82nd Leg., R.S., Ch. 288 (H.B. 1772), Sec. 5, eff. September 1, 2011.
