# Sec. 31.045. CAREER LADDER PROGRAM; PERFORMANCE EVALUATIONS.
(a) The commissioner or the commissioner's designee shall develop an intra-agency career ladder program. The program must require intra-agency posting of all nonentry level positions concurrently with any public posting.
(b) The commissioner or the commissioner's designee shall develop a system of annual performance evaluations. All merit pay for department employees must be based on the system established under this subsection.
Added by Acts 1999, 76th Leg., ch. 101, Sec. 1, eff. Sept. 1, 1999.
