# Sec. 541.085. ADVERTISEMENTS RELATING TO PREFERRED PROVIDER BENEFIT PLANS.
It is sufficient for an insurer to use the term "PPO plan" in advertisements when referring to a preferred provider benefit plan offered under Chapter 1301.
Added by Acts 2007, 80th Leg., R.S., Ch. 475 (H.B. 2251), Sec. 1, eff. September 1, 2007.
