# Sec. 1301.0057. ACCESS TO OUT-OF-NETWORK PROVIDERS.
An insurer may not terminate, or threaten to terminate, an insured's participation in a preferred provider benefit plan solely because the insured uses an out-of-network provider.
Added by Acts 2015, 84th Leg., R.S., Ch. 275 (H.B. 574), Sec. 5, eff. September 1, 2015.
