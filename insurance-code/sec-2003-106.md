# Sec. 2003.106. ENFORCEMENT.
The commissioner by rule may provide for the use of any disciplinary procedure authorized by this code to:
(1) maintain the integrity of the voluntary inspection program; or
(2) ensure compliance with this subchapter.
Added by Acts 2005, 79th Leg., Ch. 727 (H.B. 2017), Sec. 2, eff. April 1, 2007.
