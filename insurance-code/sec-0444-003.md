# Sec. 444.003. EFFECT OF CHAPTER ON ACTION BY RECEIVER AGAINST AGENT.
This chapter does not prejudice a cause of action by the receiver against an agent to recover:
(1) unearned premiums that were not returned to policyholders; or
(2) earned premiums that were not promptly remitted to the receiver.
