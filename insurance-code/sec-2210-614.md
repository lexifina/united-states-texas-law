Sec. 2210.614. REFINANCING PUBLIC SECURITIES. The association may request the board to refinance any public securities issued in accordance with Subchapter B-1, whether Class 1, Class 2, or Class 3 public securities, with public securities payable from the same sources as the original public securities.
Added by Acts 2009, 81st Leg., R.S., Ch. 1408 (H.B. 4409 ), Sec. 41, eff. June 19, 2009.
Repealed by Acts 2025, 89th Leg., R.S., Ch. 895 (H.B. 3689 ), Sec. 1.17(2), eff. September 1, 2027.
