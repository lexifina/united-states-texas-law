# Sec. 1305.201. NETWORK FINANCIAL REQUIREMENTS.
(a) Each network shall prepare financial statements in accordance with generally accepted accounting standards, which must include adequate provisions for liabilities, including incurred but not reported obligations relating to providing benefits or services.
(b) Each network shall file the financial statement under Subsection (a) with the department in the manner prescribed by commissioner rule.
Added by Acts 2005, 79th Leg., Ch. 265 (H.B. 7), Sec. 4.02, eff. September 1, 2005.
