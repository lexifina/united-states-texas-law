# Sec. 1105.0015. DEFINITION.
In this chapter, "operative date of the valuation manual" means the date, if any, on which the valuation manual described by Subchapter B, Chapter 425 (Standard Valuation Law), becomes operative as provided by that subchapter.
Added by Acts 2015, 84th Leg., R.S., Ch. 313 (S.B. 1654), Sec. 16, eff. September 1, 2015.
