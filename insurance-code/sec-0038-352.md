# Sec. 38.352. DEFINITION.
In this subchapter, "group health benefit plan" means a preferred provider benefit plan as defined by Section 1301.001 or an evidence of coverage for a health care plan that provides basic health care services as defined by Section 843.002.
Added by Acts 2007, 80th Leg., R.S., Ch. 997 (S.B. 1731), Sec. 8, eff. September 1, 2007.
