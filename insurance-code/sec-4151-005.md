# Sec. 4151.005. ADMINISTRATOR NOT INSURANCE AGENT.
(a) An administrator licensed in any state who accepts an agent's commission for coverage for a risk located in this state and disburses that commission to an agent in this state is not considered an agent for purposes of this state's laws relating to the licensing of agents.
(b) The exemption provided by this section does not authorize an administrator to perform any other act for which a license as an agent is required by law.
Added by Acts 2003, 78th Leg., ch. 1274, Sec. 7, eff. April 1, 2005.
