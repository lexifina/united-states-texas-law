# Sec. 1455.005. RULES.
Subject to Section 111.004, Occupations Code, the commissioner may adopt rules necessary to implement this chapter.
Added by Acts 2003, 78th Leg., ch. 1274, Sec. 3, eff. April 1, 2005.
Amended by:
Acts 2005, 79th Leg., Ch. 728 (H.B. 2018), Sec. 23.002(10), eff. September 1, 2005.
