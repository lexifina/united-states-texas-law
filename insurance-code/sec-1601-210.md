# Sec. 1601.210. PROVISION OF NECESSARY INFORMATION.
The Teacher Retirement System of Texas, Optional Retirement Program carriers, and Employees Retirement System of Texas shall provide to each system information the system considers necessary to provide retired employees with the coverages and system contributions provided under this chapter.
Added by Acts 2001, 77th Leg., ch. 1419, Sec. 3, eff. June 1, 2003.
