# Sec. 602.105. EXCLUSION FROM STATE PROGRAMS.
If there is evidence that a covered entity has engaged in a pattern or practice of violating this chapter, in addition to the other penalties prescribed by this subchapter, the covered entity shall be excluded from participating in any state-funded health care program.
Added by Acts 2003, 78th Leg., ch. 1274, Sec. 2, eff. April 1, 2005.
