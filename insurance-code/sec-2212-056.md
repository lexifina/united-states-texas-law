# Sec. 2212.056. ADMINISTRATIVE SANCTIONS.
If a trust is found to have violated this code or a rule adopted by the commissioner that is declared applicable to the trust, the commissioner may order sanctions under Chapter 82 for the violation.
Added by Acts 2005, 79th Leg., Ch. 727 (H.B. 2017), Sec. 2, eff. April 1, 2007.
