# Sec. 2602.451. APPLICABILITY.
This subchapter applies, at the commissioner's discretion and regardless of whether there are covered claims against an agent, to any agent that is designated by the commissioner as an impaired agent.
Added by Acts 2009, 81st Leg., R.S., Ch. 1025 (H.B. 4338), Sec. 10, eff. September 1, 2009.
