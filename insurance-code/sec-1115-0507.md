# Sec. 1115.0507. INSURER OBLIGATIONS.
(a) Notwithstanding Section 1115.0506, an insurer's issuance of an annuity must be reasonable under the circumstances known to the insurer at the time the annuity is issued.
(b) If there is no agent involved in an annuity transaction, the obligations described in this subchapter apply to the insurer that recommends or sells the annuity in the same way those obligations would apply to an agent.
Added by Acts 2021, 87th Leg., R.S., Ch. 262 (H.B. 1777), Sec. 6, eff. September 1, 2021.
