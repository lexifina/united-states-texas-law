# Sec. 1369.356. ACCESS TO MAXIMUM ALLOWABLE COST LISTS.
A health benefit plan issuer or pharmacy benefit manager must provide to each pharmacist or pharmacy under contract with the health benefit plan issuer or pharmacy benefit manager a process to readily access the maximum allowable cost list that applies to the pharmacist or pharmacy.
Added by Acts 2015, 84th Leg., R.S., Ch. 596 (S.B. 332), Sec. 1, eff. January 1, 2016.
