# Sec. 964.102. STATUS OF CAPTIVE EXCHANGES.
A captive exchange is formed as an exchange as provided by this subchapter and, except as provided by this subchapter, shall operate as a captive insurance company as provided by this chapter.
Added by Acts 2017, 85th Leg., R.S., Ch. 1050 (H.B. 1944), Sec. 2.01, eff. June 15, 2017.
