# Sec. 2171.004. RATE FILINGS.
An insurer shall file with the commissioner in accordance with Chapter 2251 the following information for commercial group property insurance written under this chapter in this state:
(1) rates;
(2) supplementary rating information; and
(3) pertinent supporting information.
Added by Acts 2005, 79th Leg., Ch. 727 (H.B. 2017), Sec. 2, eff. April 1, 2007.
