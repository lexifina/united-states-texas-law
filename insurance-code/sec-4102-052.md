# Sec. 4102.052. APPLICATION.
(a) An application for a license under this chapter must be on a form prescribed by the commissioner.
(b) The completed application must be notarized and be accompanied by a nonrefundable license application fee, as provided by Section 4102.066, for each application submitted.
Added by Acts 2005, 79th Leg., Ch. 728 (H.B. 2018), Sec. 11.082(a), eff. September 1, 2005.
