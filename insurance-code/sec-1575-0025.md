# Sec. 1575.0025. REFERENCES TO BASIC PLAN.
A reference in this code to a "basic plan" under this chapter means a health benefit plan provided under this chapter other than a Medicare Advantage plan or a Medicare prescription drug plan.
Added by Acts 2017, 85th Leg., R.S., Ch. 712 (H.B. 3976), Sec. 2, eff. September 1, 2017.
