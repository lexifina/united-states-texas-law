# Sec. 3504.0007. RULEMAKING.
(a) The commissioner may adopt rules necessary to implement this chapter. Section 2001.0045, Government Code, does not apply to rules adopted under this section.
(b) The comptroller, in consultation with the commissioner, may adopt rules to implement this chapter.
Added by Acts 2019, 86th Leg., R.S., Ch. 1000 (H.B. 2587), Sec. 1, eff. September 1, 2019.
