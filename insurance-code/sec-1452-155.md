# Sec. 1452.155. DIRECTORY ENTRIES.
Pending the approval of an application submitted under Section 1452.154, the managed care plan may exclude the applicant podiatrist from the managed care plan's directory of participating podiatrists, the managed care plan's website listing of participating podiatrists, or any other listing of participating podiatrists.
Added by Acts 2013, 83rd Leg., R.S., Ch. 79 (S.B. 365), Sec. 1, eff. September 1, 2013.
