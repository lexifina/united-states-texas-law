# Sec. 38.358. PENALTIES.
A health benefit plan issuer that fails to submit data as required in accordance with this subchapter is subject to an administrative penalty under Chapter 84. For purposes of penalty assessment, each day the health benefit plan issuer fails to submit the data as required is a separate violation.
Added by Acts 2007, 80th Leg., R.S., Ch. 997 (S.B. 1731), Sec. 8, eff. September 1, 2007.
