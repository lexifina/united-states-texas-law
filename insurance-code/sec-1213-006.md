# Sec. 1213.006. RULES.
The commissioner may adopt rules as necessary to implement this chapter. The commissioner may not require any data element for electronically filed claims that is not required to comply with federal law.
Added by Acts 2005, 79th Leg., Ch. 728 (H.B. 2018), Sec. 11.029(a), eff. September 1, 2005.
