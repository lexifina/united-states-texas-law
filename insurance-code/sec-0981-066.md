# Sec. 981.066. UNIFORM STANDARDS.
To issue surplus lines insurance in this state, an insurer must comply with all applicable nationwide uniform standards adopted by this state in accordance with 15 U.S.C. Section 8204.
Added by Acts 2013, 83rd Leg., R.S., Ch. 595 (S.B. 951), Sec. 8, eff. June 14, 2013.
