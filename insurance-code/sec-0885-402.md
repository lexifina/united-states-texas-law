# Sec. 885.402. REPORTS OF CERTAIN GRAND LODGES.
The officers of the supreme state governing body of a grand lodge considered to be a single state organization under Section 885.006 shall make each report required by this chapter. The report must include the transactions, liabilities, and assets of the state organization.
Added by Acts 2001, 77th Leg., ch. 1419, Sec. 1, eff. June 1, 2003.
