# Sec. 562.004. APPLICABILITY.
Except as otherwise provided by this chapter, a program operator, including the operator of a freestanding discount health care program or a discount health care program marketed by an insurer or a health maintenance organization, shall comply with this chapter.
Added by Acts 2009, 81st Leg., R.S., Ch. 1331 (H.B. 4341), Sec. 1, eff. September 1, 2009.
