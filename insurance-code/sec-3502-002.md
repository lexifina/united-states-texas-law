# Sec. 3502.002. APPLICABILITY OF OTHER LAW.
(a) This code and other state laws apply to the business of mortgage guaranty insurance.
(b) This chapter controls to the extent of any conflict with another provision of this code or other state law.
Added by Acts 2005, 79th Leg., Ch. 727 (H.B. 2017), Sec. 3, eff. April 1, 2007.
