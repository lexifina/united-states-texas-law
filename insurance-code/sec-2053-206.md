# Sec. 2053.206. VIOLATION OF SUBCHAPTER.
(a) A person commits an administrative violation under Subtitle A, Title 5, Labor Code, if the person engages in conduct that violates this subchapter.
(b) Liability for damages for a violation of this subchapter is determined exclusively under Subtitle A, Title 5, Labor Code.
Added by Acts 2005, 79th Leg., Ch. 727 (H.B. 2017), Sec. 2, eff. April 1, 2007.
Amended by:
Acts 2011, 82nd Leg., R.S., Ch. 1162 (H.B. 2605), Sec. 5, eff. September 1, 2011.
