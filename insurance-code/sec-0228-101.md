# Sec. 228.101. APPLICATION FOR CERTIFICATION.
(a) An applicant for certification must file the application in the form prescribed by the comptroller. The application must be accompanied by a nonrefundable application fee of $7,500.
(b) The application must include an audited balance sheet of the applicant, with an unqualified opinion from an independent certified public accountant, as of a date not more than 35 days before the date of the application.
Added by Acts 2007, 80th Leg., R.S., Ch. 730 (H.B. 2636), Sec. 1B.001, eff. April 1, 2009.
