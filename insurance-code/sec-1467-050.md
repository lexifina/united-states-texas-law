# Sec. 1467.050. APPLICABILITY OF SUBCHAPTER.
(a) This subchapter applies only with respect to a health benefit claim submitted by an out-of-network provider that is a facility.
(b) This subchapter does not apply to a health benefit claim for the professional or technical component of a physician service.
Added by Acts 2019, 86th Leg., R.S., Ch. 1342 (S.B. 1264), Sec. 2.05, eff. September 1, 2019.
