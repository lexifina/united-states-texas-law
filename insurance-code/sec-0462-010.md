# Sec. 462.010. CONFLICT WITH OTHER LAWS.
(a) Except as provided by Subsection (b), if this chapter conflicts with another statute relating to the association, this chapter controls.
(b) This section does not apply to a conflict between this chapter and:
(1) Subtitle A, Title 5, Labor Code, except as described by Subsection (c); or
(2) Subtitle E, Title 10.
(c) This chapter controls with respect to subrogation rights of an insurance carrier under Chapter 417, Labor Code, against an impaired insurer's insured or the association.
Added by Acts 2005, 79th Leg., Ch. 727 (H.B. 2017), Sec. 1, eff. April 1, 2007.
