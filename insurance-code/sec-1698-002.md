# Sec. 1698.002. APPLICABILITY OF OTHER LAWS GOVERNING RATES.
The requirements of this chapter are in addition to any other provision of this code governing health benefit plan rates. Except as otherwise provided by this chapter, in the case of a conflict between this chapter and another provision of this code, this chapter controls.
Added by Acts 2021, 87th Leg., R.S., Ch. 877 (S.B. 1296), Sec. 1, eff. September 1, 2021.
