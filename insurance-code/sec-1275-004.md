# Sec. 1275.004. OUT-OF-NETWORK CLAIM DISPUTE RESOLUTION.
Chapter 1467 applies to a health benefit plan to which this chapter applies, and the administrator of a health benefit plan to which this chapter applies is an administrator for purposes of that chapter.
Added by Acts 2021, 87th Leg., R.S., Ch. 1034 (H.B. 3924), Sec. 1, eff. September 1, 2021.
