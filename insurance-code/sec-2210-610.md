# Sec. 2210.610. PUBLIC SECURITY PAYMENTS.
(a) Revenues received from the premium surcharges under Sections 2210.612, 2210.613, and 2210.6131 may be applied only as provided by this subchapter.
(b) The association may pay public security obligations with other legally available funds.
(c) Public security obligations are payable only from sources provided for payment in this subchapter.
Added by Acts 2009, 81st Leg., R.S., Ch. 1408 (H.B. 4409), Sec. 41, eff. June 19, 2009.
