# Sec. 1952.353. NAMED DRIVER POLICIES PROHIBITED; CERTAIN NAMED DRIVER EXCLUSIONS AUTHORIZED.
(a) An insurer may not deliver, issue for delivery, or renew a named driver policy unless the named driver policy is an operator's policy.
(b) An insurer may use a named driver exclusion only if the exclusion specifically names each excluded driver and does not exclude a class of drivers and the named insured accepts the exclusion in writing.
Added by Acts 2019, 86th Leg., R.S., Ch. 455 (H.B. 259), Sec. 1, eff. September 1, 2019.
