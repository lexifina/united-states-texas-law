# Sec. 443.259. CLAIMS OF CODEBTORS.
If a creditor does not timely file a proof of the creditor's claim, an entity that is liable to the creditor together with the insurer, or that has secured the creditor, may file a proof of the claim.
Added by Acts 2005, 79th Leg., Ch. 995 (H.B. 2157), Sec. 1, eff. September 1, 2005.
