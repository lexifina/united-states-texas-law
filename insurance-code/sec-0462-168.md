# Sec. 462.168. EXEMPTION FOR IMPAIRED INSURER.
An impaired insurer is exempt from assessment from the date the insurer is designated an impaired insurer until the date the commissioner determines that the insurer is no longer an impaired insurer.
Added by Acts 2005, 79th Leg., Ch. 727 (H.B. 2017), Sec. 1, eff. April 1, 2007.
