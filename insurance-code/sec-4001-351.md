# Sec. 4001.351. APPLICABILITY.
This subchapter applies only to an applicant for a license as an agent under:
(1) Subchapters B and E, Chapter 4051; and
(2) Subchapters B, D, E, and G, Chapter 4054.
Added by Acts 2015, 84th Leg., R.S., Ch. 404 (H.B. 2145), Sec. 1, eff. September 1, 2015.
Amended by:
Acts 2017, 85th Leg., R.S., Ch. 128 (H.B. 1073), Sec. 1, eff. September 1, 2017.
