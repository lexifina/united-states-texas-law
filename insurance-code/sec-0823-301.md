# Sec. 823.301. SCOPE OF SUBCHAPTER.
(a) This subchapter applies only to the determination of the valuation for a financial statement of an investment by an insurer in an affiliate that is not an insurer.
(b) This subchapter does not apply for determining the amount invested under Section 823.253.
Added by Acts 2001, 77th Leg., ch. 1419, Sec. 1, eff. June 1, 2003.
