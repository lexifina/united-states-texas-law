# Sec. 2054.604. RULES.
Except with respect to alternative health benefit coverage as described by Section 2054.601 or a subsidiary of the company offering alternative health benefit coverage, the commissioner may adopt rules as necessary to implement this subchapter.
Added by Acts 2021, 87th Leg., R.S., Ch. 1019 (H.B. 3752), Sec. 2, eff. September 1, 2021.
