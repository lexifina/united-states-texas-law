# Sec. 1552.003. ADMINISTERING FIRM.
The board of trustees may select an administering firm to administer the long-term care insurance program under contract with the board.
Added by Acts 2001, 77th Leg., ch. 1419, Sec. 3, eff. June 1, 2003.
Amended by:
Acts 2019, 86th Leg., R.S., Ch. 158 (H.B. 392), Sec. 3, eff. September 1, 2019.
