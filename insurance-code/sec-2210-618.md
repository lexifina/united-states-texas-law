# Sec. 2210.618. EXEMPTION FROM TAXATION.
A public security issued under this subchapter, any transaction relating to the public security, and profits made from the sale of the public security are exempt from taxation by this state or by a municipality or other political subdivision of this state.
Added by Acts 2009, 81st Leg., R.S., Ch. 1408 (H.B. 4409), Sec. 41, eff. June 19, 2009.
Repealed by Acts 2025, 89th Leg., R.S., Ch. 895 (H.B. 3689), Sec. 1.17(2), eff. September 1, 2027.
