# Sec. 4001.102. LICENSE APPLICATION.
(a) To become an agent for an insurer or health maintenance organization, a person must submit to the department a completed license application in the form required by the department.
(b) The commissioner by rule shall prescribe the requirements for a properly completed application.
Added by Acts 2003, 78th Leg., ch. 1274, Sec. 7, eff. April 1, 2005.
