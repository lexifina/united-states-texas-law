# Sec. 1601.055. IDENTIFICATION OF ADMINISTRATIVE COSTS IN BIDS.
A system shall include in its respective bid documents for the various coverages a provision calling for each bidder to identify the system's administrative costs as a distinguishable figure and to enumerate the services the bidder will render in exchange for the administrative costs.
Added by Acts 2001, 77th Leg., ch. 1419, Sec. 3, eff. June 1, 2003.
