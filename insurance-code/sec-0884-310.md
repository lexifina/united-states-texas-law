# Sec. 884.310. AGENT.
Each agent of a stipulated premium company must be licensed under Title 13.
Added by Acts 2001, 77th Leg., ch. 1419, Sec. 1, eff. June 1, 2003. Amended by Acts 2003, 78th Leg., ch. 1276, Sec. 10A.221(a), eff. Sept. 1, 2003.
Amended by:
Acts 2007, 80th Leg., R.S., Ch. 730 (H.B. 2636), Sec. 2E.083, eff. April 1, 2009.
