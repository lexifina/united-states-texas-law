# Sec. 1601.006. APPLICABILITY OF DEFINITIONS.
The definition of a term defined by this subchapter and the use of the terms "employee" and "retired employee" as described by Sections 1601.101 and 1601.102 apply to this chapter unless a different meaning is plainly required by the context in which the term appears.
Added by Acts 2001, 77th Leg., ch. 1419, Sec. 3, eff. June 1, 2003.
