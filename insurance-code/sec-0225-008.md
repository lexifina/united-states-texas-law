# Sec. 225.008. TAX PAYMENT, REPORT, AND DUE DATE.
(a) The tax imposed by this chapter is due and payable on or before March 1. A surplus lines agent shall file a tax report with the tax payment.
(b) A surplus lines agent shall pay the tax imposed by this chapter and file the report using forms prescribed by the comptroller.
Added by Acts 2003, 78th Leg., ch. 1274, Sec. 1, eff. April 1, 2005.
