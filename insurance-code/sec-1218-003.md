# Sec. 1218.003. CERTAIN COVERAGE NOT AFFECTED.
This chapter does not apply to health benefit plan coverage provided to an enrollee for any abortion other than an elective abortion as defined by Section 1218.001.
Added by Acts 2017, 85th Leg., 1st C.S., Ch. 5 (H.B. 214), Sec. 2, eff. December 1, 2017.
