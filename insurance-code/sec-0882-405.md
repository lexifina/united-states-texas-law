# Sec. 882.405. DESIGNATION OF CONTINGENCY RESERVE AS UNASSIGNED SURPLUS.
The contingency reserve described by this subchapter is and may be treated as unassigned surplus, including designating the contingency reserve as unassigned surplus in financial statements.
Added by Acts 2001, 77th Leg., ch. 1419, Sec. 1, eff. June 1, 2003.
