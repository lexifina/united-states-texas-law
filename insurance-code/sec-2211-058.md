# Sec. 2211.058. ANNUAL OPERATING REPORT.
(a) Not later than March 31 of each year, the association shall compile and submit to the commissioner an operating report covering the preceding calendar year.
(b) The report is a public record.
Added by Acts 2005, 79th Leg., Ch. 727 (H.B. 2017), Sec. 2, eff. April 1, 2007.
