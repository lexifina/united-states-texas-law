# Sec. 1452.205. DIRECTORY ENTRIES.
Pending the approval of an application submitted under Section 1452.204, the managed care plan may exclude the applicant therapeutic optometrist from the managed care plan's directory of participating therapeutic optometrists, the managed care plan's website listing of participating therapeutic optometrists, or any other listing of participating therapeutic optometrists.
Added by Acts 2013, 83rd Leg., R.S., Ch. 79 (S.B. 365), Sec. 1, eff. September 1, 2013.
