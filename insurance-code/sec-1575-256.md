# Sec. 1575.256. CRIMINAL OFFENSE: FAILURE OF ADMINISTRATOR TO COMPLY.
(a) An administrator of an employer commits an offense if the administrator knowingly fails to comply with this subchapter.
(b) An offense under this section is a Class C misdemeanor.
Added by Acts 2001, 77th Leg., ch. 1419, Sec. 3, eff. June 1, 2003.
