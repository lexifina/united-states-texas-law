# Sec. 151.103. TIMBER PURCHASER AS TRUSTEE.
A timber purchaser and each officer, director, partner, or agent of a timber purchaser are trustees of trust money.
Added by Acts 1997, 75th Leg., ch. 562, Sec. 1, eff. Sept. 1, 1997. Renumbered from Sec. 151.153 by Acts 2001, 77th Leg., ch. 532, Sec. 1, eff. Sept. 1, 2001.
