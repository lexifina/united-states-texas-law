# Sec. 131.148. EXTENSION OF PERMIT COVERAGE.
If an application for renewal of a valid permit includes a proposal to extend the mining operation beyond the boundaries authorized in the existing permit, the portion of the application for renewal of a valid permit that addresses any new land areas shall be subject to the full standards, including application fees, applicable to new applications under this chapter.
Acts 1977, 65th Leg., p. 2623, ch. 871, art. I, Sec. 1, eff. Sept. 1, 1977.
