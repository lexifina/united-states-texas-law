# Sec. 131.138. FILING APPLICATION WITH COUNTY CLERK.
After deleting confidential information as provided in Section 131.048 of this code, the commission shall file for public inspection with the county clerk at the county courthouse of the county in which any portion of the mining is proposed to occur a copy of each application.
Acts 1977, 65th Leg., p. 2621, ch. 871, art. I, Sec. 1, eff. Sept. 1, 1977.
