# Sec. 111.085. APPLICABILITY OF RATE PROVISIONS TO CERTAIN COMMON PURCHASERS.
Common purchasers as defined in Subdivision (3), Subsection (a), Section 111.081 of this code are subject to the same regulation concerning rates and charges for gathering, transporting, loading, and delivering crude petroleum as set out in Subchapter F of this chapter.
Acts 1977, 65th Leg., p. 2583, ch. 871, art. I, Sec. 1, eff. Sept. 1, 1977.
