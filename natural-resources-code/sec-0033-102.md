# Sec. 33.102. CONTENTS OF APPLICATION.
The application to acquire rights in coastal public land shall include any information the board considers necessary to process the application, including information necessary to evaluate the purpose for which the land is to be used.
Acts 1977, 65th Leg., p. 2387, ch. 871, art. I, Sec. 1, eff. Sept. 1, 1977.
Amended by:
