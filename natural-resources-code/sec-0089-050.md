# Sec. 89.050. OPERATOR REPORT.
For each inactive well for which 15 years have elapsed from the date on which the relevant well completion report was filed with the commission, an operator must submit an annual report to the commission with information regarding the results of a successful fluid level test or hydraulic pressure test of the well conducted in accordance with commission rules. The report must include appropriate documentation of the results of the test.
Added by Acts 2025, 89th Leg., R.S., Ch. 1001 (S.B. 1150), Sec. 2, eff. September 1, 2025.
