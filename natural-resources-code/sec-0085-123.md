# Sec. 85.123. CURTAILMENT OF MARGINAL WELL PRODUCTION AS WASTE.
To artificially curtail the production of a marginal well below the marginal limit as set out in Sections 85.121 through 85.122 of this code before the marginal well's ultimate plugging and abandonment is declared to be waste.
Acts 1977, 65th Leg., p. 2521, ch. 871, art. I, Sec. 1, eff. Sept. 1, 1977.
