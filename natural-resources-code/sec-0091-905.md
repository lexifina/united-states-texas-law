# Sec. 91.905. APPLICATION OF OTHER LAW.
Section 212.153(e), Local Government Code, and Sections 203.092 and 224.008, Transportation Code, apply to saltwater pipeline operators and saltwater pipeline facilities in the same manner as they apply to utilities and utility facilities.
Added by Acts 2013, 83rd Leg., R.S., Ch. 1408 (S.B. 514), Sec. 1, eff. June 14, 2013.
Amended by:
Acts 2017, 85th Leg., R.S., Ch. 968 (S.B. 2075), Sec. 1, eff. September 1, 2017.
