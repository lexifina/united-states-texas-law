# Sec. 61.068. APPLICATION REQUIREMENT.
A city or county that seeks state funds under this subchapter to clean the public beaches must submit an application to the land office.
Acts 1977, 65th Leg., p. 2481, ch. 871, art. I, Sec. 1, eff. Sept. 1, 1977. Amended by Acts 1991, 72nd Leg., ch. 114, Sec. 3, eff. Sept. 1, 1991.
