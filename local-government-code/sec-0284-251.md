# Sec. 284.251. DEFINITIONS.
In this subchapter:
(1) "Cable service" and "video service" have the meanings assigned by Section 66.002, Utilities Code.
(2) "Electric cooperative" has the meaning assigned by Section 11.003, Utilities Code.
(3) "Electric utility" has the meaning assigned by Section 31.002, Utilities Code.
(4) "Telecommunications provider" has the meaning assigned by Section 51.002, Utilities Code.
(5) "Telephone cooperative" has the meaning assigned by Section 162.003, Utilities Code.
Added by Acts 2017, 85th Leg., R.S., Ch. 591 (S.B. 1004), Sec. 1, eff. September 1, 2017.
