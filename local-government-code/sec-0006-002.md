# Sec. 6.002. INCORPORATION PROCEDURE.
The procedure for incorporating as a Type A general-law municipality is the same as that prescribed for incorporating as a Type B general-law municipality.
Acts 1987, 70th Leg., ch. 149, Sec. 1, eff. Sept. 1, 1987. Amended by Acts 1999, 76th Leg., ch. 62, Sec. 13.01, eff. Sept. 1, 1999.
