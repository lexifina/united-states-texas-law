# Sec. 380.003. APPLICATION FOR MATCHING FUNDS FROM FEDERAL GOVERNMENT.
A municipality may, as an agency of the state, provide matching funds for a federal program that requires local matching funds from a state agency to the extent state agencies that are eligible decline to participate or do not fully participate in the program.
Added by Acts 1995, 74th Leg., ch. 1051, Sec. 1, eff. June 17, 1995.
