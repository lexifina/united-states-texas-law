# Sec. 43.057. ANNEXATION THAT SURROUNDS AREA: FINDINGS REQUIRED.
If a proposed annexation would cause an area to be entirely surrounded by the annexing municipality but would not include the area within the municipality, the governing body of the municipality must find, before completing the annexation, that surrounding the area is in the public interest.
Acts 1987, 70th Leg., ch. 149, Sec. 1, eff. Sept. 1, 1987.
