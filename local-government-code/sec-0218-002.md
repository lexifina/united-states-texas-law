# Sec. 218.002. APPLICABILITY.
This chapter applies only to a municipality with a population greater than 150,000 that is wholly or partly located in a county with a population greater than 300,000.
Added by Acts 2025, 89th Leg., R.S., Ch. 778 (S.B. 840), Sec. 2, eff. September 1, 2025.
Added by Acts 2025, 89th Leg., R.S., Ch. 1026 (S.B. 2477), Sec. 1, eff. September 1, 2025.
