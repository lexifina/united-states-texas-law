# Sec. 5.003. TYPE C GENERAL-LAW MUNICIPALITY.
A municipality is a Type C general-law municipality if it:
(1) has incorporated as a Type C general-law municipality under Subchapter A of Chapter 8 and has not acted to change to another type of municipality;
(2) has changed to a Type C general-law municipality under Subchapter B of Chapter 8 and has not acted to change to another type of municipality; or
(3) operated, immediately preceding September 1, 1987, under Chapter 12, Title 28, Revised Statutes, and has not acted to change to another type of municipality.
Acts 1987, 70th Leg., ch. 149, Sec. 1, eff. Sept. 1, 1987.
