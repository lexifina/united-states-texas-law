# Sec. 284.109. EXCEPTIONS.
Subject to Subchapter D, a network provider may construct, modify, or maintain in a public right-of-way a network node or node support pole that exceeds the height or distance limitations prescribed by this chapter only if the municipality approves the construction, modification, or maintenance subject to all applicable zoning or land use regulations and applicable codes.
Added by Acts 2017, 85th Leg., R.S., Ch. 591 (S.B. 1004), Sec. 1, eff. September 1, 2017.
