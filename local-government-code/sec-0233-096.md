# Sec. 233.096. CRIMINAL PENALTY.
(a) A person who violates this subchapter, an order of the commissioners court, or a rule adopted under this subchapter commits an offense.
(b) An offense under this section is a Class C misdemeanor.
Added by Acts 1991, 72nd Leg., ch. 147, Sec. 1, eff. Sept. 1, 1991. Renumbered from Sec. 237.006 and amended by Acts 2001, 77th Leg., ch; 1420, Sec. 12.003(5), eff. Sept. 1, 2001.
