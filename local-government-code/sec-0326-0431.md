# Sec. 326.0431. WRITE-IN CANDIDACIES.
Write-in votes may be counted only for names appearing on a list of write-in candidates, in the manner that Subchapter C, Chapter 146, Election Code, provides for counting write-in votes for city officers.
Added by Acts 2001, 77th Leg., ch. 61, Sec. 1, eff. Sept. 1, 2001.
