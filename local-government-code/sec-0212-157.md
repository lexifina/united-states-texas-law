# Sec. 212.157. GOVERNMENTAL FUNCTION.
An action filed by a municipality under this subchapter to enforce a land use restriction is a governmental function of the municipality.
Added by Acts 2001, 77th Leg., ch. 1399, Sec. 2, eff. June 16, 2001.
Renumbered from Local Government Code, Section 230.007 by Acts 2007, 80th Leg., R.S., Ch. 921 (H.B. 3167), Sec. 17.001(56), eff. September 1, 2007
