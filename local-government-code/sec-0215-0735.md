# Sec. 215.0735. OPERATORS OF VEHICLES.
The municipality may prescribe the qualifications of an operator of a vehicle that uses the public streets in the municipality.
Added by Acts 1995, 74th Leg., ch. 165, Sec. 3, eff. Sept. 1, 1995. Renumbered from Government Code Sec. 215.0735 by Acts 1997, 75th Leg., ch. 165, Sec. 31.01(32), eff. Sept. 1, 1997.
