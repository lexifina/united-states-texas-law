# Sec. 353.002. APPLICABILITY.
This chapter applies to an incident involving hazardous material that has been leaked, spilled, released, or abandoned on any property.
Added by Acts 2005, 79th Leg., Ch. 930 (H.B. 580), Sec. 1, eff. September 1, 2005.
Added by Acts 2005, 79th Leg., Ch. 1094 (H.B. 2120), Sec. 33, eff. September 1, 2005.
