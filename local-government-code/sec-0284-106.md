# Sec. 284.106. EQUIPMENT CABINETS.
A network provider shall ensure that the vertical height of an equipment cabinet installed as part of a network node does not exceed the height limitation prescribed by Section 284.003, subject to approval of the pole's owner if applicable.
Added by Acts 2017, 85th Leg., R.S., Ch. 591 (S.B. 1004), Sec. 1, eff. September 1, 2017.
