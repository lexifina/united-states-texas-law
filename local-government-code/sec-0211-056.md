# Sec. 211.056. NO EFFECT ON PROPERTY OWNERS' ASSOCIATIONS AND OTHER PRIVATE AGREEMENTS.
This subchapter does not prohibit a property owner from enforcing rules or deed restrictions imposed by a property owners' association or by other private agreement.
Added by Acts 2025, 89th Leg., R.S., Ch. 841 (S.B. 1567), Sec. 1, eff. September 1, 2025.
