# Sec. 352.120. OFFENSE.
A person who violates this subchapter or a regulation adopted under this subchapter in a county that requires compliance with this subchapter under Section 352.113 commits an offense. An offense under this section is a Class C misdemeanor.
Added by Acts 2001, 77th Leg., ch. 111, Sec. 1, eff. Sept. 1, 2001.
