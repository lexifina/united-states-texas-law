# Sec. 352.116. BUILDING IDENTIFICATION.
A county may require each residential building in a multi-unit housing project to have a number or letter in a contrasting color on the side of the building and placed so that the number or letter can be seen from the vehicular driving areas by a responding emergency agency.
Added by Acts 2001, 77th Leg., ch. 111, Sec. 1, eff. Sept. 1, 2001.
