# Sec. 8.021. AUTHORITY TO CHANGE TO TYPE C GENERAL-LAW MUNICIPALITY.
(a) A Type A general-law municipality containing 4,999 or fewer inhabitants or a Type B general-law municipality containing 999 or fewer inhabitants may change to a Type C general-law municipality.
(b) A municipality changing to a Type C general-law municipality adopts the commission form of government.
Acts 1987, 70th Leg., ch. 149, Sec. 1, eff. Sept. 1, 1987.
Amended by:
Acts 2025, 89th Leg., R.S., Ch. 244 (H.B. 303), Sec. 1, eff. May 29, 2025.
