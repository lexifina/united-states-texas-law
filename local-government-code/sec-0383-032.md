# Sec. 383.032. NOTICE.
The temporary directors shall give notice of the election by publishing a substantial copy of the election order once a week for two consecutive weeks in a newspaper with general circulation in the county in which the proposed district is located. The first publication must appear before the 14th day before the date set for the election.
Added by Acts 1995, 74th Leg., ch. 995, Sec. 5, eff. Sept. 1, 1995. Renumbered from Tax Code Sec. 312.615 and amended by Acts 1997, 75th Leg., ch. 165, Sec. 23.05, eff. Sept. 1, 1997.
