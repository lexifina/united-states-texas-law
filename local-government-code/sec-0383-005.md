# Sec. 383.005. GOVERNMENTAL AGENCY; TORT CLAIMS.
A district is a governmental agency, a body politic and corporate, and a political subdivision of the state. Section 375.004 applies to a district.
Added by Acts 1995, 74th Leg., ch. 995, Sec. 5, eff. Sept. 1, 1995. Renumbered from Tax Code Sec. 312.627(b) and amended by Acts 1997, 75th Leg., ch. 165, Sec. 23.05, eff. Sept. 1, 1997.
