# Sec. 117.117. QUALIFICATION AS DEPOSITORY.
A bank selected as a special depository for the registry fund must qualify as the depository in accordance with the same provisions as those prescribed by Subchapter C, Chapter 116, for the qualification as a county depository.
Added by Acts 1989, 71st Leg., ch. 1, Sec. 17(b), eff. Aug. 28, 1989.
