# Sec. 212.132. APPLICABILITY.
This subchapter applies only to a moratorium imposed on property development affecting only residential property, commercial property, or both residential and commercial property.
Added by Acts 2001, 77th Leg., ch. 441, Sec. 1, eff. Sept. 1, 2001.
Amended by:
Acts 2005, 79th Leg., Ch. 1321 (H.B. 3461), Sec. 2, eff. September 1, 2005.
