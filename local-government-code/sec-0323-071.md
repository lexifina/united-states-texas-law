# Sec. 323.071. LIBRARY FINES.
(a) The commissioners court by order may establish reasonable fines to be collected by a county library for lost, damaged, or overdue library property.
(b) The fines shall be deposited in the county free library fund.
Added by Acts 2013, 83rd Leg., R.S., Ch. 697 (H.B. 2902), Sec. 1, eff. September 1, 2013.
