# Sec. 73.001. ELECTION REQUIREMENT.
If a new county is organized, the county judge who conducts the election for officers for the new county shall order an election for the location of the county seat. The election shall be conducted in the same manner as an election for county officers.
Acts 1987, 70th Leg., ch. 149, Sec. 1, eff. Sept. 1, 1987.
