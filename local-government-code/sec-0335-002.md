# Sec. 335.002. APPLICATION TO VENUE CONSTRUCTED UNDER OTHER LAW.
A district may use this chapter for a venue project relating to a venue and related infrastructure planned, acquired, established, developed, constructed, or renovated under other law, including Chapter 505 of this code or Subchapter E, Chapter 451, Transportation Code.
Added by Acts 1997, 75th Leg., ch. 551, Sec. 1, eff. Sept. 1, 1997.
Amended by:
Acts 2007, 80th Leg., R.S., Ch. 885 (H.B. 2278), Sec. 3.21, eff. April 1, 2009.
