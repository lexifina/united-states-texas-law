# Sec. 179.057. COMPLAINTS.
A member of the public may submit a complaint to the municipality or county employing or supervising the first responder using the municipality's or county's existing complaint procedure. One or more complaints received with respect to a specific first responder are grounds for prohibiting or limiting that first responder's carrying a handgun while on duty.
Added by Acts 2021, 87th Leg., R.S., Ch. 1026 (H.B. 1069), Sec. 4, eff. September 1, 2021.
