# Sec. 234.051. DEFINITIONS.
In this subchapter:
(1) "Day-care center" has the meaning assigned by Section 42.002, Human Resources Code.
(2) "Group day-care home" has the meaning assigned by Section 42.002, Human Resources Code.
Added by Acts 2011, 82nd Leg., R.S., Ch. 388 (S.B. 436), Sec. 1, eff. June 17, 2011.
