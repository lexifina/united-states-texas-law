# Sec. 615.102. USE OF MONEY.
Money appropriated to the program under this subchapter may be used only for the support of the county road system, including uses specified by Section 256.003, Transportation Code.
Added by Acts 2001, 77th Leg., ch. 943, Sec. 1, eff. Sept. 1, 2001.
Renumbered from Local Government Code, Section 445.102 by Acts 2007, 80th Leg., R.S., Ch. 885 (H.B. 2278), Sec. 3.76(e)(4), eff. April 1, 2009.
